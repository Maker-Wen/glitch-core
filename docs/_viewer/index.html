§3.5 法则牌桌 (Law Hand) — Run 级主 UI 概念图

玩家在每场战斗之间看到的画面：5 张悬浮行动卡 + 顶部状态 HUD + 底部牌堆 + Boss 锁底

阅读要点：三大区块对应 §3.4.2~§3.4.4 的设计 ——
[1] 顶部 HUD = 全局状态条（圣所完整度 / 灵能 / 牌堆进度）；[2] 中央牌桌 = 5 张行动卡（六大类各一示例：⚔️ 入侵者 / 🏪 商店 / 🎴 法则井 / ❤️ 修复 / 🌀 裂痕）；[3] 底部 = 牌堆 / 历史 / 终极仪式 Boss 锁底

设计意图说明

  • 5 张牌的颜色编码：红色 = 战斗、青色 = 资源消耗、紫色 = 卡组扩充、绿色 = 续命、金色虚线 = 高风险
  • 视觉一致性：每张卡都是六边形切面（呼应 §6.2 的几何美学），中心 emoji + 名称 + 副标题 + 内容预览 + 操作提示
  • 信息层次：玩家一眼能看到所有 5 张卡的核心信息，无需点击就能权衡
  • 心智负担控制：顶部状态、中央选择、底部进度，三层结构信息密度适中
  • Boss 锁底视觉：终极仪式卡用酒红色边框，与 5 张行动卡视觉区分，提示"它在等你"

ℹ️ 注：本图是概念示意，部分细节（如顶部 HUD 中的小队列表）以最新文档为准。v5.2 已确认 4 MVP 构件 = 棱镜 / 楔块 / 棱柱 / 拉钩；卡组容量 3 张全部可用；战斗内动态召唤构件入场。

§2 战斗界面 — 第 2 回合（v5.2 动态召唤版）

v5.2 战斗 UI：8x8 棋盘 / 动态召唤机制 / 卡组 3 张直接可用 / 完美信息预演

场景设定：第 2 回合 · 玩家第 1 回合召唤了棱镜（B4）和棱柱（C4 朝右），现在考虑召唤拉钩到 G2
威胁：重装 D4 攻击范围覆盖 D5/D6 · 重装 E2 朝锚点 D3 行进 · 裂口 G7 下回合出炮灰

v5.2 UI 关键变化

  • 战斗开始 0 构件：v5.2 不再"战前部署"，棋盘上一开始没有玩家构件
  • 左侧"待召唤构件库"：显示 Run 池中尚未召唤的构件 + 出战上限计数（已召唤 2/4）
  • 棋盘召唤区高亮：边缘 2 格青色斜线纹理 = 可放置位置
  • 召唤候选位预览：玩家鼠标悬停时显示"半透明拉钩 + 金色虚线"（如 G2 候选位）
  • 右侧卡组直接展示：3 张卡全部"⚡ 可施放"——v5.2 不需选卡，每张限施放 1 次

通用 UI 元素

  • 顶部 HUD：圣所完整度 + 仪式完成度 + 灵能 + 已召唤数 + 回合 + 卡组状态
  • 锚点视觉：深紫色光柱 + 青色四面体 + 充能进度条
  • 裂口视觉：洋红色波纹 + 倒计时数字 + 出怪类型预告
  • 预警箭头：洋红虚线 = 敌方预警动作（被推走则落空，本回合不重算）
  • 攻击范围：红色半透明覆盖（重装"正前 2 格"清晰可见）
  • 左下威胁面板：实时威胁评估 + 推荐操作（含召唤建议）

§2.3 物理三定律图解

动量与质量物理体系 — 完美信息预演的底层规则

阅读路径：上至下五大定律，每个定律分"碰撞前 → 碰撞后"两帧
最底部的连锁推演示例展示了"工程师感"——一次冲撞触发 4 步连锁结算

三定律速记

  • 定律 1：等价交换（M_A = M_B）— "台球式" — 双方各 -1，A 停 B 接力
  • 定律 2：保龄球（M_A > M_B）— "碾压" — 双方各 -1，A 推 B 整体前移
  • 定律 3：以卵击石（M_A < M_B）— "动能溃散" — A -2 反弹，B 仅 -1 破防
  • 墙壁判定— P ≤ 2 撞墙 -1；P ≥ 3 撞墙 -2（高速重伤）
  • 坠渊判定— 推出盘外 = 立即消亡；敌方 +5 灵能，玩家进入 2 回合冷却

连锁推演（示例）

棱镜冲撞 → 重装接力 → 撞棱柱 → 折射向上 → 推出深渊。 单次冲撞触发 4 步结算，所有伤害与位移在玩家行动前的预演中全部可见。这就是"完美信息" + "工程师感"的具体体现。

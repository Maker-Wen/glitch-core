1. **推挤路径预览** — 策划案核心 UX，玩家最需要预见操作后果

3. **加速带 (Conveyor)** — 丰富环境互动
4. **打击反馈 (Hit Stop + Shake)** — 提升操作手感
5. **Roguelike 路线图** — 从单场战斗扩展为完整 Run

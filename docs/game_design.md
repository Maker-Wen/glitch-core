# 游戏策划案：《故障核心》(Glitch Core)

## 0. 设计北极星 (Design North Star)

**核心体验目标**：**棋手感 + 工程师感 + 轻度魔术师感**。

### 核心设计原则

*   **敌人是棋子，不是对手**：敌人 AI 极度可预测——智能感来自"多个简单棋子的组合"和"棋盘空间挤压"，而非 AI 算法的复杂性。
*   **威胁来自空间，不是攻击**：玩家不应通过"躲避攻击"来减少压力。压力来自棋盘上不断逼近仪式终点的"无情进程"。敌人朝向锚点而非玩家——玩家**主动凑过去**才能阻止仪式。
*   **每个决定都有物理代价**：基于 §2.3 三大物理定律，玩家所有干预手段都伴随**机会成本与连锁后果**。MVP 阶段攻击方不掉血、不位移，代价主要体现为：动作分配（这回合用了棱镜攻击就不能用它做别的）、连锁意外（推飞的目标可能撞到不该撞的位置）、位置消耗（构件原地不动 = 暴露在敌人下回合的攻击范围）；血量代价仅来自被敌人攻击与撞墙。1.0 后通过升华动词、不稳定接入构件等方式重新引入位置/血量代价分支（详见附录 A）。
*   **完美信息**：所有结果可预演，没有随机命中率。决策成败在于推演而非运气。
*   **双阶段决策模型**：逐步搭建法则机关（部署折镜传送门 + 每回合微调位置/朝向 / 铺地块法则卡）→ 再用攻击型注入动量 / 用拉钩把目标拉到机关前 / 用推力卡牌远程触发 → 完成预设连锁。这是"工程师感"的具体载体——折镜可移动（2 格/回合）让布局有渐进式调整空间，但需要在敌人攻击改变其朝向之前提前规划。

## 1. 核心概述 (Game Overview)

*   **游戏名称**：故障核心 (Glitch Core)
*   **游戏类型**：回合制战棋解谜 / Roguelike (Turn-based Tactical Puzzle Roguelike)
*   **开发引擎**：Godot Engine (导出 WebGL/HTML5)
*   **一句话概念**：在漂移崩坏的几何圣所中，熵化体正朝**仪式锚点**行进以完成召唤仪式。你通过"移动→攻击"的物理链式反应、"法则机关"的传送门部署与"法则覆写卡牌"，**阻止它们抵达锚点**。信息绝对公开，这是一场步步为营的脑力与法则碰撞。
*   **流派定位**：Into the Breach 流派的物理化变体——保留 ITB 的完美信息、敌人攻锚点、Roguelike 框架；引入独有的"动量与质量物理三定律"和"法则牌桌 Run 结构"作为差异化核心。

## 2. 核心机制 (Core Mechanics)

### 2.1 完美信息回合制与仪式阻止战 (Perfect Information & Ritual Prevention)

游戏不存在随机命中率，一切结果均可预演。战斗的核心目标是 **"在仪式完成度饱和前阻止敌方"**。

*   **战斗回合数**：每场战斗 = **R0 部署相**（独立阶段，详见 §2.1.2）+ **R1~R5 共 5 个作战回合**
*   **单场仪式条件**：
    *   单场理想结果 = 撑过 5 回合且仪式完成度 = 0
    *   单场可接受结果 = 撑过 5 回合，部分锚点完成（按比例扣 Sanctuary Integrity）
    *   单场失败 = 棋盘上的仪式锚点累计完成 = 总锚点数（MVP 阶段每场固定激活 3 锚点 / 阈值 3，详见 §2.6）
*   **战斗内不 GAME OVER**：即使仪式完成度达到 N，本场战斗结束（敌人撤退/虚空塌陷动画），但 Run 不会立即终止。**Run 失败由 §2.1.1 圣所完整度统一裁定**。

#### 2.1.1 圣所完整度（Sanctuary Integrity）—— Run 级失败条件

*   **初始值**：每个 Run 开始时 = **7**
*   **结算时机**：每场战斗结束后，按本场仪式完成度按比例扣减
    *   完成度 0/N → 完整度 -0
    *   完成度 1/N → 完整度 -1
    *   完成度 2/N → 完整度 -2
    *   完成度 N/N（饱和）→ 完整度 -3
*   **Run 失败条件**：圣所完整度 ≤ 0 → 整 Run 结束
*   **Run 胜利条件**：成功通关法则牌桌的"终极仪式"Boss 战（详见 §3.5）
*   **恢复手段**：法则牌桌中的"❤️ 秩序修复"行动卡可恢复完整度（详见 §3.5）

> **设计意图**：单场战斗可以"亏损"，但要规划全局。这把单场的"完美求胜"压力转化为 Run 级的**资源管理决策**——是这场战斗咬牙保住完整度，还是承受损失但保留主力构件？这是肉鸽的核心张力。

#### 2.1.2 战斗结构：R0 部署相 + R1~R5 作战阶段

每场战斗分两段：**1 个独立的 R0 部署相**（不计入 5 回合战斗预算）+ **R1~R5 共 5 个作战回合**。

##### R0 部署相（独立阶段，不算 5 回合）

战斗开局首先进入**部署相**。这是一段**信息盲区中的承诺时刻**：

1.  **棋盘揭示**：玩家看到完整棋盘——锚点位置、裂口位置（含倒计时）、**晶柱位置**（详见 §2.4.8）、棋盘地形。**敌人尚未现身、不显示任何敌人意图**——R0 期间敌人完全不可见
2.  **构件强制部署**：玩家必须从 Run 池中**选定 4 台构件**（允许重复，详见 §3.1）依次放入棋盘**边缘 2 格内**的空格。必须满 4 台才能结束部署相，**不允许少于 4 台开战**
3.  **折镜默认朝向**：法则机关型构件部署时**朝向自动设为指向棋盘几何中心**的 4 方向之一（详见 §2.4.6 中心朝向规则）；R0 不允许调朝向
4.  **部署完成 → 进入 R1**：玩家点"开战"按钮 → 棋盘上敌人首次刷新、首次预警同步出现 → R1 敌方预警阶段正式开始

> **设计意图**：R0 是玩家在"信息盲区"中做出的**位置承诺**——你不知道敌人会从哪里出现、走向哪条路径，必须靠经验从棋盘几何（锚点位置、裂口节奏、深渊边缘形状、晶柱阻挡格局）推演最优阵型。这是 **"工程师感"的字面化时刻**——开战前的工程蓝图绘制；开战后则是完美信息下的精算执行。R0 的盲点 + R1 起的全开放，构成本作"承诺 vs 精算"的核心张力。

##### R1~R5 作战阶段（每回合执行）

每个作战回合按以下顺序执行：

1.  **敌方预警阶段**：敌人刷新并立即展示下回合的行动意图——**绝大多数敌人朝向最近的未饱和锚点行进**，预警显示其下一格落点 + 攻击范围 + 攻击目标（按敌人类型差异化：被动攻击型仅在被挡路时攻击，主动攻击型如冲锋者会优先选择能撞到玩家的路径，详见 §5.2）。地面亮起"仪式裂口"，预示倒计时回合后即将涌出的新敌人。**R1 的敌方预警阶段是玩家首次见到敌人**——R0 的盲点至此终结
2.  **玩家行动阶段**：操作已在场构件——移动/近战攻击/远程攻击（拉钩拉攻击 / 炮手推攻击），调整折镜朝向，或施放卡组中的法则卡
    *   **R1+ 不再召唤新构件**：构件名单已在 R0 锁定。HP 归零或主动撤回的构件**本场永久离场，不可补援**
    *   **默认显示精确预演**：完整连锁路径、所有伤害数字、各锚点的下回合充能进度等（详见 §2.5）
3.  **敌方执行阶段**：敌人**严格按照之前的预警执行**——如果被推离原位，预警的攻击/移动**继续按原坐标执行**（撞空 / 走空），**本回合不重算**。新位置带来的下一步路径将在**下回合预警阶段**重新计算并显示（详见 §5.0 锁定原则）
4.  **锚点结算**：任何站在锚点格子上的敌人 → 锚点 +1 充能（**简单计数**，不区分敌人质量）。锚点充能 ≥ 阈值 → 该锚点完成 → 仪式完成度 +1（详见 §2.6）
5.  **裂口刷新**：倒计时归零的仪式裂口尝试钻出新敌人。若裂口格子上站有任何单位（不论敌我），则该裂口**被强行压制**——新怪物无法钻出，站在上面的单位受到 **1 点地底冲击伤害**，但**裂口本身不消失，继续保留在该格**等待下回合再次尝试出怪（详见 §2.2）

> **锁定原则**：玩家本回合的位移决策可能让敌人攻击/移动落空，**这正是设计意图**——推开敌人 = 让它本回合的预警动作失效 = 等于额外一回合时间。这把"推撞"从位置博弈升级为**节奏博弈**。

### 2.2 仪式裂口：敌人出生点 (Ritual Rift)

裂口是 **敌人出生点**，是一种 **可交互、短期存在的博弈资源**。注意：裂口（敌人出生）与仪式锚点（仪式终点）是**两种不同的发光格**，详见 §6.2 视觉区分。

#### 2.2.1 裂口生命周期

*   **预警表现**：裂口出现时，地面亮起 **洋红色波纹光芒**（区别于锚点的深紫色稳态光柱），头顶悬浮**倒计时数字**标示"X 回合后出怪"
*   **倒计时**：MVP 阶段统一为 **1 回合**——预警出现的下一回合即尝试出怪
*   **出怪节奏**：每回合激活 **1~2 个裂口**；位置分散；新裂口在每回合"敌方预警阶段"刷新
*   **裂口消失条件**：仅一种——**成功出怪后立即消失**。被压制时**裂口不消失**，继续保留在该格、倒计时保持 0、下回合再次尝试出怪
*   **被压制中的裂口预警**：在下回合"敌方预警阶段"仍点亮波纹光，并显示双状态预警："**若本回合末仍被占据 → 继续阻塞 + 占据者再受 1 伤；否则 → 出怪**"。这让玩家在每回合开始就能精确预演两种分支后果

#### 2.2.2 阻挡规则（持续压制）

*   **裂口结算时机**：每回合"裂口刷新"阶段（§2.1.2 第 5 步）检查倒计时归零的裂口
*   若裂口尝试出怪时，格子上站着任何实体单位（秩序构件或敌方熵化体）→ 新怪物召唤仪式被**强行压制**：
    *   新怪物**不会钻出**（敌方损失本回合增援）
    *   裂口**保持存在**（不消失），倒计时**保持 0**，下回合"裂口刷新"阶段**继续尝试出怪**
    *   站立单位受到 **1 点地底冲击伤害**——压制结算每回合都触发，**只要被占据就持续吃伤**
*   **持续压制循环**：若占据者被磨血至 HP=0（构件碎裂消失 / 敌人被击杀离场）→ 裂口在下回合"裂口刷新"阶段顺利出怪。若一直被占据 → 持续阻塞 + 占据者每回合 -1 HP，直到占据者死亡或主动让位
*   **自我献祭**：玩家可以用自己的构件去堵裂口，但**每回合都要付出 1 HP 代价**——"拿自己人堵门"从"高性价比单次行动"升级为**持续资源消耗博弈**：构件 HP=2 → 最多堵 2 回合就会碎裂；折镜 HP=3 → 最多堵 3 回合（且折镜 M=∞ 不会被推走，是最稳定的"压制专员"，但代价是折镜碎裂后本场永久离场）
*   **互压制（推敌占位）**：玩家也可以**把敌人推到裂口上**——压制下波增援 + 敌人本回合末再受 1 伤；若该敌人下回合仍站在裂口上（敌人按预警执行后未离开），继续吃 1 伤、继续阻塞。这是"用敌人替自己堵门"的战术，比自我献祭更优——但敌人通常会按预警朝锚点移动，**只能阻塞 1 回合**

#### 2.2.3 与锚点的关系

*   敌人**从裂口诞生**，**朝最近未饱和锚点行进**
*   压制裂口 = 减少敌人总量；阻止敌人抵达锚点 = 减少仪式完成度
*   两条防线都需要管理，构成双层空间博弈的核心张力

#### 2.2.4 核心决策

玩家在每个裂口上面临三选一：

*   **A. 推入深渊**（高奖励，远离裂口）—— 敌人坠渊死亡 + 灵能掉落（详见 §3.2）；与裂口无关的最干净击杀
*   **B. 推到裂口上**（中等奖励）—— 敌人本回合受 1 伤 + 压制本回合增援。若敌人下回合按预警离开裂口（朝锚点行进）→ 仅压制 1 回合；若敌人下回合仍在裂口（被卡住 / 被锚定）→ 继续吃 1 伤 + 继续压制
*   **C. 派构件占位**（防御性持续压制）—— 阻止裂口出怪但**构件每回合吃 1 伤**：HP=2 的棱镜 / 拉钩 / 炮手最多堵 2 回合就碎裂；HP=3 的折镜可堵 3 回合（推荐"压制专员"，因其 M=∞ 不会被推走）

**关键设计变化**：旧规则下"压制 = 永久消除一波增援"，B 和 C 都是高性价比的单次行动；新规则下"压制 = 持续阻塞，每回合付费"——B 仅阻塞 1 回合（敌人会走开），C 是真正的"持续压制"但需要持续付出 HP。这把"裂口管理"从一次性博弈升级为**持续资源消耗博弈**，更接近 ITB 的"建筑被打"持续压力哲学

设计目标：让 A、B、C 在地图空间上**互相排斥**（同一时刻不能都做到），强制玩家做战术选择；同时让 C 不再是"无脑堵门"，而是需要权衡"用 X 回合 X HP 换 X 回合阻塞"的资源决策。

### 2.3 核心解谜手段：动量与质量物理体系 (Momentum & Mass)

摒弃了传统战棋的死板设定，引入数值化的物理底层。强制位移不再是简单的算术题，而是符合直觉的"物理法则"。

*   **基础概念**：
    *   **质量 (Mass, M)**：决定单位**被推动难度**——M 越大越难被推动。MVP 数值：构件 M=1（棱镜、拉钩、炮手）、折镜 M=∞；敌方 M=1（炮灰、射手）、M=2（冲锋者）。1.0 后补回 M=3（重装行者 / 楔块）触发撞墙差异化。
    *   **动量 (Momentum, P)**：单位被推出去后携带的动能。单位每滑动 1 格消耗 1 动量，直到归零或掉入盘外虚空。
    *   **力 (Force, F)**：决定单位**主动攻击赋予目标的击退动量**——所有攻击（近战 / 远程）伤害固定 1 点，F 仅控制击退力度（F=1 → P=1，F=2 → P=2，F=3 → P=3）。每个能主动攻击的单位都有 F 数值；不主动攻击的单位（如折镜）没有 F。
    *   **M 与 F 的关系**：M 是被动属性（被推时按 M 算阻力），F 是主动属性（攻击时按 F 算输出）。两者解耦——可以做"轻型重攻击"（M=1/F=3）或"重型轻攻击"（M=3/F=1）的差异化单位。MVP 阶段大多数单位 F=M，1.0 后通过升华路线引入差异化。

*   **碰撞物理定律 (Collision Laws)**：当一个单位 A 携带着 **剩余动量** 碰撞单位 B（或障碍物）时——无论 A 是**主动近战攻击**、还是被推飞接力撞击、还是被远程攻击/拉力推动——**A 自身不掉血、不位移**（攻击方位置永远不变）；B 吸收能量受到伤害与位移：
    *   **定律一：等价交换 ($M_A = M_B$)** —— 动能传导。A **原地不动、不掉血**，并将 **全部剩余动量** 100% 转移给 B。B 受到 **1 点碰撞伤害** 并接力飞出。这是"台球式"连环撞击。
    *   **定律二：保龄球效应 ($M_A > M_B$)** —— 碾压发射。大块头 A **原地不动、不掉血**，把动能传递给小块头 B。B 受到 **1 点碾压伤害** 并以 P=A 剩余动量 飞出（若被推至墙壁则承受二次撞墙伤害）。
    *   **定律三：以卵击石 ($M_A < M_B$)** —— 动能溃散。小块头 A **原地不动、不掉血**。B 吸收冲击力受到 **1 点破防伤害**，仅当 `A 的剩余动量 > B 的质量` 时，B 才会被勉强推退。

> **设计意图**：MVP 阶段攻击方**不掉血、不位移**，鼓励玩家积极进攻、以低操作门槛验证核心体验。"质量差距"完全通过**伤害结果与位移连锁**体现：等价交换 = 双方都受影响（B 飞），保龄球 = B 飞但 A 不跟进，以卵击石 = B 不动但仍受 1 伤。"每个决定都有物理代价"原则在 MVP 阶段限定为**机会成本与连锁后果**（消耗本回合行动权、产生连锁意外），1.0 后可通过升华路线 / 不稳定接入构件重新引入位置代价分支（详见附录 A）。
>
> **术语统一**：本作中"攻击 (Attack)"是统一动词，包括近战攻击（棱镜冲击）、远程拉攻击（拉钩对敌）、远程推攻击（推力卡牌）等。所有攻击对**生物单位**造成 **1 点伤害 + 击退动量**；折镜作为机关有特殊响应（详见 §2.4.6）。三定律描述**任何碰撞物理事件**（无论攻击触发还是被动连锁）。

*   **墙壁判定（撞击不可移动障碍）**：任何单位被推挤撞上**地形边缘**或**不可移动障碍物**（如棋盘外缘、晶柱、折镜）时，动量瞬间溃散，并受到 **1 点撞墙伤害**；若剩余动量 ≥ 3，则加深为 **2 点伤害**（高速撞击的物理直觉）。
    *   **撞晶柱特殊规则**：晶柱 HP=1 → 被撞时晶柱碎裂（详见 §2.4.8）；撞击单位仍受撞墙伤害，但碎裂后该格变空，撞击单位**不会顺势滑入**——动量在撞击瞬间已溃散
    *   **撞折镜不算撞墙**：折镜是传送门，被推飞的单位走入折镜视为"使用传送门"（详见 §2.4.6），不结算撞墙伤害
    > **MVP 阶段说明**：MVP 阶段所有单位的 F ≤ 2（《强力推送》F=2 是上限），常规情况下不触发 P≥3 撞墙差异化。这条差异化是**为 1.0 阶段铺路**——1.0 后引入 M=3 楔块（F=3 近战）与观测者（F=3 远程蓄力）后，"把目标推到墙边/晶柱/深渊边"成为高效战术，让玩家有明确的"墙边突破口"。

*   **坠渊判定**：任何单位（包括秩序构件）被推出盘外边缘时立即坠落阵亡。秩序构件坠渊**本场永久离场**（不再有冷却重组），战斗结束后回到 Run 池满血归位；敌方坠渊则直接消灭并奖励玩家**灵能**（详见 §3.2）。这是物理一致性的铁律——玩家必须把自身站位纳入每回合计算。

*   **Boss 机制免疫**：Boss 不依靠数值免疫推挤，而是拥有"锚定 (Rooted)"状态，免疫一切强制位移直到玩家打破其某种仪式状态（如击破护盾/打断施法）。

#### 2.3.1 原子结算顺序 (Atomic Resolution Order)

当玩家或敌人发起一次攻击 / 推 / 拉 / 卡牌效果时，会触发一连串可能涉及推动、传送、碰撞、死亡、地形效果的连锁。所有连锁按以下**确定性顺序**结算，确保完美信息可推演：

##### 单次攻击的原子链

```
1. 锁定目标 T，结算伤害（T HP -1，但不立即移除）
2. 赋予 T 朝击退方向 P=F 动量
3. 进入【逐格推进循环】：
   while T.动量 > 0:
       下一格 = T 当前位置 + 击退方向
       根据下一格状态分支：
       a. 空格（盘内）             → T 滑入，动量 -1，继续
       b. 仪式锚点 / 仪式裂口      → T 滑入（地面标记不阻挡），动量 -1，继续
                                    （锚点充能 / 裂口压制不在此结算，留到第 4/5 阶段）
       c. 折镜（半透传送门）       → T 因动量进入折镜即时折算：保留剩余动量，
                                    沿折镜朝向方喷出。检查同一原子链中
                                    该折镜是否已被穿越——若是则退化为撞墙
                                    判定（分支 f，防止 A→B→A 循环）。
                                    （注：玩家主动移动绝不会进入折镜——
                                     A* 寻路视折镜为不可通过；折镜仅在
                                     动量推递场景下才触发传送门）
       d. 晶柱                    → 晶柱 -1 HP（碎裂），T 受 1 撞墙伤
                                    （P≥3 时 2 伤），动量溃散归零，停在晶柱
                                    原位前一格。结束推进
       e. 棋盘外缘（盘外）        → T 坠渊，标记死亡。结束推进
       f. 折镜（已被同链穿越过 → 退化为撞墙判定）→ T 受 1 伤（P≥3 时 2 伤），
                                    动量溃散，停在折镜前一格
                                    （注：正常情况下折镜传送优先级高于撞墙；仅当 T 已穿越过
                                     该折镜且第二次进入时才退化——防止折镜循环）
       g. 其他单位 U（敌或友）    → 套用 §2.3 三定律：
                                    比较 T.M 与 U.M → 等价交换 / 保龄球 / 以卵击石
                                    U HP -1（标记死亡但不立即移除），
                                    根据定律分支决定动量是否传给 U：
                                    - 等价交换 / 保龄球 → 动量转移给 U，T 停在原位，
                                      改由 U 接力进入推进循环（从步骤 3 继续，
                                      新主体 = U）
                                    - 以卵击石 → 动量溃散归零，T 停在 U 前一格
4. 推进结束 → 当前主体停在最终位置
5. 链中所有标记死亡的单位**统一移除**（同时离场，不留残骸）
```

##### 多构件 / 多敌人单回合的整体顺序

每回合（详见 §2.1.2）：

1.  **敌方预警阶段**（R1+ 起，每回合开始）
2.  **玩家行动阶段** —— 玩家逐次操作构件 + 卡牌；每次操作触发一次完整原子链（按上方规则结算到底，再开始下一次操作）
3.  **敌方执行阶段** —— 敌人按**全局稳定顺序**逐个执行预警动作：从棋盘**北→东→南→西**逐行扫描，平局按 spawn ID 升序。每个敌人完整执行其预警的"移动 + 攻击"原子链后再处理下一个
4.  **锚点结算阶段** —— 此时盘面已稳定。逐个检查锚点：若有敌人站在锚点上 → 该锚点充能 +1；充能 = 阈值 → 该锚点完成（湮灭锚点上敌人 + 仪式完成度 +1）
5.  **裂口刷新阶段** —— 逐个检查裂口：倒计时归零的裂口尝试出怪；若被占据则压制结算（占据者 -1 HP，裂口保留），否则正常出怪生成新敌人

##### 链中死亡的传递规则（关键设计选择）

- **死亡标记不立即移除**：单位 HP 归零后**仍保留在棋盘上**直到**当前原子链结束**（步骤 5）
- **死亡单位仍可携带动量**：A 推 B 致死 → B 仍按定律分支接力（如等价交换则 B 携带原动量飞向 C，撞 C 后 B 才统一移除）
- **死亡单位不可发起新动作**：链结束后才移除；下回合不再被预警计算
- *设计意图*：保留"推炮灰 → 撞射手 → 飞向冲锋者"这种链式连锁的爽感。如果死亡立即移除会让"用即将死亡的脆皮当炮弹"这种核心战术失效

##### 折镜循环防护

- 同一原子链中，**任意单位最多穿越同一折镜 1 次**
- 第 2 次进入同一折镜 → 视为出口堵塞 → 退化为撞墙判定（动量溃散 + 1 伤）
- 防止 A→B→A、B→A→B 等无限循环

##### 棋盘外效应不在原子链内结算

- 锚点充能 / 裂口压制 / 裂口出怪 **不在原子链内触发**——只在第 4 / 第 5 阶段统一结算
- 即使一个敌人在原子链中被推过 5 个锚点，只算 1 次（按最终落点）
- 即使构件被推到裂口上，本回合内不立即受压制伤；要等到第 5 阶段才结算

> **设计哲学**：原子链 = "纯物理事件序列"；地形效应 = "回合末统一结算"。两者解耦确保完美信息可推演——玩家在玩家行动阶段做决定时，能精确预演物理连锁结果，但不需要在每次推力中间穿插地形结算。

### 2.4 行动模型：移动 / 攻击 / 法则操作 (Action Model)

#### 2.4.1 每回合每构件的标准动作

每个构件每回合执行 **1 次完整动作**，结构如下：

```
1. 移动阶段（可选，最多 1 次）
   └─ 在该构件的"移动力"范围内移动到任意可达空格

2. 行为阶段（最多 1 次，三选一）
   ├─ A. 近战攻击（棱镜）：到位后 4 方向相邻格有敌人 → 1 伤 + P=F_self 击退（套 §2.3 三定律）
   ├─ B. 远程攻击（拉钩 / 炮手）：4 方向直线扫描射程 3，锁定第一目标（友军不可穿透）→ 1 伤 + P=F 击退（详见 §2.4.5）
   ├─ C. 法则操作（折镜）：调朝向 / 主动撤回（消耗本回合该构件的所有行动权）
   └─ D. 不行为：保留位置，回合结束
```

**核心定义**：

*   **移动力（Movement）** = 该构件单次移动阶段最多走的格数（如棱镜 3、拉钩 2、炮手 2、折镜 2）
*   **行动权（Action Slot）** = 1 次"移动 + 行为"组合。每个构件每回合默认 1 个行动权
*   **特例规则可追加行动权**（详见 §2.4.2 表格）

#### 2.4.2 各构件每回合可做多少事（特例汇总）

| 构件 | 标准动作 | 特例规则 | 一回合上限 |
|---|---|---|---|
| **棱镜 Prism** | 移 3 + 行为 1 | 近战攻击结算后**恢复 1 行动权** → 可再做 1 次完整动作 | 2 次（移 3 + 行为 1）× 2 |
| **折镜 Refractor** | 移 2 + 行为 1 | 行为可选"调朝向"（改变传送方向）或"主动撤回"（按 §3.1）| 1 次完整动作（移 2 + 调朝向 / 撤回 / 不行为）|
| **拉钩 Grappler** | 移 2 + 行为 1 | 行为可选"远程拉攻击"（4 方向直线扫描射程 3，**友军不可穿透**；锁定方向上第一个目标，无论敌我 → 1 伤 + 拉；详见 §2.4.5） | 1 次完整动作 |
| **炮手 Cannoneer** | 移 2 + 行为 1 | 行为可选"远程推攻击"（4 方向直线发射炮弹，射程 3，**友军不可穿透**；锁定方向上第一个目标，无论敌我 → 1 伤 + P=F=1 推；详见 §2.4.5） | 1 次完整动作 |

> **MVP 阶段构件名单**：棱镜 + 折镜 + 拉钩 + 炮手（共 4 种）。每场战斗玩家从这 4 种中**选 4 台**出战，**允许重复**（如 1 棱镜 + 1 折镜 + 1 拉钩 + 1 炮手，或 2 棱镜 + 1 折镜 + 1 炮手）。楔块（重型攻击）延后到 1.0（详见附录 A.4）。

#### 2.4.3 移动规则

##### 2.4.3.1 选中即显示可达集（ITB 风格）

*   **点选构件**：玩家点击场上的友方构件 → 系统**高亮显示该构件本回合所有可达落点格**（详见 §2.5.2 移动范围可视化）
*   **A\* 寻路 + 4 方向**：可达集按 4 方向 A\* 寻路计算，距离为**有效路径长度**而非曼哈顿直线——绕路也算消耗移动力
*   **障碍阻挡可达集**：
    *   敌人单位 / 友方构件 / 晶柱 → **完全阻挡**寻路；占据格不可达，且若无路绕过则身后区域也不可达
    *   折镜 → **完全阻挡寻路（半透传送门）**：玩家主动移动 A\* 把折镜视为不可通过节点，与晶柱一致——折镜仅在"被推递动量进入"时才触发传送门效果（详见 §2.4.6）；主动移动**永远不能走入或穿过**折镜
    *   仪式锚点 / 仪式裂口 → **不阻挡寻路**（地面标记），可以踩上去
    *   深渊（盘外）→ 不算可达
*   **范围呈不规则形状**：因为障碍可能切断身后的区域，可达集**不是规则的菱形**——敌人正后方、晶柱身后、或被折镜朝向"折叠"过去的格都是不规则的可达边界

##### 2.4.3.2 点击直达（ITB 风格）

*   **点击可达格** → 构件**直接传送/滑动**到该格（视觉上沿 A\* 路径滑动作动画，逻辑上直接结算落点）
*   **不显示中间路径**：玩家无需选路、无需确认中间节点；只看可达集、点目标即移动
*   **未使用的移动力不浪费 / 不留存**：移动到落点后剩余移动力直接清零；本回合不能再次移动该构件（除非有"恢复行动权"特例如棱镜近战后）
*   **移动本身不触发攻击**——到位后由玩家主动决策是否进入行为阶段（近战 / 远程 / 法则操作）
*   **可点击但无可达格的构件**：若构件被完全包围（4 方向都是障碍）→ 可达集只含原地 → 玩家可选"原地不动"跳过移动阶段直接进入行为阶段

##### 2.4.3.3 寻路边界条件（A\* 边角情况）

以下规则在文档中明确，避免实现时的设计-程序员歧义：

*   **折镜（半透传送门）A\* 处理**：
    *   主动移动（玩家与敌人）→ A\* 把折镜视为**不可通过节点**，与晶柱一致——必须绕开
    *   折镜仅在"**被推递动量进入**"时触发传送门效果（详见 §2.4.6 / §2.3.1 原子结算第 3 步分支 c）；主动移动 A\* 与传送门规则**完全分离**
    *   被推递动量进入折镜时，若**朝向方格被堵塞**（晶柱 / 敌人 / 友军 / 盘外）→ 视为撞墙，单位受 1 撞墙伤 + 动量溃散 + 折镜不掉血（详见 §2.3.1 分支 f）
    *   **同一原子链中同一折镜最多被穿越 1 次**——防止 A→B→A 循环。第 2 次进入退化为撞墙
*   **A\* 平局规则**：多条等长路径并存时，按 **北 → 东 → 南 → 西** 优先级 tiebreak，与敌人寻路 tiebreak 一致（详见 §5.0）。该规则仅影响动画路径展示——逻辑上落点与移动力消耗一致
*   **不允许对角穿越**：4 方向 A\* 严格只走正交方向；即使两个对角格都空、对角相接的两个格被障碍占据，也**不允许"切角"穿越**
*   **晶柱和折镜在 R0 部署时不可被覆盖**：玩家 R0 部署时构件不能放在晶柱 / 折镜已占据的格（晶柱不可踏；折镜位由其他构件部署生成，单格仅一构件）
*   **构件无可达格时的 UX**：若被完全包围 → 移动范围 UI 仅高亮原地（青色脉动）+ 显示"无可达落点"提示；玩家直接进入行为阶段或跳过本构件回合

#### 2.4.4 近战攻击规则 (Melee Attack)

*   构件移动到位后，若相邻格（4 方向任一）有**敌人单位** → 出现"近战攻击"选项
*   近战攻击 = 对目标造成 **1 点伤害** + 以 `击退动量 = F_self` 推动目标朝攻击方向飞出，完全套用 §2.3 三大物理定律结算
*   攻击可**引发连锁**：若被推飞的目标携带剩余动量撞上下一个单位，后续碰撞按定律传导
*   **近战攻击后构件位置永远不变** —— 无论三定律走哪条分支，攻击方都原地不动
*   构件可选择**不攻击**，保留位置消耗行动力结束回合——提供"定位而不交战"的选项
*   **MVP 棱镜攻击力分析**：棱镜 M=1, F=1
    *   撞炮灰（M=1）/ 射手（M=1）→ 等价交换 → 棱镜原地，目标 -1 + 飞 1 格（动量耗尽即停）
    *   撞冲锋者（M=2）→ 以卵击石 → 棱镜原地，冲锋者 -1（不动）
    *   连锁需要敌人**紧贴排列**（飞 1 格后接触下一个），否则连锁中断

#### 2.4.5 远程攻击 (Ranged Attack)

施加方（拉钩构件、炮手构件、或推/拉类卡牌）选定**4 方向之一**，沿该方向锁定**第一个目标 T**（敌我无差别，**友军不可穿透**），对 T 实施远程动作：

*   **统一规则**：对 T 造成 **1 点伤害 + P=F 击退动量**（拉攻击朝施加方拉，推攻击朝远离方推）
*   **不分阵营**：无论 T 是敌人还是友军，伤害与位移规则完全一致——这是"远程攻击的目标都是当前方向上第一个目标"的设计意图
*   *友军伤害的代价意义*：玩家若误把构件挡在拉钩/炮手射线上，将自伤——逼迫玩家精算射线占位，远程攻击不再是"无脑安全的清场工具"

**F 数值由施加方决定**：

| 远程工具 | F 数值 | 方向 |
|---|---|---|
| 拉钩远程拉攻击 | **F=1** | 朝施加方拉 |
| 炮手远程推攻击 | **F=1** | 远离施加方推 |
| 《脉冲推送》卡 | **F=1** | 远离施加方推 |
| 《拉扯》卡 | **F=1** | 朝施加方拉 |
| 《强力推送》卡（稀有）| **F=2** | 远离施加方推 |
| 1.0 后观测者远程攻击 | F=3 | 远离施加方推 |

**推力工具**（炮手构件 + 卡牌《脉冲推送》《强力推送》）与**拉力工具**（拉钩构件 + 卡牌《拉扯》）共用本节判定逻辑，仅位移方向相反。

##### 2.4.5.1 目标锁定（直线工具专用：方向性扫描 · 友军不可穿透）

拉钩与炮手沿选定方向扫描射程 1~3 格：

*   遇到**任何单位**（敌人 / 友军 / 折镜 / 不可推动障碍）→ 强制锁定该单位为 T，**不可跳过、不可穿透**
*   扫描完 3 格仍无可锁定目标 → 远程动作作废，行动权消耗
*   全图卡牌（《脉冲推送》《拉扯》等）不需要扫描——直接选定目标，仅直线构件适用本扫描规则

##### 2.4.5.2 攻击效果与连锁判定（推/拉共用）

锁定 T 后，先结算攻击效果（**T 受 1 伤**，无论敌我），再赋予 T 朝击退方向 **P=F** 动量。判定 **T 的下一格状态**：

| 下一格状态 | 结果 |
|---|---|
| **空格（盘内）** | T 滑 1 格停下（F=1）/ 滑 N 格直到动量耗尽（F≥2）|
| **盘外（深渊边缘）** | T 坠渊（套用 §2.3 坠渊判定；友军坠渊本场永久离场）|
| **施加方自己（仅拉力）** | T 停在施加方相邻格，**不触发额外碰撞结算**（远程攻击的伤害与击退已结算完毕；远程拉攻击的"靠近施加方"是设计意图——拉钩的攻击方式就是把目标扯到自己面前 -1 后停下）|
| **其他单位（敌或友）** | **触发 §2.3 三定律连锁**——T 以 P=F 撞击该单位，按 M 比较结算（被撞的友军同样吃 1 伤 + 套定律）|
| **折镜（传送门）** | T 走入折镜 → 立即从折镜朝向方喷出（P=F 保留），按朝向格继续判定。详见 §2.4.6 |
| **墙 / 不可推动障碍** | **触发 §2.3 撞墙判定**——T 受 1 点撞墙伤害（P ≤ 2 时），动量溃散；F≥3 时撞墙 2 伤 |

##### 2.4.5.3 关键差异（远程攻击 vs 近战攻击）

*   远程攻击 = "1 伤 + P=F 击退动量"——击退力度由 F 控制（拉钩/炮手 F=1，《强力推送》F=2，1.0 观测者 F=3 触发撞墙差异化）
*   远程攻击**施加方不参与定律结算**——拉钩 / 炮手既不掉血、也不位移；连锁仅在被推飞的目标 T 撞上第三方时触发
*   远程攻击是"安全代价低、威力受 F 决定"的工具；近战攻击是"无位置代价但需相邻、击退 P=F_self"的工具
*   远程拉攻击**几乎无法直接送敌进深渊**（拉钩位于盘内，敌人朝拉钩移动 = 远离深渊）；远程推攻击则可顺势送渊。送渊任务由近战攻击 / 折镜传送门 / 炮手 / 推力卡牌承担
*   **友军不可穿透 = 占位代价**：拉钩 / 炮手射线上若挡有友军构件，强制锁定该友军 → 友军吃 1 伤 + 被推/拉。玩家必须把"射线净空"纳入每回合规划

##### 2.4.5.4 示例：拉钩沿线锁定第一目标（友军挡线 = 误伤）

```
G _ A _ E    (G 拉钩 F=1，A 友军，E 敌人)
玩家选定方向「右」，扫描遇 A → 强制锁定 A（友军不可穿透）
↓ 攻击效果：A 受 1 伤，赋予 P=F=1 朝 G 方向击退
G A _ _ E    (A 滑 1 格到 G 相邻格停下；E 不受影响)
```

> **设计要点**：在新规则下，"用拉钩从远处援护友军"不再是无代价动作——拉友军过来同时让其 -1 HP。玩家若需安全位移友军，应使用近战推 / 折镜传送门 / 主动撤回。

##### 2.4.5.5 示例：拉钩直接拉到面前

```
G _ Z E _    (G 拉钩 F=1，Z/E 紧贴的两个敌人)
玩家选定方向「右」，扫描锁定第一目标 Z
↓ 攻击效果：Z -1 HP，赋予 P=F=1 朝 G 方向击退
G Z _ E _    (Z 滑 1 格到 G 相邻格停下，攻击结算完毕)
（连锁需要 Z 的下一格有第三方才会触发——本例下一格空，无连锁）
```

```
G _ E Z _    (E 在中间，Z 在远侧)
玩家选定方向「右」，强制锁定最近的 E
↓ 攻击效果：E -1 HP，赋予 P=F=1 朝 G 方向击退
G E _ Z _    (E 滑到 G 相邻格，停下；Z 不动)
```

##### 2.4.5.6 示例：炮手远程推攻击送渊

```
_ _ _ E _ C    (C 炮手 F=1，E 敌人，左侧空格 + 深渊在最左)
玩家选定方向「左」，扫描锁定第一目标 E
↓ 攻击效果：E -1 HP，赋予 P=F=1 朝 C 反方向（左）击退
_ _ E _ _ C    (E 滑 1 格停下；若左侧 1 格即为深渊则 E 直接坠渊)
```

##### 2.4.5.7 推力卡牌（全图）

推力卡牌不需要直线扫描，直接选定全图任意敌人，详见 §3.2.2 类三：

*   **《脉冲推送》**：选定全图任意敌人施加 **远程推攻击**（1 伤 + **F=1** 推开）
*   **《强力推送》**（稀有）：施加 **远程推攻击**（1 伤 + **F=2** 推开），F=2 可一次飞 2 格送渊或撞击连锁

推力卡牌套用 §2.4.5.2 攻击效果与连锁判定（方向相反、施加方为虚拟法则点位、不存在"施加方相邻格"概念因为施加方不在棋盘上）。**卡牌锁定目标不限制阵营**——但绝大多数情境下玩家不会主动选自己的构件作为目标。

##### 2.4.5.8 远程攻击命中折镜：被折射

折镜是法则机关（详见 §2.4.6 / §3.1.1），对**远程攻击免疫**——但远程动量不会消失，而是**被折镜折射**：

*   **远程拉/推攻击命中折镜**：
    *   折镜**不掉血、不动、朝向不变**
    *   攻击的击退动量（F）被折镜**沿其朝向方重新发射**为推力，朝折镜朝向方的相邻格作用
    *   折镜朝向方相邻格的状态决定后续：空格 → 推力扩散到该格（无作用单位则消散）；有单位 → 该单位受 P=F 推力朝折镜朝向方滑动 + 套三定律连锁
    *   **关键**：远程攻击的"伤害效果"（1 点）也被折镜吸收（不结算）—— 远程攻击对折镜完全失效，仅折射动量
*   **示例**：
    ```
    G(拉钩) _ R(折镜朝东) _ E(敌人)    G 在西，R 朝东
    ↓ 拉钩沿线扫描锁定第一目标 R（折镜不可穿透）→ 远程拉攻击（F=1 朝西拉）
    G _ R E _    (R 不动；F=1 被折射为「朝东推 1 格」；E 受 P=1 推朝东滑 1 格 → 但 E 已在 R 的东边相邻格，相当于 E 朝东再滑 1 格)
    ```
*   **设计意义**：折镜免疫远程，但折射的动量可被玩家**主动利用** —— 用拉钩 / 炮手攻击折镜可以"借力"对折镜朝向方的目标产生推力，作为远距离触发连锁的工具。炮手对折镜施加远程推攻击时，折射方向同样按折镜朝向

#### 2.4.6 法则部署 — 折镜（半透传送门机关）

折镜是 MVP 阶段唯一的法则机关，机制为**半透传送门**——主动移动**不能进入**（占位阻挡寻路），但**被推递的动量可进入并被传送**：

##### 占位与寻路（关键差异：与旧"传送门"不同）

*   **完全阻挡寻路与主动移动**：
    *   敌人 A\* 寻路把折镜视为**不可通过节点**——必须绕开
    *   玩家构件主动移动**不能走入折镜所在格**（与晶柱、其他构件一致）
    *   折镜是棋盘上的"硬物"——单位不能借它"走捷径"
*   **被推递动量可进入（半透传送门）**：
    *   被推 / 被拉 / 三定律连锁动量传导**进入折镜所在格** → 立即从折镜朝向方喷出
    *   **保留剩余动量**朝折镜朝向方向喷出
    *   若朝向方向是空格 → 单位停在该格（动量耗尽则停）
    *   若朝向方向是其他单位 / 墙 / 晶柱 / 深渊 → 套用 §2.3 三定律或撞墙/坠渊判定
*   **关键设计差异**：旧版"折镜不阻挡寻路"让玩家可"借折镜当电梯"；新版**折镜阻挡寻路 + 仅被动量进入**——折镜回归"工程师工具"角色，不再是"廉价机动加速"
*   **R0 部署不允许走入**：玩家在 R0 部署时不能把构件放到折镜所在格，折镜与晶柱在阻挡上一致

##### 远程攻击折射（保留）

*   **远程拉/推攻击命中折镜** → 折镜**不掉血、不变朝向**，攻击的击退动量（F）被折镜**沿其朝向方重新发射**（详见 §2.4.5.8）
*   折镜朝向**仍然有意义**——决定折射方向 + 决定被推入时的喷出方向
*   设计意义：折镜仍是"机关"而非纯硬墙——玩家可"对折镜开火 → 借力推动折镜朝向方的目标"，连锁工具仍存在

##### HP 与受伤规则（HP=3，可摧毁）

*   **HP=3**，三种攻击命中分支：
    *   **近战攻击命中折镜** → 折镜 -1 HP + 朝向变为攻击来源反方向（攻击者套以卵击石规则：原地不动）
    *   **AOE 攻击命中折镜** → 折镜按 AOE 数值 -N HP + 朝向变为攻击合力反方向（MVP 阶段无 AOE 敌人，1.0 后激活）
    *   **远程拉/推攻击命中折镜** → 折镜**不掉血、不变朝向**，攻击动量被折射朝折镜朝向方重新发射（详见 §2.4.5.8）
    *   **被推飞的连锁动量进入折镜所在格** → 视为"使用半透传送门"，不算"攻击折镜"，折镜不掉血
*   **HP 归零** → 折镜碎裂，本场永久离场（下场战斗满血归位）

##### 移动与行为

*   **M=∞，主动移动力 = 2**：折镜免疫一切外力位移（推/拉/三定律连锁都推不动它），但每回合可主动移动 2 格调整阵型
    *   主动移动遵循正常 A\*——折镜不能穿过其他单位 / 晶柱 / 折镜 / 深渊
*   **行为阶段动作**：调整朝向（4 方向之一）或主动撤回（按 §3.1，撤回后本场永久离场）
*   **R0 部署的初始朝向规则（中心朝向）**：折镜在 R0 部署相放下时，朝向**自动指向棋盘几何中心**——
    *   设折镜坐标 (px, py)、8x8 棋盘几何中心 (3.5, 3.5)，向中心的位移为 (dx, dy) = (3.5-px, 3.5-py)
    *   **候选朝向集合**：所有"与位移同号"的轴向方向（即指向中心的方向）：
        *   dx > 0 → 候选包含 **东** ；dx < 0 → 候选包含 **西**
        *   dy > 0 → 候选包含 **南** ；dy < 0 → 候选包含 **北**
        *   （dx 或 dy = 0 时该轴不贡献候选方向）
    *   **从候选中选取**：按 **北 → 东 → 南 → 西** 优先级取第一个候选方向（与敌人寻路 tiebreak 一致）
    *   *示例 1*：折镜放在 (1, 1) 西北角 → 位移 (+2.5, +2.5) → 候选 {东, 南} → 取**东**
    *   *示例 2*：折镜放在 (6, 1) 东北角 → 位移 (-2.5, +2.5) → 候选 {西, 南} → 取**南**（北→东→南→西 中"南"优先级高于"西"）
    *   *示例 3*：折镜放在 (3, 0) 北边正中 → 位移 (+0.5, +3.5) → 候选 {东, 南} → 取**东**（dx 微小但仍 >0）
    *   *示例 4*：折镜放在 (3, 3) 接近中心 → 位移 (+0.5, +0.5) → 候选 {东, 南} → 取**东**
    *   R0 不允许改朝向 —— 玩家必须等到 R1 玩家行动阶段才能用折镜的"行为阶段动作"调整朝向（消耗当回合行动权）
    *   **设计意图**：避免 R0 决策爆炸——玩家专注于"放在哪"，朝向自动给一个合理默认值；想"改朝向"必须付出 R1 的行动权，符合"工程师感"的承诺成本逻辑

##### 战术核心（折镜新角色）

*   **占位拦路** + **动量传送** + **远程折射** = 三合一工具
*   阻挡敌人寻路：把折镜放在锚点附近 → 敌人必须绕路 → 多消耗 1-2 回合
*   传送动量：拉钩拉敌人到折镜前 → 敌人撞入折镜被动量推入 → 从朝向方喷出（送进深渊或撞另一敌人）
*   远程折射：炮手对折镜开火 → 沿朝向方推送另一格目标 → 远距离触发连锁
*   **新差异**：折镜不再是"敌人廉价加速通道"——玩家放置折镜**只对玩家有利**（提供绕路压力 + 动量传送 + 折射机关）。这修正了旧规则下"折镜阻碍我也阻碍敌"的中性设计

#### 2.4.7 卡牌动词（独立于构件回合）

*   施放卡牌**不消耗任何构件的行动权**——卡牌是"全局法则修改指令"，独立于棋子回合
*   玩家整回合可使用卡组中所有卡牌（卡组容量 3 张，每张每场战斗限用 1 次，详见 §3.2）
*   推/拉类卡牌（《脉冲推送》《拉扯》等）使用 §2.4.5 的远程攻击规则（卡牌为全图选目标，不走直线扫描）
*   其他法则覆写卡（《质量置换》《零摩擦领域》等）按各自卡面文本生效

#### 2.4.8 棋盘地形 — 晶柱（Crystal Pillar，可破坏障碍）

晶柱是 MVP 棋盘上的**可破坏障碍地形**——是 ITB"山"机制的本作变体，提供"虚空（瞬死）"和"折镜（传送门）"之外的第三类阻挡形态：**会被打碎的硬墙**。

##### 2.4.8.1 基础规格

| 属性 | 值 | 说明 |
|---|---|---|
| **HP** | 1 | 任意攻击 / 撞击命中 → -1 HP → HP=0 → 碎裂消失，留下空格 |
| **M** | ∞ | 不可被任何外力位移（推/拉/连锁动量传导都推不动） |
| **F** | — | 无主动攻击能力 |
| **可踏** | ❌ 否 | 单位不能站立、移动不能穿过 |
| **阻挡寻路** | ✅ 是 | 晶柱是**一击碎死墙**（HP=1）；折镜是**永久半透墙**（HP=3 + M=∞ 不可摧毁外力位移 + 仅被动量进入）。敌人 A* 寻路对二者都必须绕开 |
| **阻挡动量** | ✅ 是 | 被推飞的单位撞上晶柱时动量溃散（详见下方碰撞规则） |
| **可见性** | 整局可见 | 战斗开始前棋盘揭示时即标注位置（含 R0 部署相） |
| **生成方式** | 棋盘预设 | 棋盘骨架手工设计 + 程序化激活 2~3 块（详见 §4） |

##### 2.4.8.2 攻击与碰撞规则

晶柱不参与三定律（§2.3）的"质量比较"——它的 M=∞ 让一切试图推动它的力都退化为"撞墙判定 + 晶柱扣 1 HP"。具体分两种情境：

**情境 A · 主动攻击晶柱**（构件 / 敌人主动出击）：

*   棱镜近战攻击晶柱 → **晶柱 -1 HP（碎裂消失）+ 棱镜原地不动**
    *   攻击方按物理三定律"攻击方不掉血、不位移"——主动出击不算撞墙
    *   棱镜可"主动拆墙"——为打开新路径或暴露后方敌人付出 1 行动权
*   炮手远程推攻击命中晶柱 → **晶柱 -1 HP + 炮手不受影响**
    *   远程攻击同样"施加方不参与定律结算"
    *   炮手是 MVP 阶段唯一能远程拆墙的工具
*   拉钩远程拉攻击命中晶柱 → **晶柱 -1 HP + 拉钩不受影响**（晶柱不会被拉过来——M=∞）
*   **敌人不会主动攻击晶柱**：MVP 阶段敌人 AI 永远绕开晶柱（详见 §2.4.8.3 + §5.0）。即使冲锋者直线冲刺路径上有晶柱，AI 也会重新选择不经过晶柱的路径——若所有路径都被晶柱阻断则原地停留，不会主动拆墙。1.0 后引入主动攻击型敌人或 AOE 自爆体后该规则可能调整

**情境 B · 被推飞的单位撞晶柱**（连锁动量碰撞）：

*   被推飞的单位（敌人 / 构件）携带 P≥1 撞上晶柱 → **双方都受伤**：
    *   **晶柱 -1 HP**（碎裂消失）
    *   **撞击单位受 1 点撞墙伤害**（套用 §2.3 撞墙判定；P≥3 时撞墙 2 伤）
    *   撞击单位**停在晶柱原位的前一格**（晶柱碎裂后该格变空，但单位不会顺势滑入——动量在撞击瞬间已溃散）
*   *战术意义*：玩家可"棱镜近战推炮灰撞晶柱"——炮灰 -1（推飞伤害）+ 撞墙再 -1（炮灰 HP=1 直接死） + 晶柱 -1（碎裂打开通路）。一次行动三连收益

> **设计意图**：主动攻击 vs 连锁碰撞的差异——主动攻击是"工程师有计划地拆墙"，连锁碰撞是"被推过去顺便撞坏"，后者让推力工具有了**"杀敌 + 拆墙"**的双重价值。

##### 2.4.8.3 与其他棋盘元素的交互

*   **vs 折镜传送门**：折镜传送门是"瞬移" → 单位走入折镜后从朝向方喷出。若**折镜朝向方相邻格是晶柱**：
    *   单位被传送后撞上晶柱 → **晶柱 -1 HP 碎裂消失 + 单位受撞墙 1 伤** + 单位停在晶柱原位（现在是空格）
    *   这是 §2.4.8.2 情境 B"被推飞的单位撞晶柱"的标准结算——传送同样视为"被赋予动量的位移"
    *   *战术意义*：玩家可故意把折镜朝向设为晶柱方向 → 用拉钩拉敌人到折镜前 → 敌人走入折镜被传送撞晶柱 → 敌人 -1（被拉时） -1（撞墙）+ 晶柱破碎打开通路。**4 段连锁**的终极工程师战术
*   **vs 仪式锚点**：晶柱不影响锚点——锚点是地面标记（§2.6.1），可与晶柱在不同格共存
*   **vs 仪式裂口**：晶柱不会生成在裂口候选位置——避免"裂口出怪即被晶柱顶死"的死锁
*   **vs 深渊（盘外虚空）**：晶柱不会贴边生成（保留至少 1 格通路），避免"晶柱挡住所有送渊路径"
*   **vs 单位寻路（§5.0）**：敌人 A* 把晶柱视为不可通过节点；绕路计算照常（≤2 格则绕，否则攻击挡路构件——但晶柱不是单位，不在攻击偏好列表，敌人**不会主动攻击晶柱**，永远只绕路）

##### 2.4.8.4 视觉表现

*   **未受损晶柱**：地面竖立的青色发光多面体（直径 ≈ 0.8 格），表面有细密的几何纹路，缓慢自旋
*   **被攻击瞬间**：纹路断裂闪光、白色碎片飞溅（持续 0.3 秒顿帧），晶柱整体抖动
*   **碎裂消失**：多面体几何分解为青色光尘飘散——**几何结构被抹除**的冷硬质感（与 §6.3 死亡特效原则一致）
*   **碎裂后**：该格变为普通空格，无残留视觉占位（与锚点完成的"黑色凹陷痕迹"区分——晶柱碎裂是中性的"通路打开"事件，不附带语义重量）

### 2.5 默认精确预演 UI (Default Precise Preview)

完美信息游戏的精髓在于**所有信息默认即可见**——分层 UI 反而会让新手以为"简略层就够了"，错过游戏精髓。本作采用 ITB 式的"默认精确"，但用**视觉信息密度**而非"分层切换"来管理认知负担。

#### 2.5.1 默认显示内容（无需任何按键切换）

*   敌方所有单位的下回合行动意图（移动落点 + 攻击范围 + 攻击伤害 + 锁定目标）
*   玩家操作时的完整连锁路径与所有伤害数字
*   双方最终位置、坠渊判定、撞墙伤害、晶柱破碎预演
*   各锚点的"下回合充能进度预测"
*   所有裂口的倒计时与出怪预告（含被压制的双状态预警，详见 §2.2.1）

#### 2.5.2 移动范围可视化 (Movement Range)

构件移动范围采用 **ITB 风格"可达落点高亮"** —— 不显示路径，只显示终点。

##### 触发与显示规则

*   **触发**：点选场上的友方构件 → 立即高亮所有可达落点格
*   **可达集**：按 §2.4.3 A\* 寻路计算，覆盖该构件本回合移动力范围内**未被障碍切断**的所有落点
*   **不规则形状**：因为障碍切断身后区域，可达集**不是规则菱形**——这是与 ITB 一致的核心特征
    *   敌人 / 友方构件 / 晶柱占据的格 → 不可达
    *   敌人 / 友方构件 / 晶柱**正后方**的格 → 仅当存在绕路时可达，否则不可达
    *   折镜（半透传送门）→ 玩家主动移动**不能进入**折镜所在格（A\* 视为不可通过，与晶柱一致）；折镜仅在"被推递动量进入"时才传送（详见 §2.4.6 / §2.3.1）
    *   仪式锚点 / 仪式裂口 → 不阻挡，可作为落点（但落在裂口上下回合会受 1 伤压制结算）

##### 视觉编码

| 元素 | 视觉样式 | 颜色 |
|---|---|---|
| **可达落点格** | 半透明地面发光叠加层（菱形纹路）| **霓虹青** Cyan，与秩序阵营色一致 |
| **构件原位** | 高亮边框脉动 | 青色脉动光环 |
| **不可达格（障碍后方）** | 不显示叠加层 | —— 玩家通过"无高亮"自然识别"过不去" |
| **障碍单位**（敌人 / 友军 / 晶柱）| 单位本身正常显示 + **暗红色/暗灰阻断标记** | 暗红 = 敌人阻断；暗灰 = 晶柱 / 友军阻断 |
| **悬停某可达格** | 该格脉动高亮（**不显示路径**）| 加深的青色发光 |
| **点击可达格** | 构件沿 A\* 路径滑动到该格（动画）| 滑动轨迹仅作动画表现，不影响逻辑 |

##### 与敌人移动预警的视觉区分

由于"玩家可达集"和"敌人下回合落点"是两类信息，必须严格区分：

*   **玩家可达集**：青色（霓虹青地面叠加层）—— 仅在玩家**点选构件**时显示
*   **敌人移动预警**：洋红色（朝下一格落点的发光圆环）—— **始终默认显示**，不需要点选
*   **敌人攻击范围预警**：红色虚线 / 红色目标格高亮 —— 始终默认显示
*   **关键差异**：敌人**不显示"可去范围"**——只显示"下回合实际会去那一格"。完美信息原则下，预警告诉玩家**确切的下回合行动**，玩家无需推算"敌人能到多远"

> **设计意图**：这与 ITB 的"敌人预警 = 红色具体目标"哲学一致——不让玩家算 What If（"如果我推它一下它就够不到我"），而是让玩家**先精算自己的可达性**（青色范围），再**针对敌人的具体威胁**（红色预警）做出反应。这把"信息盲区博弈"从 ITB 的"敌人射程范围"层面降低到"敌人确切目标"层面，更紧凑、更 puzzle-like。

##### 远程攻击射程预览（独立 UI 层）

*   选定拉钩 / 炮手后，按行为阶段 → **沿 4 方向各显示一条 3 格直线扫描线**（每条线扫描沿途的第一个目标）
*   每条线的视觉：青色虚线 + 沿途每格中心的小圆点（指示扫描经过的格）
*   被锁定的目标格脉动高亮 + 显示预演结果（如"E -1 + 飞 1 格停在 X 格"）
*   **友军不可穿透提示**：若直线第一个目标是友军 → 该线显示为**橙色警告色**（与青色"安全攻击线"区分），提醒玩家"会自伤"

#### 2.5.3 视觉密度管理（替代分层）

*   **颜色编码总表**：

| 颜色 | 含义 |
|---|---|
| **霓虹青** Cyan | 玩家可控元素：构件 / 玩家可达集 / 玩家攻击预演 |
| **深紫** Purple | 仪式锚点（长期发光柱） |
| **洋红** Magenta | 仪式裂口 / 敌方单位 / 敌人预警轨迹 |
| **红色** Red | 直接锚点威胁 / 敌人本回合攻击命中格 |
| **橙色** Orange | 间接威胁 / 友军挡线警告 |
| **暗灰** Dark Gray | 晶柱 / 不可达 / 已结算的"阴影信息" |

*   **箭头粗细**：动量大 → 箭头粗（P=1 细线、P=2 中线、P=3 粗线）
*   **悬停聚焦**：鼠标/手指悬停某单位时，**仅高亮**与该单位相关的预演线，其余淡化（不删除——只是降低透明度）
*   **预演锁定**：点击"暂停预演"按钮可冻结当前画面便于细看
*   **信息层次原则**：紧迫信息（即将达成的锚点充能、下回合死亡的构件）使用**强视觉脉动**，背景信息（远处单位的轨迹）使用**静态线条**

> **设计哲学**：完美信息不是"信息少 + 可切换补全"，而是"信息全 + 视觉过滤"。玩家的认知负担应通过**视觉设计**减轻，不是通过**藏起来再切换**。

#### 2.5.4 撤销契约 (Undo Contract — ITB 风格)

参照 Into the Breach 的"移动可撤销，攻击不可"原则——给玩家**安全实验空间**而不破坏完美信息推演的紧凑感。

##### 撤销规则

*   **构件移动后未行为前** → **可撤销**：玩家点了构件移动到 X 格，但还没点近战 / 远程 / 法则操作 → 可点"撤销移动"按钮 → 构件回到原位，本回合该构件移动力恢复
*   **行为阶段一旦开始** → **不可撤销**：玩家选定攻击目标 / 远程方向 / 卡牌目标后点"确认"瞬间，整个动作（移动 + 行为）原子提交，不可逆
*   **目标选择阶段（点确认前）** → **可取消**：选攻击方向 / 远程目标 / 卡牌目标的过程中，可按 Esc 或右键取消，回到"已移动但未行为"状态——此时仍可撤销移动
*   **行为后回到移动**？❌ 不允许。一旦执行行为，本构件本回合行动结束（除非有"恢复行动权"特例如棱镜近战）。棱镜近战触发的"恢复 1 行动权"产生**新的行动槽**，新槽内的移动同样可在攻击前撤销
*   **跨构件不可撤销**：构件 A 完整结算后再操作构件 B → A 的行动**不可回溯**，只能撤销 B 的当前未提交移动
*   **卡牌动词**：选定卡牌后选目标的过程可取消；点击"确认释放"后不可撤销
*   **R0 部署**：部署期间所有构件位置可自由调整（移动 / 删除重放）→ 点"开战"按钮才锁定。R0 撤销空间最大

##### UX 表现

*   构件移动到位但未行为时，构件原位**保留半透明残影**（青色幽灵），表示"可撤销回到这里"
*   屏幕角落出现**「↶ 撤销移动」按钮**（快捷键 Z），仅在可撤销状态时亮起
*   攻击 / 远程瞄准 UI 中显示**「✗ 取消」按钮**（快捷键 Esc / 右键），随时可放弃当前目标选择
*   一旦执行不可逆行为（攻击 / 卡牌释放），残影立即消散——视觉上给玩家"决策已落地"的明确反馈

> **设计意图**：完美信息游戏需要"实验自由"。玩家可以"先移到 X 看看连锁预演 → 觉得不好 → 撤销移到 Y"。但攻击锁定瞬间承诺——这保留物理三定律的精算稳定，不允许"试错式爆炸"。这与 ITB 的撤销机制完全对齐。

#### 2.5.5 目标 HUD 与关卡三星目标 (Mission Objectives — ITB 三星风格)

参照 Into the Breach 的关卡三目标系统——**主目标 + 次目标 + 可选挑战**——给玩家清晰的"什么算胜利"和"什么算炫技"。

##### 屏幕固定目标 HUD

屏幕**顶部正中**始终显示当前战斗的目标进度：

```
[⭐ 撑过 5 回合] R3/5    [⭐ 0 锚点完成] 0/3    [⭐ 挑战：零阵亡] 4 构件存活
```

- 三颗星目标始终可见，不需要切换 / 悬停
- 已完成的星变金色 + 脉动；进行中的灰色；失败的灰色 + 划线
- 鼠标悬停某颗星 → 浮窗显示详细规则与当前进度

##### 三星目标设计

每场战斗 3 颗星，按 ITB 哲学分层：

| 星 | 类型 | MVP 默认规则 | 设计意图 |
|---|---|---|---|
| ⭐ **主目标**（必达） | 撑过 5 回合 | 5 回合结束时构件 ≥ 1 台存活 + 仪式完成度 < 阈值 | 基础胜利条件，不达则单场失败 |
| ⭐ **次目标**（高分） | 完美防守 | 5 回合结束时仪式完成度 = 0（**0 锚点完成**）| 主目标的"高质量版本"——给精算玩家额外回报 |
| ⭐ **可选挑战**（每场不同） | 战前简报指定 | 见下表 | 给重玩者新目标，避免每场感觉重复 |

##### 可选挑战池（每场战前简报指定 1 个）

| 挑战名 | 规则 | 触发场景 |
|---|---|---|
| **零阵亡** | 5 回合结束时 4 台构件全存活 | 默认低难度战斗 |
| **送渊大师** | 累计推 ≥ 3 敌人入深渊 | 含深渊边缘的地图 |
| **拆墙工** | 击碎 ≥ 2 块晶柱 | 含 2+ 晶柱的地图 |
| **裂口压制者** | 累计压制 ≥ 5 次裂口（含被推敌人压制） | 裂口密集战斗 |
| **连锁艺术** | 单回合内触发 ≥ 4 段物理连锁 | 高难度精英战 |
| **一击毙命** | 单次攻击触发 ≥ 3 敌死亡 | Boss 战或精英战 |
| **节俭** | 整场战斗不释放任何法则卡 | 默认 |
| **法则风暴** | 整场战斗释放全部 3 张法则卡 | 默认 |

##### 三星奖励

战后结算按完成的星数给奖励（叠加）：

- 1 ⭐（仅主目标）：基础奖励
- 2 ⭐（主 + 次）：额外 +5 灵能
- 3 ⭐（主 + 次 + 挑战）：额外 +10 灵能 + Demo 阶段战间奖励 3 选 1 池**多 1 个候选**（4 选 1）

##### 实施优先级

- **MVP 必做**：星 1（撑过 5 回合）+ 星 2（0 锚点完成）+ 星 3（仅 1~2 个固定挑战，如"零阵亡"和"送渊大师"轮换）
- **1.0 扩展**：完整挑战池 8 种 + 每张入侵者卡指定专属挑战 + 全 Run 三星累计统计（"本 Run 已得 12 颗星"）

> **设计意图**：完美信息游戏中，目标 HUD 不仅是"提醒玩家在干嘛"，更是**自定义难度阶梯**——休闲玩家追求 1 ⭐，硬核玩家追逐 3 ⭐。三星目标也是 ITB 的核心保留——给一次通关后再回头打"全三星"的明确动力。

### 2.6 仪式锚点：敌方目标与失败核心 (Ritual Nodes)

仪式锚点是棋盘上若干个固定的"召唤终点"，所有非特殊敌人朝最近未饱和锚点行进。锚点完成 = 仪式完成度 +1；累计达阈值即单场失败。

#### 2.6.1 锚点基本属性

| 属性 | 值 | 说明 |
|---|---|---|
| **充能阈值** | 3 | 锚点累计充能 ≥ 3 即完成（简单计数：敌人在锚点上每回合 +1） |
| **占位** | 否 | 锚点是地面标记，不阻挡寻路；单位可踩上去 |
| **HP** | 不可破坏 | 锚点本身是法则结构，玩家不能直接攻击销毁 |
| **可见性** | 整局可见 | 锚点位置在战斗开始时确定，整场战斗存在 |

#### 2.6.2 锚点的位置生成（Roguelike 友好）

*   **MVP 阶段数量**：每场战斗激活**恰好 3 个锚点**（固定，**不浮动**）
*   **MVP 阶段失败阈值**：完成 **3 个** 锚点 → 仪式饱和 → 单场失败（完成度 / 阈值 = 1:1）
*   **生成方式**：
    1.  棋盘预设 **8~12 个候选锚点位置**（手工设计的"战术兴趣点"——通常邻近深渊边缘、棋盘几何重心或战略位置）
    2.  每场战斗**随机激活其中 3 个**
    3.  约束：被激活的锚点之间**曼哈顿距离 ≥ 4 格**，避免集中防守的退化解
*   **1.0 后扩展方向**：浮动 3~5 锚点 + 阈值随难度调整（如精英战 = 4 锚点 / 阈值 4，Boss 战 = 5 锚点 / 阈值 5）。MVP 阶段锁定 3 简化平衡空间。
*   **设计哲学**：棋盘是手工设计的，激活模式是程序化的——这是 Into the Breach 验证过的"半程序化关卡"经典做法

#### 2.6.3 锚点充能机制

*   **触发**：任何**敌人**站在锚点格子上时（无论"主动走到"还是"被推到"），在**第 4 步锚点结算阶段**触发：
    *   敌人在锚点上 → 锚点充能 +1（每回合 +1，**简单计数**，不区分敌人质量）
    *   敌人**留在锚点上**持续充能：下回合若仍在锚点 → 再次 +1
*   **饱和**：锚点充能 ≥ 3 → 锚点**完成**：
    *   锚点上所有敌人**湮灭消散**（视觉上一道洋红色冲击波）
    *   锚点光柱**熄灭**（视觉上崩解，留下黑色凹陷的"仪式痕迹"）
    *   仪式完成度 **+1**
    *   该锚点**不再作为敌人寻路目标**，敌人转向其他未饱和锚点
*   **失败**：仪式完成度 ≥ 阈值 → 战斗失败（按 §2.1.1 扣 Sanctuary Integrity）

> **设计选择**：选择"简单计数 +1"而非"按质量加权 +M"。理由：阈值=3 + 计数+1 = 玩家心智成本最低（数到 3 就完了）。**所有敌人到达锚点都是 +1**——统一规则避免特殊计数的心智负担，1.0 后扩展敌人时此规则同样适用。

#### 2.6.4 玩家干预手段（基于现有机制）

锚点机制本身**不引入新动词**，而是让现有机制有了新意义：

*   **近战攻击推开**：用棱镜近战攻击把敌人撞离锚点路径——套用 §2.3 三定律。最经典的就是把敌人**撞入深渊**，既是击杀掠夺奖励，又彻底消除一个仪式威胁。
*   **折镜半透传送门**：在锚点附近部署折镜（§3.1.1）→ 折镜阻挡敌人寻路（必须绕开多消耗回合）+ 玩家用拉钩 / 炮手 / 卡牌把敌人推入折镜后从朝向方喷出（甚至传送进深渊）
*   **拉钩远程拉攻击**：从远处把敌人拉离锚点路径 / 拉到折镜前等待传送 / 拉到自己面前集中处理；新规则下友军不可穿透，射线净空时是位置整理利器。
*   **炮手远程推攻击**：从远处把锚点上的敌人直接推开 / 推下深渊 / 推到折镜前 → 配合折镜送渊；4 方向直线 3 格射程，对锚点防线是关键远程压制工具。
*   **推力卡牌远程推**（《脉冲推送》《强力推送》）：从远处把敌人推离锚点 / 推进深渊 / 推到折镜前——一次性消耗，零物理代价的位置控制（卡牌不受射线净空约束）。
*   **占位拦截**：玩家构件**站在锚点上**时——
    *   敌人到达锚点格 → 触发 §2.3 三定律碰撞结算（敌人 vs 构件）
    *   构件被推开 → 锚点暴露 → 敌人下回合可能再次到达
    *   构件挡住但被磨血 → 持续防守的代价
    *   **关键**：占位防御不是免费——构件吃伤害+被推开，且若被推入深渊则**本场永久离场**（下场战斗才能重新部署）
*   **裂口压制**：从源头延缓敌人涌入（§2.2）→ 延缓锚点充能压力。注意新规则下压制是"持续付费阻塞"而非"一次性永久消除"——你需要权衡"花 X 回合 X HP 换 X 回合不出怪"是否值得
*   **法则卡牌**：未来扩展可设计专属卡牌（如《暂封锚点》《扭曲引力》），MVP 阶段不强制添加

#### 2.6.5 锚点的视觉表现

*   **未饱和锚点**：地面深紫色发光圆盘（直径 ≈ 1 格），中央悬浮一个**倒立的青色四面体**，缓慢自旋
*   **充能进度**：四面体下方涌出洋红色能量柱，高度 = `充能值 / 阈值`（1/3 矮、2/3 半、3/3 满）
*   **接近完成 (2/3)**：能量柱顶部破裂，溢出洋红色雾气，棋盘整体微震
*   **完成瞬间 (3/3)**：四面体逆时针炸裂，留下黑色凹陷"仪式痕迹"（永久视觉占位，提醒玩家"这里输过一次"）
*   **与裂口区分**：裂口 = 洋红色波纹（短期、地面波动）；锚点 = 深紫色光柱（长期、垂直发光）

#### 2.6.6 全局仪式进度 UI

屏幕顶部显示一个**仪式条**：

*   "仪式完成度：1/3"
*   每完成 1 个锚点 → 屏幕边缘脉动一次红色警报，BGM 音色变浑浊
*   完成 (N-1)/N → BGM 加速，屏幕震动加剧
*   完成 N/N → 本场战斗结束动画，进入 §2.1.1 圣所完整度结算

## 3. 单位与养成系统 (Squad & Progression)

### 3.1 战术棋子：秩序构件 (Order Constructs)

玩家控制的单位定名为 **"秩序构件"**（视觉上表现为具备清晰切面的发光几何实体，代表圣所的防御具象化）。它们是战场上持久存在的实体棋子，拥有独立生命值。

*   **构件池与出战上限**：
    *   *Run 级构件池*：玩家通过 Run 进展（虚空商店购买 / 法则井抽取 / 牺牲事件等）持续获得构件。构件池**没有数量上限**——你拥有的所有构件都属于这个 Run 的资源
    *   *单场出战编制*：每场战斗在 R0 部署相**强制选定 4 台构件**入场（详见 §2.1.2）。**超过 4 台的构件本场不能上场**；阵亡 / 撤回后**不可补援**——4 台是本场全部预算

*   **R0 强制部署 (Mandatory Pre-Combat Deployment)**：
    *   *战斗开局即进入 R0*：棋盘上**没有玩家构件**也**没有敌人**——仅锚点、裂口、地形可见。R0 是"信息盲区中的位置承诺"
    *   *必须满 4 台才能开战*：从 Run 池中选 4 台构件（允许重复，详见下方"纯自由组队"）依次放入棋盘**边缘 2 格内**的空格。**禁止放在晶柱占据的格**（晶柱不可踏）；锚点 / 裂口是地面标记不阻挡占位，可以放在上面（但裂口下回合会触发压制结算 → 构件 -1 HP）。**少于 4 台时无法进入 R1**
    *   *部署位置*：必须选**棋盘边缘 2 格内**的空格（与"虚空裂口"对应的世界观——构件从盘外飞入）
    *   *折镜朝向自动指向中心*：法则机关型构件部署时**朝向自动设为指向棋盘几何中心**的 4 方向之一（详见 §2.4.6 中心朝向规则）。R0 期间不允许调朝向 —— 朝向调整属于 R1 起的"行为阶段"动词
    *   *部署是免费动作*：不消耗任何资源（不消耗灵能 / 行动权 / 卡牌）
    *   *部署完成 → 进入 R1*：玩家点"开战"按钮 → 棋盘敌人首次刷新与首次预警**同步**揭晓 → R1 敌方预警阶段正式开始

> **R0 设计意图**：把"构件选择 + 位置承诺"从 R1+ 的动态决策**收缩为开战前一次性敲定**。这与 Into the Breach 流派的"任务前 squad lock"哲学对齐——开战即固定，承担位置决策的全部责任。同时保留你的"虚空召唤"世界观（构件从盘外飞入边缘 2 格内），不需要 ITB 风格的"任务前 loadout 屏幕"，部署相直接放在棋盘上完成。
>
> **天然反龟缩**：R0 强制满 4 台 + R1+ 不可补援，**根本上消除了"龟到 R5 再出兵"的退化解**——你的 4 台必须在 R1 就全部承担棋盘空间。原"反龟缩约束"论述（依赖锚点充能/裂口压力作为间接惩罚）不再需要——R0 强制部署是更优雅的结构性约束。

*   **战斗内死亡规则**：
    *   *本场永久离场*：构件 HP 归零或坠渊 → 碎裂消失，**本场战斗内无法补充**（出战上限已在 R0 用完，4 台是固定预算）
    *   *消失即真消失*：HP 归零的构件**立即从棋盘移除**（不留残骸、不占格、不阻挡寻路）
    *   *主动撤回 (Manual Recall)*：玩家可主动撤回场上构件，**消耗当回合行动权 + 该构件本场永久离场不可补援**——本质是"提前让构件离场"，避免被击毁前留全 HP，同时主动让出位置；但代价高昂，因为不存在"补援空缺"——撤回 = 永久减员到 3 台

*   **跨战斗满血归位**：每场战斗结束后，所有构件（包括本场离场/阵亡的）**满血回到 Run 池**。下场战斗 R0 部署时又可从满血 Run 池中重新选 4 台。**Run 级损失只通过"圣所完整度（§2.1.1）"承担**，构件本身不跨场惩罚——这保证每场战斗的"R0 部署选择"是聚焦本场入侵预告的纯战术决策

*   **构件两大类**：

    **攻击型 (Attackers)** —— 主要职责是输出伤害与位移
    *   **冲撞子类 Strikers**：实体棋子，可移动可近战攻击，套用 §2.3 三定律。MVP 代表：棱镜。是棋盘上的"力"。
    *   **远程子类 Shooters**：实体棋子，可移动 + 远程推攻击（4 方向直线扫描射程 3，友军不可穿透）。MVP 代表：炮手。是棋盘上的"远程发射器"。
    *   *[1.0 后扩展]* 重型子类 Heavies（楔块）、远程狙击子类 Snipers（观测者，蓄力 + F=3 高威力）

    **功能型 (Utilities)** —— 主要职责是位置控制与法则改造
    *   **法则机关子类 Rulers**：实体机关，M=∞ 不可被外力推动但可主动移动；**HP=3，可被近战 / AOE / 连锁动量伤害（远程攻击免疫被折射）**；近战命中改朝向 + 扣 1 HP；HP 归零碎裂本场永久离场；提供"传送门"机制（任何穿过的单位从机关朝向方喷出）。MVP 代表：折镜。是棋盘的"物理引擎"。
    *   **拉力子类 Grapplers**：实体棋子，可移动 + 远程拉攻击（4 方向直线扫描射程 3，友军不可穿透）。提供"远程位置控制（把目标拉到自己面前）"。MVP 代表：拉钩。1.0 后补回敌方钩锁时形成镜像博弈（详见附录 A.5）。
    *   *[1.0 后扩展]* 其他法则机关变体（锚点型、召唤型）

*   **纯自由组队**：每局自由选择 4 台构件出战，**无任何类别强制约束**——可以 4 棱镜 / 3 棱镜 + 1 折镜 / 2 棱镜 + 1 折镜 + 1 拉钩 + 1 炮手等任意搭配。

*   **差异化路线**：游戏共设计 **8 种构件**（MVP 阶段先实现 **4 种**：1 近战攻击 + 1 远程攻击 + 1 法则 + 1 拉力，玩家出战 4 台允许重复）。每个构件专精一个维度，**没有全能单位**——这是战术组合深度的根基。

*   **战术核心**：与拉钩互补——拉钩负责"把远处敌人拉过来集中处理"，炮手负责"把眼前的敌人推出去送渊 / 触发连锁"；与折镜组合则是"对折镜开火 → 折射动量沿折镜朝向方推送另一格的目标"

*   **远程拉攻击**（**F=1**）：1 伤 + P=1 朝拉钩方向击退动量；连锁仅在目标的下一格有第三方时触发
*   **方向性扫描 · 友军不可穿透**：玩家选 4 方向之一，沿线第一个单位（敌 / 友 / 折镜 / 障碍）强制锁定，无法跳过

*   **不卷入碰撞结算**：拉钩自身不被弹回、不掉血；攻击效果（1 伤 + 击退）结算完毕后即停

##### 功能型 · 法则机关子类（1 个）

| 构件 | M | F | HP | 移动 | 攻击范围 | 法则规则 | 战术定位 |
|---|---|---|---|---|---|---|---|
| **折镜 Refractor** | ∞ | — | 3 | 2 | 无主动攻击（仅折射他人动量）| **半透传送门**：主动移动**不能进入**（占位阻挡寻路）；**被推递动量进入**则从折镜朝向方喷出（保留剩余动量）；**远程攻击免疫，被折射朝折镜朝向方推送**；近战/AOE 攻击 -1 HP + 改朝向 | 棋盘的物理引擎 + 路径阻断器。把动量"折叠"到目标位置——典型连锁是"拉钩拉敌人到折镜前 → 敌人撞入折镜被动量推入 → 从折镜朝向方喷出（往往朝深渊或朝其他敌人撞击连锁）"|

**折镜完整规则**（详见 §2.4.6）：

*   **半透传送门机制**：
    *   主动移动 → **不能进入**（玩家与敌人 A\* 寻路均把折镜视为不可通过节点；详见 §2.4.3.3）
    *   被推 / 被拉 / 三定律连锁动量传导进入 → 从折镜朝向方喷出，保留剩余动量
    *   单位在折镜朝向方"喷出"时**不停在折镜内**——必须从邻接格出来
    *   若朝向方格被堵塞 → 视为撞墙判定（详见 §2.3.1 分支 f）
*   **完全阻挡寻路**：与晶柱在阻挡角度一致（HP 不同 + 朝向作用不同）
*   **HP=3，选择性免疫**：
    *   **近战攻击命中折镜**（玩家用棱镜或敌方近战）→ 折镜 -1 HP + 朝向变为攻击来源反方向（攻击者按以卵击石套规则：原地不动）
    *   **AOE 攻击命中折镜**（1.0 后激活）→ 折镜按 AOE 数值 -N HP + 朝向变为攻击合力反方向（如自爆体 3 伤 AOE → 折镜 HP -3 → 立即碎裂）
    *   **远程攻击命中折镜**（拉钩 / 炮手 / 推力卡牌）→ 折镜**不掉血、不变朝向、不动**，攻击动量被折射朝折镜朝向方重新发射（详见 §2.4.5.8）
    *   **被推动量进入折镜**→ 视为"使用半透传送门"，不是"攻击折镜"，不掉 HP
*   **HP 归零**：折镜碎裂，本场永久离场（下场战斗满血归位）
*   **被攻击改朝向规则**：
    *   棱镜从北方近战攻击折镜 → 折镜朝向变为南，HP -1（玩家可借此快速调整朝向，但消耗折镜 HP）
    *   敌人从北方近战撞折镜 → 同上规则（朝向变南、HP -1）
    *   AOE 攻击 → 朝向变为"攻击合力的反方向"（MVP 阶段无 AOE，1.0 后细化）
*   **敌人 AI 与折镜**：折镜阻挡寻路 → 敌人 A\* 必须绕开折镜，与晶柱处理一致。**敌人不主动攻击折镜**（与晶柱一致，详见 §5.0）。MVP 阶段折镜**几乎不会被敌人攻击**——除非冲锋者直线冲刺路径上有折镜完全堵死，但 AI 会预先重选路径避开。"近战攻击折镜改朝向"机制主要由**玩家自己的棱镜**触发（作为快速重定向工具，但要承担 HP 消耗代价）
*   **M=∞ + 主动移动力 = 2**：折镜免疫一切外力位移（推/拉/连锁动量传导），但每回合可主动移动 2 格调整传送门阵型
    *   主动移动遵循 A\* 寻路——折镜不能穿过其他单位 / 晶柱 / 折镜 / 深渊
*   **行为阶段动作**：可选"调整朝向"（4 方向之一）或"主动撤回"（按 §3.1，撤回后本场永久离场）
*   **主动撤回**：可按 §3.1 主动撤回——撤回后构件本场永久离场，不可重新部署
*   **战术核心**：用折镜"路径阻断 + 半透传送 + 折射"三合一——
    *   *路径阻断*：折镜放在锚点附近 → 敌人必须绕路 → 多消耗 1-2 回合
    *   *半透传送*：拉钩拉敌人到折镜前 → 敌人撞入被动量推入 → 从朝向方喷出（往往送深渊或撞另一敌人连锁）
    *   *远程折射*：炮手对折镜开火 → 沿朝向方推送另一格目标 → 远距离触发连锁
    *   折镜本身不输出，但是连锁的**结构骨架**。每回合可挪 2 格让玩家**渐进式调整传送阵型**，但仍慢于棱镜（3）—— 棋盘是动态的法则结构而非静态布局
*   **新规则下的设计哲学**：旧规则"折镜不阻挡寻路"导致敌人能借折镜当电梯（双刃剑），新规则**折镜只对玩家有利**——阻挡敌寻路 + 仅被动量传送（玩家可控）+ 折射机关。折镜回归"工程师工具"角色

**数值平衡原则**：

*   构件升华**只解锁动词 / 动作变体**，**不改 HP / M / 移动力 / 伤害**——保护物理三定律的精算稳定（详见 §3.3）
*   折镜的传送朝向 R0 部署时按"中心朝向规则"自动设定（详见 §2.4.6），R1+ 可通过行为阶段调整；升华路线可解锁"3 向喷出"/"同回合可重新设朝向"等**动词扩展**分支
*   每个构件都有明确的"克星场景"（详见 §5 敌人矩阵）——玩家必须根据本局敌人类型选择带谁
*   构件总数将扩展到 8 种，其余 4 种延后至 1.0 后内容（方向预留：楔块、观测者、召唤型、回响）。注：原计划的"推进器 Booster（远程推力）"在 MVP 阶段已落地为**炮手 Cannoneer**

### 3.2 法则系统：双轨制 (Law System: Dual Track)

#### 3.2.1 法则双轨：构件 vs 卡牌

法则覆写（Law Override）有两种载体并行存在：

**轨道 A — 法则型构件（持久轨）**：

*   实体棋子，占战斗出战槽位（出战 4 台之一）
*   永久存在直到被破坏（除非主动撤回）
*   可调整朝向 / 参数
*   代表：折镜（传送门）；扩展方向：锚点、拉扯型、召唤型（1.0 后）

**轨道 B — 法则卡牌（卡组直接可用）**：

*   不占战斗出战槽位，归 Run 级"卡组"管理
*   **卡组容量上限 = 3 张**（MVP 阶段固定，未来可能引入升级机制）
*   **Run 开始时**：玩家获得 3 张基础法则卡（默认入组：《脉冲推送》《拉扯》《临时传送场》各 1 张），卡组直接处于满编状态
*   战斗内**所有 3 张卡都可用**——不需要"战前选 2 张带组进场"
*   每张卡每场战斗**限施放 1 次**（战斗结束自动恢复，下场又是 3 张可用）
*   战斗外通过**法则井**（免费抽）或**法则裂痕**（事件随机）扩充——满编时抽到新卡需弃 1 张旧卡换入

**两轨道的资源经济差异**：

| 维度 | 法则型构件（持久轨） | 法则卡牌（卡组轨） |
|---|---|---|
| **占用槽位** | 战斗出战槽位（4 选 1） | Run 级卡组（容量 3） |
| **持续时间** | 永久（除非被破坏） | 一次性 / 几回合 |
| **可调整** | 撤回 / 调朝向 | 不可调（施放即生效） |
| **战略价值** | 整 Run 持久压舱石 | 灵活临场反应 |
| **决策时机** | Run 池积累 + 战前选 4 台 | 战中临场（每场 3 张全部可用） |
| **施放次数** | 部署后持续生效 | 每张每场 1 次 |

**核心哲学**：法则型构件 = 永久版的卡牌（高承诺、高回报）；卡牌 = 临时版的法则（灵活、随手可用）。两者在战略层（Run 池积累）与战术层（每场临场施放）形成互补。卡组容量 3 是有意的稀缺——逼迫玩家做"卡组管理"的 Run 级决策（拿到第 4 张时必须弃 1 张），但战斗内不再增加心智负担。

#### 3.2.2 卡牌三大类

**类一：地块法则卡** —— 在指定地块生成短期生效的法则区域：

*   *《临时传送场》*：选 1 格地块，3 回合内具备传送门能力（任何走入该格的单位从指定朝向方喷出，朝向出牌时确定）
*   *《无摩擦地带》*：选 3 格地块，2 回合内单位经过不消耗动量
*   *《引力反转区》*：选 1 格地块，1 回合内任何接近的敌人被弹开 1 格
*   *《虚空印记》*：选 1 格非边缘地块，2 回合内变成"虚空格"——单位踩上去坠渊判定

**类二：法则覆写卡** —— 临时修改物理法则：

*   *《质量置换》*：将两个单位的质量互相交换 1 回合
*   *《绝对动能》*：下一次推力判定时无视目标质量
*   *《零摩擦领域》*：使一个单位滑动时不再消耗动量（直到撞墙或坠渊）

**类三：推/拉动词卡（高阶推力）** —— 远程施力（卡牌全图选目标，不需要直线扫描，目标默认为敌人）：

*   *《脉冲推送》*：选择**任意位置**的一个敌人施加 **F=1 远程推攻击**（1 伤 + P=1 远离施加方向击退）；施加者不位移、不掉血；按 §2.4.5 规则结算（含连锁）
*   *《拉扯》*：选择**任意位置**的一个敌人施加 **F=1 远程拉攻击**（1 伤 + P=1 朝施加方向拉）；与拉钩构件的射程差异——拉钩仅 3 格直线（友军不可穿透），本卡覆盖全图
*   *《强力推送》*（稀有）：施加 **F=2 远程推攻击**（1 伤 + P=2 击退）；按 §2.4.5 规则结算
*   *《传送带轨道》*（稀有）：临时铺设 1 回合的传送带，区域内动量沿朝向额外延长 1 格

**推/拉力工具的层次区分**：

| 工具 | 方向 | 射程 | 力强度 | 触发连锁 | 资源代价 | 战术定位 |
|---|---|---|---|---|---|---|
| 拉钩构件 | 拉（朝施加方）| 直线 4 方向 3 格（**友军不可穿透**）| **F=1** | ✅ | 占小队槽位 | "基础拉力"——把敌人拉到自己面前集中处理 |
| 炮手构件 | 推（远离施加方）| 直线 4 方向 3 格（**友军不可穿透**）| **F=1** | ✅ | 占小队槽位 | "基础远程送渊器"——直线推走第一目标 |
| 《脉冲推送》卡 | 推（远离施加方）| 全图（指定敌人）| **F=1** | ✅ | 占卡组槽位（每场限施放 1 次）| 关键时刻的"远程送渊救场" |
| 《强力推送》卡 | 推 | 全图（指定敌人）| **F=2** | ✅ | 稀有卡（每场限施放 1 次）| 一次性高威力推力 |
| 《拉扯》卡 | 拉 | 全图（指定敌人）| **F=1** | ✅ | 占卡组槽位（每场限施放 1 次）| 关键时刻的"远程位置控制" |
| 近战攻击（棱镜）| 推（远离施加方）| 相邻 1 格 | P=F_self | ✅ | 1 伤 + 攻击方原地不动 | 默认近战工具，无位置代价但需相邻 |

**推 vs 拉的核心战术差异**：

*   **推**（炮手 + 卡牌池）→ 把目标**远离施加方**送向深渊 / 障碍 → 主打**杀伤与送渊**
*   **拉**（拉钩 + 卡牌）→ 把目标**靠近施加方** → 主打**位置整理**：拉敌人到折镜 / 裂口 / 自己面前集中处理
*   **近战攻击** → 推的近距离版本 → 1 伤 + P=F_self 击退；MVP 棱镜 F=1 时所有 M≥2 单位均以卵击石（棱镜原地不动 + 敌人 -1），1.0 后楔块 F=3 可与重型敌人等价交换互推

#### 3.2.3 灵能资源系统

战斗内击杀掠夺的"灵能"是 Run 级核心资源——但**不直接用来买卡牌**（卡牌靠免费的法则井获取，详见 §3.5）。灵能的主要用途是**永久增益类投资**。

**战斗内**：

*   **任何敌人死亡都给玩家灵能**（统一归因，避免规则歧义）：
    *   击杀方式不限——近战 / 远程 / 撞墙 / 撞晶柱 / 坠渊 / 裂口压制致死 / 锚点完成湮灭 / 敌人误伤友军 / 自爆体爆炸 / 折镜折射动量致死，均给玩家灵能
    *   **理由**：玩家在战场上，所有敌人死亡都是玩家行动 / 布局的间接结果——简化经济规则，避免"压制致死不给灵能 → 玩家不愿主动堵裂口"的反激励
    *   **例外**：仅"敌人在锚点完成时被湮灭"按击杀算（虽然锚点是失败标志，但被湮灭的敌人给灵能作为安慰奖）
*   屏幕上有计数器实时显示灵能数（视觉上是悬浮的青色光点环绕玩家阵营）
*   不同敌人击杀给不同灵能：炮灰 1，射手 1，冲锋者 2，精英 5，Boss 10（具体数值待平衡）
*   **战斗内不抽卡，不消耗灵能**——只是累积

**战斗结束**：

*   灵能点数带入"法则牌桌"结算（详见 §3.5）
*   不同战斗结束时灵能不刷新——**Run 内可累积**

**灵能的主要用途**：

*   🔧 **构件升华**：在虚空商店用灵能解锁构件的"动词扩展"（详见 §3.3.2）
*   💎 **遗物购买**：全局被动法则修改（详见 §3.3.1）
*   ❤️ **圣所修复（主修复路径）**：在虚空商店用 **3 灵能 = +1 圣所完整度**（详见 §3.5.3 商店货架）。这是**主修复路径**，强调"修复 vs 升华 vs 遗物"的灵能三头权衡
*   🎲 **重抽桌面**：消耗 1 灵能舍弃 1 张桌面行动卡（详见 §3.5.4）

**灵能不用于**：
*   ❌ 购买法则卡牌（改为通过法则井 / 法则裂痕事件免费获得）
*   ❌ 提升卡组容量（MVP 固定 3 张，1.0 后可考虑容量升级）

**设计哲学**：

*   战斗内击杀有**即时反馈**（看到数字涨）—— 保留"击杀掠夺"的爽感
*   资源结算延迟到战斗外 —— 不打断战斗节奏
*   灵能 = "**永久投资资源**"（升华 / 遗物 / **修复**）；卡牌 = "**Run 级机会资源**"（法则井免费抽）—— 两者经济独立、互补
*   修复主路径定为**付费 (灵能)**——免费"秩序修复"行动卡仅 +1（小额免费补给），**避免免费修复 +2/+3 让灵能囤积失去意义**（详见 §3.4.3 行动卡六大类）

### 3.3 局内成长 (Roguelike Upgrade Loop)

成长奖励通过"法则牌桌"获得（详见 §3.5），不是每场战斗后"3 选 1"。

#### 3.3.1 四类局内成长资源

通过法则牌桌的"🏪 虚空商店"、"🎴 法则井"、"⚠️ 精英入侵"奖励等行动卡获得：

1.  **构件升华 (Ascension)** —— **只解锁动词，不改数值**
2.  **法则扩充 (Law Expansion)** —— 获得新的法则卡牌入卡组
3.  **圣所遗物 (Relics)** —— 全局被动法则修改
4.  **不稳定接入 (Unstable Integration)** —— 双刃剑式强力构件

#### 3.3.2 构件升华的"动词扩展"哲学

升华**只解锁新动作 / 动作变体，不改基础数值**。

**正确的升华案例**：

*   棱镜 → 升华路线示例：
    *   "近战攻击后转向 90°"（动词扩展，原本只能直线攻击）
    *   "撞墙不受 1 伤"（动词例外，原本必受撞墙伤害）
    *   "近战攻击后追加移动 1 格"（动词链，让"恢复行动权"特例更灵活）
    *   "重型对抗"——撞 M=3 单位时仍可推动 1 格（动词例外，突破"以卵击石不推目标"限制）
*   折镜 → 解锁"对角线传送"（朝向不再限于 4 方向）/"被攻击不改朝向"（朝向锁定，免受敌人扰动）/"双向传送门"（朝向方和反方向都可作为出口）等动词参数化
*   拉钩 → 升华路线示例：
    *   "对角线拉力"——可拉 8 方向而非仅 4 方向（动词扩展）
    *   "穿透拉力"——拉力锁定的目标越过第一格继续滑（动词链，仍是 P=1 等价于滑 2 格）
    *   "拉后追加移动"——拉力施放后拉钩自身可再移动 1 格（动词链）
    *   "推送模式"——可选拉方向反转为"推"（动词扩展，但仍是 P=1，且不再有"拉到拉钩相邻格"的特殊语义）
    *   "群体拉力"——同方向同时拉锁定目标 + 其相邻一个友军（动词扩展，专攻援护）

**禁止的升华形态**：

*   ❌ "棱镜 HP +1" / "拉钩 M +1" / "折镜获得 HP" 等数值或属性扩展
*   ❌ "重型化"（修改 M 类别）
*   ❌ "高速化"（修改移动力）
*   ❌ "拉力 1 → 拉力 2"——拉钩尤其不能破例

**设计动机**：

*   保护物理三定律的精算稳定性 —— 玩家任何时刻都能精确算出三定律分支
*   "build 多样性"来自动词组合的爆炸（指数级），而不是数值堆叠（线性）

#### 3.3.3 不稳定接入 (Unstable Integration)

*   **机制**：在牌桌中遇到"⚠️ 精英入侵"或"🌀 法则裂痕"事件后，可选择**接受一个带副作用的强力构件**入队，占用第 4 槽
*   **副作用示例**：
    *   每回合自动流失 1 HP（直到坠渊或被击毁）
    *   自带负面光环（半径 2 格内的友方构件 -1 移动）
    *   与玩家阵营颜色不同的视觉标记（提醒它的"不稳定性"）
*   **强力性**：作为代价的回报，不稳定构件具有**独特动词**——例如"远程攻击 2 格"、"献祭自身换全场清屏"等普通构件没有的能力
*   **设计哲学**：双刃剑选择 = Roguelike 的"高风险高回报"经典张力

### 3.4 法则牌桌 (Law Hand) — Run 级结构

完全替代传统肉鸽节点图。整个 Run 是一张悬浮在虚空中的"法则牌桌"——玩家从行动卡牌堆中选择"机会卡"执行，自主构筑 Run 的节奏与方向。

> **MVP / Demo 范围说明**：完整法则牌桌（§3.4.1~§3.4.7）是 1.0 正式版结构。**Demo 阶段使用 §3.4.0「线性简版运行」** 跳过牌桌系统，以确保战斗核心循环先被验证。Demo 不实现牌桌、舍弃、桌面刷新、Run 池构件解锁等机制。

#### 3.4.0 Demo 阶段：线性简版运行结构 (Demo Linear Run)

Demo 阶段砍掉法则牌桌的卡牌构筑层，用**线性 3-5 场战斗 + 战间 3 选 1 奖励**的传统肉鸽结构验证战斗体验。

##### 结构

```
Run 开始
  ↓
固定教学战 × 1（暂缓实现，详见正式版规划）
  ↓
普通战斗 1 → 战间奖励（3 选 1）
  ↓
普通战斗 2 → 战间奖励（3 选 1）
  ↓
精英战斗 1 → 战间奖励（3 选 1，必出遗物 / 大额灵能）
  ↓
普通战斗 3 → 战间奖励（3 选 1）
  ↓
终极仪式 Boss 战
  ↓
Run 结算（胜利 / 失败）
```

- **战斗总数固定 5 场**：4 场普通 + 1 场 Boss（精英战是其中一场普通战的"高难度变体"）
- **战间奖励 3 选 1**：每场战斗胜利后弹出奖励选择面板，从 3 个候选中选 1 个：
    - 类型 A：法则卡牌（满编时弃 1 换 1）
    - 类型 B：构件升华（解锁动词扩展）
    - 类型 C：遗物（全局被动）
    - 类型 D：圣所修复 +1（不消耗灵能）
    - 类型 E：灵能 +5（小额收入）
- **精英战奖励**：3 选 1 中**必含 1 个遗物 + 1 个大额灵能 +10**，第三个随机
- **没有"舍弃 / 重抽 / 多路径选择"**——线性推进，无分支

##### Run 经济（简化）

- **圣所完整度**：仍是 7（与法则牌桌版一致）
- **灵能**：战斗中击杀累积，战间奖励选 E 可加 +5。Boss 战前可访问**虚空商店**（一次性）：
    - 修复 +1：3 灵能
    - 升华一次：5 灵能
    - 购买 1 件遗物：8~12 灵能（随机货架 3 选 1）
- **法则卡牌**：Run 开始默认 3 张（《脉冲推送》《拉扯》《临时传送场》）；战间奖励选 A 可获新卡

##### 与正式版的关系

| 维度 | Demo 简版 | 正式版法则牌桌 |
|---|---|---|
| **Run 结构** | 线性 5 场战斗 | 18 张行动卡桌面流 |
| **路径选择** | 无（固定推进） | 自由选行动卡 |
| **经济决策** | 战间 3 选 1 + 1 次商店 | 持续灵能 / 卡组 / 遗物管理 |
| **战斗类型** | 普通 / 精英 / Boss 三种 | 入侵者 / 精英 / 商店 / 法则井 / 修复 / 裂痕 六类 |
| **总时长** | 30-45 分钟 | 60-90 分钟 |
| **核心目的** | 验证战斗循环 | 验证完整肉鸽体验 |

##### 设计意图

- **Demo 必须先证明"战斗本身有意思"**——R0 部署 + 物理三定律 + 锚点防守的核心乐趣
- 牌桌系统是**meta 层包装**，加在不好玩的核心上没救；加在好玩的核心上锦上添花
- 线性结构**降低 demo 玩家的认知负担**——一次只学一个系统
- **正式版无需重做核心代码**——线性结构是牌桌的"退化形态"，从线性升级到牌桌只需替换 Run-level 状态机

> **风险提示**：如果在 demo 反馈期发现牌桌系统是核心吸引力（玩家说"还想玩到更复杂的 Run 结构"），优先扩展 §3.4.1~§3.4.7。如果发现战斗本身不够吸引人，则优先迭代战斗（构件 / 敌人 / 棋盘 / 物理），暂缓牌桌。

#### 3.4.1 设计哲学（正式版起）

为什么不用杀戮尖塔节点图？

*   单图 Run（0.5~1h，约 12 张行动卡）尺度上，节点图的"路径分支策略"基本退化
*   节点图是**外壳**，可以套在任何游戏上，与本作的"法则执行者"世界观无深度耦合
*   "法则牌桌"= **机制即世界观**——玩家作为上位法则执行者，整个 Run 就是"摆弄法则机会"，与战斗内"法则覆写卡"是**同一种设计语言**

#### 3.4.2 牌桌结构

**桌面**：始终保持 **5 张可选行动卡**（半透明几何卡牌悬浮在 3D 虚空中，可点选）

**牌堆**：MVP 阶段共 **18 张**行动卡 + 1 张**终极仪式 Boss** 锁底

*   玩家执行 1 张牌 → 该卡消耗 → 从牌堆顶补 1 张到桌面
*   桌面始终保持 5 张
*   牌堆耗尽 → 终极仪式 Boss 强制触发 → Run 结算

**Run 长度**：玩家约执行 12~15 张牌（剩余因"舍弃"消耗），耗时 0.5~1h，对齐 MVP 节奏目标。

#### 3.4.3 行动卡六大类（MVP 配比 18 张）

| 类型 | 数量 | 卡牌内容 | 玩家选择动机 |
|---|---|---|---|
| ⚔️ **入侵者** | 8 | 触发一场普通战斗，从 MVP 全部敌人种类（炮灰 / 射手 / 冲锋者）中按预算半随机抽取——卡面**列出本场可能出现的敌人种类**，但不锁定具体比例（参考 ITB 岛屿风格）；1.0 后引入更多种类后池子相应扩展 | 主线推进 |
| ⚠️ **精英入侵** | 2 | 触发高难度战斗（敌人 +1 强化、可能含 Boss 小怪） | 高奖励：必给遗物 + 大额灵能 |
| 🏪 **虚空商店** | 2 | 用灵能购买：构件升华 / 遗物 / 圣所修复（不卖法则卡）| 资源消耗与构筑 |
| ❤️ **秩序修复** | 2 | 恢复圣所完整度 **+1**（不消耗灵能，小额免费续命）。主修复路径仍是虚空商店的灵能购买（3 灵能 = +1）—— 让"花灵能修复"的决策有意义 | 小额续命 |
| 🎴 **法则井** | 2 | 直接抽 1 张法则卡进卡组（法则卡的主要来源，不消耗灵能）| 卡组扩充 |
| 🌀 **法则裂痕** | 2 | 触发随机事件：赌博（输掉 / 翻倍灵能） / 牺牲（弃 1 构件换升华额度） / 净化（删卡组 1 张换升华） / 拾遗（额外抽 1 张法则卡）等 | 高风险高回报 |

**行动卡视觉**：

*   每张卡 = 一面悬浮的几何切面（六边形 / 三角形 / 八边形）
*   卡面用 §6 美学风格：黑底 + 青色霓虹边 + 中央符号
*   入侵者卡上小预告："本场 Anchor 数 / Rift 节奏 / 本场可能出现的敌人种类"（不显示具体数量与比例——保留半随机的紧张感，但玩家能预判该带哪些构件 / 卡）

#### 3.4.4 牌桌操作

**核心动作**：

*   **打出**：点选 1 张桌面卡 → 执行其内容 → 该卡消失，从牌堆补 1 张
*   **舍弃**：消耗 **1 灵能**丢弃 1 张桌面卡 → 立即从牌堆补 1 张
*   不需要"锁定"机制（卡牌只在被打出时才消失，不会被随机替换）

**舍弃机制的设计意图**：

*   桌面 5 张可能都不想要 → 灵能换"重抽"
*   保护"建造路线"：玩家想避免某些卡（如不想被迫接战时丢弃入侵者卡）
*   但灵能稀缺 = 不能滥用舍弃

#### 3.4.5 Run 流程示例

```
开局：
- 圣所完整度 7 / 灵能 0 / 卡组 3 张基础卡（容量上限固定 3，详见 §3.2.1）
- 牌堆 18 张 + Boss 1 张
- 桌面抽出 5 张：[入侵者A][商店][法则井][入侵者B][修复]

第 1 回合（玩家选择）：
- 打出"入侵者A" → 进入 5 回合战斗 → 击杀获得 8 灵能 → 完成度 0/3 → 完整度仍 7
- 卡牌消失，牌堆补 1 张到桌面：[商店][法则井][入侵者B][修复][精英入侵]

第 2 回合：
- 打出"商店" → 用 8 灵能给棱镜升华 1 次（解锁"转向攻击"，剩 0 灵能）
- 牌堆补 1 张：[法则井][入侵者B][修复][精英入侵][入侵者C]

...（玩家持续选择）

第 13 回合（牌堆耗尽）：
- 终极仪式 Boss 强制触发 → 最终战
- 战斗结果决定 Run 胜负
```

#### 3.4.6 与战斗系统的衔接

*   **战前简报**（打出"⚔️ 入侵者"或"⚠️ 精英入侵"卡时显示，纯信息无操作）：
    *   显示**本场预告**：棋盘缩略（含锚点 / 裂口 / 晶柱位置）、**本场可能出现的敌人种类**（半随机池，不显示精确比例）、奖励预览
    *   玩家点"开战"或"取消" —— 取消则不消耗本张行动卡
    *   **不需要在此选构件 / 选卡** —— 构件选择延迟到 R0 部署相在棋盘上完成；卡组 3 张全部默认进入
*   **R0 部署相**（详见 §2.1.2 / §3.1）：
    *   棋盘揭示 — 锚点位置、裂口位置（含倒计时）、晶柱位置、地形可见；**敌人不显示、敌人意图不显示**
    *   玩家从 Run 池选定 4 台构件依次放入边缘 2 格内空格 → 折镜朝向自动指向棋盘中心
    *   点"开战"按钮 → 敌人首次刷新 + R1 预警同步揭晓
*   **R1~R5 作战阶段**：
    *   按 §2.1.2 的"敌方预警 → 玩家行动 → 敌方执行 → 锚点结算 → 裂口刷新"5 步循环
    *   玩家行动阶段：操作 4 台已部署构件 + 卡组施放任意穿插（**不再召唤**）
*   **战后**：
    *   击杀累积的灵能 → 加入 Run 总灵能池
    *   按完成度扣 圣所完整度
    *   构件满血归位 Run 池（包括本场阵亡的）
    *   卡组所有卡牌的"本场限施放 1 次"状态自动恢复
    *   返回牌桌 → 桌面卡刷新（如果有牌被消耗的话）

#### 3.4.7 平衡与扩展空间

**MVP 阶段保守**：

*   18 张行动卡总量是上限（不再做更多类型）
*   每个类型只设计基础变体（"入侵者"模板 3 个差异化主题就够）

**1.0 后扩展方向**（详见附录 A）：

*   行动卡总量 → 30+
*   引入"传说卡"（极稀有的特殊事件）
*   多牌堆系统（不同 Run 抽不同主题牌堆）
*   多 Boss 池（终极仪式有 3~5 种，随机触发）

> **创新点**：法则牌桌不是节点图变体，也不是菜单变体。它把"Run 路径选择"重新定义为"卡牌构筑"——这是杀戮尖塔的卡组构筑哲学外推到 Run 结构层。玩家在 Run 中做的不是"走哪条路"，而是"打哪张牌"，与战斗内的"打法则覆写卡"形成**统一的设计语言**。

## 4. 微型战术地图设计 (Micro Tactical Maps)

MVP 阶段地图设计大幅简化，符合"单图 Run + 0.5~1h"的目标范围。

*   **棋盘尺寸**：固定 **8x8 = 64 格**
*   **MVP 地图数量**：**1 张**（统一棋盘骨架，敌人/锚点/裂口/晶柱位置随 Run 变化）
*   **棋盘特征**：
    *   **外圈 1~2 格预留为深渊**（坠渊击杀区，单位被推出 = 瞬死，详见 §2.3 坠渊判定）
    *   **中央 8~12 个候选锚点位置**（MVP 每场战斗**固定激活 3 个**，详见 §2.6）
    *   **6~8 个候选裂口位置**（每场战斗激活其中一部分，详见 §2.2）
    *   **4~6 个候选晶柱位置**（每场战斗激活 2~3 块，详见 §2.4.8）
*   **MVP 棋盘的三层地形结构**：
    *   *瞬死层 · 深渊*（外圈，永久存在）：单位被推过去 = 瞬死。玩家最强武器，但占位即危险
    *   *阻断层 · 晶柱*（棋盘中段，可破坏）：HP=1 的硬墙。提供"拆墙战术"+"撞墙杀敌"+"路径阻塞" 多重战术
    *   *机关层 · 折镜*（玩家部署，半透传送门）：玩家的物理引擎 + 路径阻断器。**HP=3 可被摧毁**（近战 / AOE / 连锁动量 -1 HP，远程被折射不掉血）；近战命中同时改朝向；**主动移动不能进入**（占位阻挡寻路），仅被推递动量可进入并从朝向方喷出
*   **MVP 棋盘的三类发光格**（详见 §6.2）：
    *   *仪式锚点*（深紫光柱，长期）：敌人仪式终点
    *   *仪式裂口*（洋红波纹，持续）：敌人出生点，被压制时持续存在
    *   *无发光特效* 晶柱 / 深渊（地形元素，纯几何视觉）
*   **设计原则**：
    *   规则形状 → 玩家算清楚边界
    *   深渊作为玩家最强武器 → 边缘空间设计是核心
    *   晶柱作为"路径调味料" → 中心区不再是空白桌面，而是有可破坏障碍的迷你迷宫
    *   半程序化 → 棋盘骨架手工设计 + 锚点/裂口/晶柱程序化激活
*   **生成约束**（保证战斗可解性）：
    *   被激活的锚点之间曼哈顿距离 ≥ 4 格
    *   晶柱**不生成在棋盘边缘 2 格内**——保留 R0 部署区净空（避免玩家无法部署的死锁）
    *   晶柱不与裂口候选位置重叠（避免出怪即顶死）
    *   晶柱不贴深渊边（保留至少 1 格通路绕行）
    *   每个锚点至少有 1 条不经过晶柱的可达路径——晶柱可让通路变窄但不能完全堵死

> **延后到 1.0**：异形棋盘、多地图、其他地形（森林 / 烟雾 / 冰面 / 酸液池等 ITB 风格地形系统）。MVP 阶段以"深渊 + 晶柱 + 折镜"三层结构覆盖核心地形博弈。

## 5. 敌方：熵化仪式体 (Entropy Invaders)

敌人按照固定仪式步骤推进。**所有近战敌人与玩家共享同一套近战攻击规则**（1 伤 + P=F_self 击退，套 §2.3 三定律），保证物理一致性是完美信息的根基。

### 5.0 敌人核心目标：奔向锚点（带个性化攻击偏好）

**敌人主目标是仪式锚点**，但每种敌人对"路上玩家构件"的攻击偏好不同。这是体系的根基：

*   **寻路目标**：每个敌人在**每回合预警阶段**计算**最近的未饱和锚点**（曼哈顿距离），朝其移动
*   **路径规则（仅在预警阶段计算一次）**：
    *   首选：朝目标锚点的最短路径方向（4 方向之一）
    *   多个最短方向并列：tiebreak 顺序为 **北 → 东 → 南 → 西**（保证完美信息可推演）
    *   **路径上有玩家构件（棱镜 / 拉钩 / 炮手）**：按**敌人个性化攻击偏好**处理（详见 §5.2）：
        *   **被动攻击型**（炮灰、射手）：绕路 ≤ 2 格 → 绕路；绕路 > 2 格 或 完全被围 → 进入攻击阶段
            *   炮灰：近战攻击挡路构件
            *   射手：在攻击范围内（4 方向直线 3 格内）有玩家构件 → 远程射击该构件，**无需挡路触发**
        *   **主动攻击型**（冲锋者）：在锚点路径基础上，**主动选择能撞到玩家构件的路线**（即使绕路 ≤ 2 格能避开玩家，仍优先撞玩家）—— 体现"野蛮冲撞兽"的攻击性
        *   绕路计算公式：`新路径长度 ≤ 原路径长度 + 2`
    *   **路径上有折镜 / 晶柱**：折镜与晶柱**完全阻挡寻路**——敌人 A\* 必须绕开（与玩家主动移动一致）：
        *   绕路计算按 ≤2 格规则（与挡路构件相同）；绕路 > 2 格 或 完全被围 → 原地停留
        *   敌人**不会主动攻击折镜 / 晶柱**（非生物目标，不在攻击偏好列表中）
        *   折镜的"半透传送门"特性仅在敌人**被推递动量进入**时触发（如冲锋者撞入或被构件推入）；敌人主动移动**永远不会走入折镜**
    *   **路径上有深渊**：绕开（敌人不会主动跳深渊）
    *   完全无路可走：原地停留

> **设计哲学（修订）**：敌人攻击行为分两种模式——**被动攻击**（仅挡路时打 / 在攻击范围内才打）和**主动攻击**（优先选择能打到玩家的路径）。MVP 阶段以被动攻击为主（炮灰、射手），冲锋者作为唯一的主动攻击型，体现"敌人不全是无脑朝锚点冲"的多样性。**整体仍然以"威胁来自空间"为主轴**——锚点压力始终存在，玩家需要管理两条战线（保护构件 + 阻止仪式）。射手的远程攻击让"距离"不再等于"安全"，玩家必须主动管理射线遮蔽。
*   **攻击范围（差异化）**：不同敌人有不同的攻击范围，详见 §5.2
*   **锁定原则（核心规则）**：
    *   预警阶段计算的**移动 + 攻击**全部锁定，本回合执行
    *   **被推走 = 攻击/移动落空**（撞空、走空），本回合不重算路径
    *   被推走后的新位置 → **下回合预警阶段重新计算路径**
    *   这是完美信息的根基——若"被推走则当回合重算"会让玩家算不清连锁后果
*   **预警可视化**：每个敌人头顶有 **2 个图标**：
    *   下一格落点圆环（本回合移动终点）
    *   攻击范围发光（本回合攻击格）
    *   ⚠️ 不显示"距锚点步数"或"指向锚点的箭头"——锚点目标信息由玩家从敌人朝向 + 棋盘锚点位置自行推演（保持完美信息但不喂答案，避免把"算路径"这一棋手乐趣替玩家做完）
*   **锚点饱和后**：原本朝该锚点行进的敌人**在下回合预警阶段**重新计算最近的未饱和锚点（不当回合切换）

> **设计要点**：敌人"攻击构件"不再是主动行为，而是"挡路时的副作用"。锁定原则让"推开敌人"获得**双重价值**——既改变它的位置，又让它本回合的攻击/移动落空（等于额外一回合时间）。这把"推撞"从位置博弈升级为**节奏博弈**。

### 5.1 敌人功能类型分类

按对锚点的贡献方式分类。MVP 阶段聚焦"充能型"作为唯一敌人类型，简化验证核心循环：

*   **类型 A · 充能型**（MVP 核心）：炮灰 / 射手 / 冲锋者。**核心威胁**——直接走到锚点上充能。它们是仪式的主力执行者，体现"敌人朝锚点而非朝玩家"的设计原则。
*   **类型 B · 干扰型**（1.0 后扩展）：拉扯型敌人（空间钩锁等）。瓦解玩家防线，详见附录 A.5。
*   **类型 C · 区域/特殊**（1.0 后扩展）：重装行者（高 M 硬钉子）/ 远程蓄力（Caster）/ 自爆体 / Boss 等。详见附录 A.5。

> **关键视角**：玩家的每一个敌人决策都问的是"它对仪式构成什么威胁"，但**"会不会打我"也是次要考量**——主动攻击型（冲锋者）会让玩家不能光顾着算锚点距离，还要算"它会冲到我脸上"；射手则让"远距离 ≠ 安全"。MVP 阶段三种充能型敌人足以验证此体验——炮灰提供"批量推渊"基础节奏（被动近战），射手提供"远程压制 + 射线管理"（被动远程，距离威胁），冲锋者提供"节奏压力 + 主动攻击"（玩家压力的另一维度）。**1.0 阶段补回重装行者（M=3 硬钉子）+ Caster + 钩锁 + 自爆体**后，威胁谱系扩展到完整 6 种敌人。

### 5.2 MVP 敌人规格 (3 种)

所有敌人**默认朝最近未饱和锚点行进**（§5.0），下表"攻击范围"列定义敌人**触发攻击的有效格子范围**（近战 = 挡路时的相邻格；远程 = 直线扫描射程）；"行为规则"列描述其**特殊行为**：

| 敌人 | M | F | HP | 移动 | 攻击范围 | 类型 | 行为规则 |
|---|---|---|---|---|---|---|---|
| **炮灰 Shard** | 1 | 1 | 1 | 2 | 近战 · 4 方向相邻 1 格 | A · 充能 | **被动攻击型**（近战）：朝最近锚点行进。挡路时绕路（≤2 格）或近战攻击构件（1 伤 + P=1 击退）。轻而脆，最易被推入深渊或被折镜传送门重定向 |
| **射手 Slinger** | 1 | 1 | 1 | 2 | 远程 · 4 方向直线 3 格（友军不可穿透）| A · 充能 | **被动攻击型**（远程）：朝最近锚点行进。每回合预警阶段检查"4 方向直线 3 格内是否有玩家构件"——若有则锁定**第一个目标**实施远程攻击（1 伤 + P=F=1 远离射手方向击退），不再移动；若无则正常向锚点行进。**与炮手镜像**：玩家构件的射手版本——脆（HP=1）、轻（M=1）、远程压制 |
| **冲锋者 Charger** | 2 | 2 | 2 | 3（冲刺） | 近战 · 冲刺直线全程 | A · 充能 | **主动攻击型**：朝最近锚点冲刺，但**冲刺路径优先选择能撞到玩家构件的方向**（即使存在不撞玩家的同长度路径，仍优先撞玩家——"野蛮冲撞兽"行为）。下回合直线冲刺套三定律结算（攻击 1 伤 + P=2 击退）；路径上遇构件**强行近战攻击**（不绕路）；**若路径上有折镜 / 晶柱**——预警阶段 AI 会重新选择不经过的方向（与普通寻路一致），不会主动撞墙；但若被推入折镜（外力动量传入），则从折镜朝向方喷出（玩家可设朝向把冲锋反推送进深渊）|

**射手的关键行为细节**：

*   **预警显示**：射手在攻击范围内有玩家构件时，预警阶段头顶亮起红色直线发光区域 + 锁定的目标格（让玩家精确预演"下回合谁会被打"）
*   **被推/被拉打断攻击预警**：套用 §5.0 锁定原则——若射手被推飞或被拉到新位置，原预警的远程攻击仍按**原坐标**结算（撞空、攻击落空），新位置下一回合重新预警
*   **射线遮蔽 = 玩家防御手段**：射手射线上若有炮灰、冲锋者等其他敌人 → 射手强制锁定**第一个目标**（敌我无差别）→ 射手会"误伤"自己人
*   **没有友军意识**：射手不会主动避开会误伤友军的射线方向——这是"敌人 AI 极度可预测"原则的体现，玩家可主动布置"诱敌挡线"战术

**关键互动设计**：

1.  **攻击范围差异化**：按敌人特征差异化攻击范围（炮灰"近战相邻"、射手"远程直线 3"、冲锋"直线全程"），让玩家根据敌人混编做不同站位决策
2.  **敌人充能统一规则**：所有敌人到达锚点都是 +1 —— 简单计数避免心智负担
3.  **MVP 三种敌人的设计分工**：炮灰提供"批量推渊连锁"基础体验（验证物理三定律 + 近战挡路）；射手提供"远程压制 + 射线管理"（验证远程对抗 + 射线遮蔽战术）；冲锋者提供"节奏压力"（验证折镜阻挡机关 + 主动攻击）。三者覆盖核心物理体系的近 / 远 / 节奏三个维度，**1.0 阶段补回 重装行者 / Caster / 钩锁 / 自爆体扩展威胁谱系**（详见附录 A.5）

### 5.3 Boss 设计方向

*   **仪式领主 (Boss)**：拥有 [锚定] 状态（免疫强制位移），生命极高。Boss 自身**就是一个移动锚点**——它每回合**为最近的未饱和锚点 +1 充能**（远程，无视距离），是仪式的"主祭司"。玩家无法推其坠渊，必须拿小兵当炮弹砸向 Boss 破防，再用法则覆写打破其锚定状态。
*   **远程供能机制专属性**：远程供能是 **Boss 专属**——这让 Boss 在结构上确实和普通敌人不同，它是唯一能"开传送 buff"的存在，配合锚定状态形成质变挑战。
*   **关键设计要求**：
    *   Boss 战必须有**稳定的"炮弹供给"**（周期性召唤小兵 或 Boss 专属炮弹生成装置）——新规则下裂口持续存在不可永久压制，但 Boss 战仍需保证小兵供给节奏稳定，防止玩家集火 Boss 时小兵断档造成死锁。
    *   Boss 战的失败条件除"仪式完成度饱和"外，还可叠加"Boss 完成专属仪式步骤" → 双失败条件压力。
    *   Boss 战的胜利条件 = 击破 Boss 锚定状态 + 推入深渊 / 击破其 HP，**而非**单纯撑过回合数。
*   **牌桌结构下的 Boss 角色**：终极仪式 Boss 是法则牌桌的"锁底"—— 牌堆耗尽（约 12~15 张行动卡执行后）强制触发，是 Run 的最终考验。详见 §3.4。

### 5.4 构件 × 敌人互动矩阵（战术克制关系）

> 所有互动均以"敌人对锚点的威胁能否被该构件削弱"为评估标准。"💪 优势"意味着该构件能稳定阻止该敌人贡献仪式。

#### 攻击型构件 × 敌人

| 构件\敌人 | 炮灰（M=1，近战）| 射手（M=1，远程 3 格）| 冲锋（M=2，冲刺）|
|---|---|---|---|
| 棱镜（近战 · 相邻 1 格）| 💪💪 等价交换链式连锁（紧贴排列时一发清整排）| 💪 等价交换 → 射手 -1 + 飞 1 格（脆易死）；前提是棱镜能贴脸（射手射程 3 让贴脸有压力）| ✅ 以卵击石（停下打断冲刺，棱镜原地反复 -1 磨）|
| 炮手（远程 · 直线 3 格）| 💪 等价交换 → 炮灰 -1 + 飞 1 格（顺势送渊或撞击连锁）| 💪 等价交换 → 射手 -1 + 飞 1 格；远程对远程的镜像对抗，谁先开火谁占优 | ✅ 以卵击石 → 冲锋 -1（不动，但打断了冲刺预备）|

#### 功能型构件 × 敌人

| 构件\敌人 | 炮灰 | 射手 | 冲锋 |
|---|---|---|---|
| 拉钩（远程 · 直线 3 格）| 💪 拉到折镜前传送 / 拉到自己面前 -1 集中处理 | 💪 拉到自己面前 -1 → 射手脱离射程，无法对玩家其他构件远程压制 | ✅ 1 伤 + 拉离冲刺直线 |
| 折镜（半透传送门 + 阻路，无主动攻击）| 💪 路径阻断 + 推入折镜传送进深渊 / 撞击连锁 | 💪 阻挡射手寻路绕路 + 推入传送进深渊（射手 HP=1 一击死）；折镜免疫射手的远程攻击（折射动量）| 💪 折镜阻断冲锋直线路径 → 冲锋绕路 + 多消耗 1 回合；推入传送时玩家可设朝向送其入渊 |

**图例**：💪 优势 / ✅ 对等 / ⚠️ 劣势 / ❌ 克制

**战术注释**：

*   **射手的处理**：射手是 MVP 唯一的远程敌人。处理射手的核心思路：
    *   **抢攻**：射手 HP=1 + M=1 → 任何构件正面对它都能一击 / 一推送渊。关键是"在射手开火前先打到它"
    *   **遮蔽射线**：射手不会主动避开会误伤友军的射线 → 玩家可故意把炮灰 / 冲锋者推到射手的射线方向 → 射手强制锁定第一个目标 → 射手"误伤"自己人
    *   **折镜免疫**：射手攻击折镜时折镜不掉血、动量被折射 → 射手对折镜完全无效，但折射的动量可被玩家利用
    *   **拉钩拉脱**：拉钩远程拉射手到自己面前 → 射手脱离射程 + 射手 -1（HP=0 直接死）
    *   **配合炮手**：炮手与射手都是 4 方向直线 3 格，是远程对远程的"先手博弈"——预警阶段优先看谁能锁定谁
*   **棱镜的"恢复 1 行动权"特例**：攻击不自伤后，这个特例真正可用——棱镜可以"攻击 → 移动 → 再攻击"，每回合最多 2 次近战攻击 + 移动 6 格，是机动游击 + 多目标处理的核心动词。M=1 让棱镜对炮灰的连锁链路最长（等价交换台球式）。
*   **炮手的核心价值**：MVP 唯一的"远程推力构件"——直线推走第一个目标，配合深渊边可一发送渊。**与拉钩对偶**：拉钩"拉过来集中处理"，炮手"推出去送渊"——两者覆盖远程位置控制的两个方向。**和折镜组合**：炮手对折镜开火 → 折射动量沿折镜朝向方推送另一格目标 → 远距离触发连锁。**友军不可穿透代价**：炮手射线上若挡有友军 → 友军吃 1 伤 + 飞 1 格，玩家必须为远程攻击付出"射线净空"代价。
*   **冲锋者 vs 折镜（新规则）**：冲锋者预警阶段 AI 会**预先绕开折镜**（与晶柱、其他构件一致）—— 冲锋不再"自动撞入折镜触发传送门"。但若玩家**主动用推力把冲锋者推入折镜**（如棱镜近战推、拉钩拉），则触发半透传送门 → 从折镜朝向方喷出。**折镜在新规则下变成"路径阻断 + 玩家主动触发的传送门"**——冲锋者既不能借折镜当电梯，也仍可被玩家"用折镜重定向"。
*   **冲锋者的主动攻击性**：冲锋者**会优先选择能撞到玩家构件的路径**——即使有更直接朝锚点的方向。这意味着玩家**不能把构件随便摆**，否则会被冲锋者主动找上门。**反制**：把折镜 / 晶柱设在冲锋直线路径上（冲锋必须绕路），或用拉钩远程拉冲锋离开冲刺路径，或主动撤回构件让冲锋者扑空。
*   **拉钩的核心价值**：远程拉攻击 1 伤 + P=1 击退，跟近战攻击同等伤害但**安全得多**（拉钩自身不卷入碰撞）。**和折镜组合**："拉钩把远处敌人拉到折镜前 → 敌人撞入折镜被动量推入 → 从朝向方喷出（送进深渊或撞击其他敌人）"是 MVP 的招牌连锁。但拉力把目标朝拉钩方向拉（远离深渊），**几乎无法直接送渊**——送渊任务由棱镜攻击 / 炮手 / 折镜传送门 / 推力卡牌承担。
*   **拉钩的友军代价**：新规则下"友军不可穿透" → 拉钩拉友军时友军同样 -1 HP。这意味着拉钩失去"无伤援护"功能，必须为"远程拉回友军"付出 1 HP 代价。**安全位移友军应使用近战推 / 折镜传送门 / 主动撤回**。
*   **炮灰的连锁价值**：紧贴排列的炮灰是 MVP 最爽的连锁素材——棱镜近战攻击首个炮灰（等价交换 → 炮灰 -1 + 飞 1 格）→ 飞向第二个炮灰（等价交换 → -1 + 飞 1 格）→ 链式传导。**M=1 时连锁需要敌人紧贴**（飞 1 格刚好接触下一个），布局重要。炮手对炮灰开火同样能触发紧贴连锁，且方向相反——拉钩拉过来 / 炮手推出去 / 棱镜近战，三种连锁触发器互补。
*   **折镜被攻击 → 朝向变化**：敌人近战攻击折镜（如冲锋者撞折镜）会改变其朝向；射手远程攻击折镜**不改朝向**（仅折射动量）——这是动态法则结构的核心。玩家需要在预演中算清"如果敌人攻击了折镜，朝向会变成什么样，连锁路径会变成什么"。

**关键洞察**：MVP 阶段构件简化为"棱镜（机动近战）+ 炮手（远程推）+ 拉钩（远程拉）+ 折镜（传送门法则机关）"四件套，配合"4 种构件中选 4 台允许重复"的战术（如 1 棱镜 + 1 炮手 + 1 拉钩 + 1 折镜、2 棱镜 + 1 折镜 + 1 炮手）。MVP 三种敌人（炮灰 / 射手 / 冲锋）覆盖核心物理体系：近战连锁、远程对抗、节奏冲刺。**远程对远程的对偶**（炮手 vs 射手）让 MVP 阶段就能验证"射程 + 射线净空 + 先手博弈"完整体验。法则双轨制（构件 + 卡牌）通过推/拉力卡牌覆盖工具空缺；拉钩+折镜的"机关式战术"让玩家有"远程消耗 + 传送送渊"的强力组合。build 决策从战略层（开局选构件 + 重复策略）扩展到战术层（每场带不同卡）。**1.0 阶段补回重装行者（M=3 高 M 硬钉子）/ Caster / 钩锁 / 自爆体后**，互动矩阵和战术深度将显著扩展（详见附录 A.5）。

## 6. 世界观与视听表现 (Worldbuilding & Aesthetics)

### 6.1 核心世界观：漂移圣所 (The Drifting Sanctuary)

世界是一座由秩序法则构筑的几何圣所，悬浮于无底虚空之上。由于"故障核心"的破裂，维持平衡的法则失控，熵化怪物从虚空裂口侵入，试图完成吞噬一切的仪式。玩家扮演圣所最后的法则执行者，率领"秩序构件"，在不断碎裂、漂移的仪式盘上，通过物理推挤与法则覆写，将入侵者打入盘外虚空。

### 6.2 视觉表现原则与 AI 美术约束

为了最大化伪 3D 效果并确保 AI 生成资产的高度统一，制定以下严格约束：

1.  **舞台化构图 (Diorama Effect)**：重点展现"高低层次、边缘厚度、深渊落差"。深渊不是黑色的地板，而是真正的无底空间。
2.  **形体极简语法**：所有单位（无论敌我）只允许由 **1~3 个主形体** 构成。不画五官，不画复杂机械关节。认清轮廓（Silhouette）是第一要务。
3.  **绝对阵营配色**：
    *   *秩序阵营（玩家/地图）*：黑、白灰、深靛蓝、发光的霓虹青（Cyan）。强调对称、稳定、切面平整。
    *   *熵化阵营（敌人）*：高饱和洋红、橙红、毒黄绿。强调错位、拉伸、断裂、不对称的几何增生。
4.  **UI 符号化**：预警线、推挤轨迹全部采用极具仪式感和数学感的虚线、旋转圆环、发光矢量面，与世界观无缝融合。
5.  **发光格协议**：棋盘上有两类"发光格"和一类"实体地形"，必须用颜色 + 形状三重区分以避免认知混淆：
    *   **仪式裂口（敌人出生点）**：洋红色横向波纹光，地面波动效果。**成功出怪后**消失；被压制时持续保留并继续阻塞，直到占据者离开后才出怪消失。
    *   **仪式锚点（长期 / 仪式终点）**：深紫色稳态光柱（垂直发光），中央悬浮青色四面体；充能时下方涌出洋红色能量柱（高度 = 充能进度）。整局战斗持续存在。
    *   **完成痕迹**：锚点饱和后留下黑色凹陷的"仪式痕迹"作为永久视觉占位，提醒玩家"此处仪式已完成"。
    *   **晶柱（实体地形）**：青色发光多面体，缓慢自旋；表面有几何纹路。**与裂口/锚点完全不同**——不是"地面发光"而是"竖立的实体"，玩家一眼就能区分"这是要绕开/打碎的硬墙"而非"要踩上去/避开的法则点"。

### 6.3 沉浸打击感 (Hit Feedback)

动作无需花哨，强调冷酷的物理反馈。保留强烈的顿帧 (Hit Stop) 与屏幕震动。死亡特效不做爆炸烟雾，而是**"几何结构瞬间崩解、轮廓断裂碎裂、静止、然后消散"**，极度突出"规则被抹除"的冷硬质感。

## 附录 A：1.0 后规划 (Post-MVP Roadmap)

以下内容已规划但**延后到 1.0 之后**实现。MVP 阶段不实现，但保留作为路线图。

### A.1 局内净化与同化 (Purification & Assimilation)

> 与 §6.3 "绝对阵营配色"存在美学张力，且会在 MVP 阶段增加不必要的平衡维度。计划作为 1.0 后的资料片/DLC 内容。

*   **同化机制**：在精英关卡中，若玩家能将"特殊的熵化模块"推入地图特定的净化区（而非推入虚空击杀），战后可选择将其**编入小队**。

### A.2 双人合作模式：战术互锁 (Co-op: Tactical Interlock)

> 回合制战棋的多人模式普遍面临"等待问题"（一人思考五分钟另一人干瞪眼），独立团队难以在 MVP 阶段同时打磨单机体验与多人平衡。建议作为 1.0 发售后的内容或社区 MOD 方向。

*   **缩减编制**：在微型棋盘上，双人模式场上总共只有 **4 台构件**（P1 控 2 台，P2 控 2 台），避免交通拥堵
*   **基于压力的动态缩放**：敌方总生成预算提高 25%~35%。每波生成 1~2 只带有"单次防推"的强化怪，迫使玩家利用 4 台机体打出"破甲 + 接力推入深渊"的配合连招
*   **平行控制权**：两人在同棋盘上共享回合和物理法则，但各自控制独立单位，打出"接力扣篮"式的精妙连招

### A.3 仪式变体：会聚仪式 (Converging Ritual)

> 静态锚点是 MVP 唯一战斗类型。"会聚仪式"是规划中的关卡变体，验证静态锚点稳定后再做。

*   **机制概述**：与静态锚点相反，棋盘上有一个**汇聚点**和若干**仪式碎片**（M=1, HP=2 的物理实体）。每回合所有碎片自动朝汇聚点滑动 1 格。任何碎片到达汇聚点 → 仪式完成度 +1。
*   **玩家干预**：用攻击型推开/推渊碎片（享受击杀掠夺奖励）、用折镜传送门重定向碎片路径、用卡牌临时反转引力 / 冻结漂移
*   **敌人定位**：普通敌人在会聚仪式关里**变为碎片的护卫**——它们朝最近碎片走，到达后给碎片加 buff（+HP / +速度 / 远程格挡 / 拉扯构件）。玩家必须先拆护卫，再处理碎片
*   **设计价值**：与静态锚点关形成**"防守 vs 追击"**两种空间体验，让 Roguelike 节点图有真正不同的关卡类型
*   **关卡分工方向**：守护战（静态锚点）50% / 追猎战（会聚仪式）30% / 精英战（仪式行者）15% / Boss 战 5%

### A.4 其他扩展方向

*   **棋盘扩展**：异形棋盘、多地图、地形修正（山地/森林/烟雾对应 ITB 的地形系统）
*   **构件扩展**：游戏共设计 **8 种构件**，MVP 4 种之外保留如下方向：

#### A.4.1 楔块 Wedge（重型攻击型）

*   **基础规格**：M=3 / F=3 / HP=3 / 移动 2
*   **战术定位**："重型清线兵"。M=3 让它能跟重装行者等价交换互推；F=3 让其近战攻击产生 P=3 击退动量，触发撞墙差异化（2 伤）。
*   **差异化升华方向**（通过升华动词而非数值）：
    *   "攻击 M ≤ F_self 单位时目标 +1 额外伤害"（重型碾压感的伤害补偿）
    *   "对角线攻击"（动词扩展，棱镜只能 4 方向）
    *   "近战攻击后追加攻击"（动词链）

#### A.4.2 观测者 Spotter（远程狙击型）

*   **基础规格**：M=2 / HP=2 / **F=3** / 移动 1 / 射程 全图直线 4 方向
*   **战术定位**：远程狙击 + 蓄力释放。1.0 阶段补回 Caster 后形成镜像博弈——Caster 蓄力 1 回合释放直线 AOE，观测者蓄力 1 回合释放远程攻击。
*   **F=3 的设计意义**：观测者是 1.0 阶段第一个 **F > M** 的差异化单位（M=2 自身轻、F=3 攻击强），符合"狙击枪很轻但子弹有杀伤力"的物理直觉。F=3 让它的远程攻击能：
    *   推动 M=3 重装（F=3 > M=3 → 等价交换）
    *   击退距离 3 格 → 触发撞墙差异化（P≥3 时 2 伤）
    *   贯穿一排紧贴敌人形成长链连锁
*   **核心规则**：
    *   **蓄力机制**：行动分两步
        - 第一回合：选定 4 方向之一进入「瞄准」状态（无法移动，标记瞄准线）
        - 第二回合：释放——沿瞄准方向锁定**第一个非穿透目标**：
            * 命中目标 T：T 受 1 点伤害 + 被赋予 P=F=3 动量沿瞄准方向击退
            * 击退后套用 §2.3 三定律——T 飞 3 格内若撞到下一个单位，按 M 比较结算连锁；若撞墙触发 P≥3 时 2 伤差异化；若飞出盘外则坠渊
    *   **打断条件**：蓄力期间被攻击或被推开 → 瞄准打断，回到正常状态（下回合可重新蓄力）
    *   **预演**：完美信息原则下，瞄准线在蓄力开始时全场可见——敌人会优先攻击/推开蓄力中的观测者
*   **战术价值**：
    *   **1 伤 + F=3 击退**是 MVP 玩家阵营无法企及的击退强度——可推动 M=3 重装 + 撞墙触发 2 伤差异化（重装被击退至墙边瞬间 -2 HP）
    *   蓄力期间是「空间承诺」——玩家在蓄力的 1 回合内必须接受观测者无防御的状态
    *   远程动量套连锁——一发 F=3 可贯穿一排炮灰（首个 -1 + 飞 3 格 + 接力撞下一个，每个连锁单位仍按三定律结算）
*   **与 §0 北极星的相容性**：观测者**不让玩家"躲角落安全输出"**——蓄力暴露 1 回合 + 移动力仅 1 + HP 2 → 玩家必须为远程攻击付出"位置承诺"代价，符合「每个决定都有物理代价」原则
*   **升华路线候选**：
    *   "蓄力即射"——下回合蓄力即可释放（取消 1 回合延迟，但仍有「不能移动」约束）
    *   "穿透瞄准"——动量穿过折镜不被传送（特殊豁免）
    *   "扇形瞄准"——一次蓄力可锁定 3 方向中任一释放
    *   "强力击退"——F 升级到 4（动量上限提升，进一步强化推墙战术）

#### A.4.3 其他构件方向

*   **回响**（M=1, HP=1, 移动 3，近战攻击后可立即再移动 2 格的游击型——MVP 阶段独特性不足，挪到 1.0 后扩展）
*   ~~**推进器 Booster**：远程推力构件——拉钩（拉力工具）的镜像版本（推力工具）~~ → **已并入 MVP 阶段炮手 Cannoneer**（详见 §3.1.1）
*   其他保留：锚点型 / 拉扯型加强（专攻援护链）/ 召唤型

### A.5 敌人扩展（1.0 后补回）

MVP 阶段精简为 3 种敌人（炮灰 / 射手 / 冲锋）已覆盖核心物理体系的近战 / 远程 / 节奏三个维度。1.0 阶段补回以下四种敌人，扩展威胁谱系到完整的"7 种敌人 × 3 大威胁类型"矩阵：

#### A.5.1 重装行者 Juggernaut（类型 A·充能 + 高 M 硬钉子）

*   **基础规格**：M=3 / F=3 / HP=3 / 移动 1 / 攻击范围 近战 · 正前方 2 格直线
*   **行为规则**：**被动攻击型**（仅锚点）。朝最近锚点行进，专注不分心。**质量大** → 难以撞飞（M=3，棱镜推不动需用折镜传送门或卡牌《强力推送》）。攻击力高 → 近战攻击构件 1 伤 + P=3 击退（可触发撞墙差异化 2 伤）。若有路绕路就会绕，不会主动找玩家麻烦
*   **设计价值**：MVP 阶段被替换为远程射手以补足远程对抗维度。1.0 阶段重新补回作为"高 M 硬钉子"的纯物理对抗教学——验证 M=3 质量推制 + P≥3 撞墙差异化
*   **处理工具**：
    *   **棱镜近战磨血**：以卵击石（棱镜原地不动 + 重装 -1），每回合 1 伤、3 回合磨死。但磨重装期间重装持续朝锚点行进，**时间成本高**
    *   **《强力推送》卡（F=2）**：等价交换 → 重装 -1 + 飞 2 格。可推重装坠渊 / 撞墙（P=2 撞墙仅 1 伤，未达 P≥3 差异化）/ 推入折镜触发半透传送门 → 重装从折镜朝向方喷出（玩家可设朝向送进深渊）
    *   **观测者远程攻击（F=3）**：等价交换 → 重装 -1 + 飞 3 格。撞墙触发 P≥3 差异化（重装 -2 HP）
    *   **路径布置**：在重装预测路径上提前部署折镜（朝向深渊）→ 重装的 A\* 寻路被折镜阻断 → 必须绕路 → 多消耗回合（注：1.0 后重装走入折镜机制需重新设计——新规则下主动移动不能进入折镜）
    *   **拉钩 / 炮手 F=1 < M=3** → 无法推动重装，仅能造成 1 伤（远程消耗）

#### A.5.2 远程祭祀 Caster（类型 A·充能 + 远程蓄力）

*   **基础规格**：M=1 / HP=1 / 移动 1 / 攻击范围 远程 AOE · 正前方 3 格直线
*   **行为规则**：朝最近锚点行进 + 充能（与其他充能型一致）。**特殊行为**：蓄力 1 回合后，下回合释放正前方 3 格直线 AOE 攻击（伤害 2，对挡路构件造成额外威胁）。被攻击可打断蓄力
*   **设计价值**：在射手"远程单点"基础上引入"远程 AOE + 蓄力"威胁层级，让"挡线占位"代价 2 伤，迫使玩家在直线上提前布置折镜传送门或拉钩拉离
*   **与射手的差异**：射手 = 单点 1 伤即时；Caster = AOE 2 伤蓄力。Caster 是射手的"重型版本"
*   **与玩家观测者构件的镜像**：详见 §A.4.2

#### A.5.3 空间钩锁 Hookspine（类型 B·干扰）

*   **基础规格**：M=2 / HP=1 / 移动 1 / 攻击范围 远程拉扯 · 十字 4 方向 3 格内
*   **行为规则**：朝锚点缓慢行进，但**每回合额外执行**一次拉扯：把"十字 4 方向 3 格范围内、距锚点最近的玩家构件"朝远离锚点方向拉 1 格（让出锚点防线）。AI 在多个候选中优先拉 HP 最低的
*   **设计价值**：唯一的"瓦解锚点防御"敌人，强制玩家不能简单靠"占位防御"应对仪式
*   **与玩家拉钩构件的镜像**：钩锁拉走玩家友军，玩家拉钩可拉回友军 / 反拉钩锁本身离开十字射程 → 镜像博弈核心场景
*   **折镜反制**：钩锁的拉扯视为远程动量，可被折镜传送门重定向

#### A.5.4 自爆体 Pyre（类型 C·区域事件）

*   **基础规格**：M=2 / HP=1 / 移动 2 / 攻击范围 触发式 AOE 3x3（到达锚点或倒计时归零时爆炸）
*   **行为规则**：朝最近锚点行进。**到达锚点格时**：锚点 +1 充能，同时立即爆炸 3x3 范围 3 点伤害（阵营无差别，敌我同炸）。3 回合天然倒计时归零也会爆炸（不到达锚点也炸）
*   **设计价值**：制造"高紧迫性瞬间"——玩家必须用折镜传送门 / 拉钩拉离 / 推进深渊处理，不能拖延
*   **与拉钩的互动**：拉钩拉自爆体过来仅是位置控制，不会引爆（自爆体仅在到达锚点或倒计时归零时引爆）；拉钩拉时自爆体仍 -1 HP（HP=1 → 0 → 直接死亡，避免引爆）—— **新规则下"拉钩拉自爆体"成为最稳定的拆弹手段**
*   **与炮手的互动**：炮手推自爆体送渊 / 远离锚点同样有效；推时自爆体 -1 HP 直接死亡
*   **构件远离原则**：3x3 / 3 伤的 AOE 能秒杀棱镜 / 拉钩 / 炮手（HP=2）；折镜（HP=3）受 1 次 AOE 伤害（-1 HP + 朝向变为攻击合力反方向）—— 自爆 3 伤一次性扣光折镜所有 HP，折镜碎裂本场离场

#### A.5.5 1.0 后扩展方向

*   **Boss · 仪式领主**：[锚定] 状态免疫位移 + 远程供能（每回合为最近未饱和锚点 +1 充能）。详见 §5.3
*   **更多变体**：精英敌人变体（重装+1 强化）、远程供能小怪、护卫队（保护碎片或 Boss）等

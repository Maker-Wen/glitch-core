## 0. 设计北极星

### 一句话

> **暗黑哥特版的完美信息棋盘解谜战旗**——3 个守卫者保护建筑，用物理推撞、连锁碰撞、地形利用阻止敌人。所有信息公开，每场战斗都是一道可解的取舍谜题。

### 核心体验目标

**棋手感 + 工程师感 + 暗黑哥特视觉**

- **棋手感**：所有信息公开（敌方下回合行动完全可见），决策成败在于**精确推演**而非运气
- **工程师感**：玩家不直接打怪，而是**通过物理连锁、地形利用"操纵"局面**——把怪物推下深渊、撞死在石柱上、撞出碎裂状态减速
- **暗黑哥特视觉**：暗黑地牢式的氛围皮——压抑、黯淡、有重量。视觉差异化是市场已验证路径（参考 Othercide）

> **基调说明**：本游戏不追求宏大叙事或情绪共鸣。哥特皮是视觉层，不是叙事层。核心体验是"棋盘解谜的成就感"——不是"末更守夜的悲剧感"。

### 六条不动的设计原则

1. **完美信息**（揭示后）：所有**已揭示**的内容（当前棋盘单位的下回合行动、连锁结果、伤害数字）可精确预演，零随机命中率。**未揭示**的部分（地裂下回合冒出什么类型敌人）按 ITB 风格延后揭晓——揭晓后立即变完美信息。
2. **威胁来自空间，不是攻击**：玩家不应通过"躲避攻击"来减少压力。压力来自怪物**逼近建筑的进程**。
3. **每个决定都有物理代价**：推开一只怪可能撞到另一只；让守卫者离开 X 格意味着 X 格暴露。
4. **敌人是棋子，不是对手**：敌人 AI 极度可预测——智能感来自"多个简单棋子的组合"和"棋盘空间挤压"，而非 AI 算法的复杂性。
5. **可读性高于酷炫**：任何机制如果让玩家看不懂下回合发生什么，就砍掉。
6. **每个 Run 必须感觉不同**：调研显示 ITB 最大痛点是"看似随机实则千篇一律"。通过**协同遗物组合**（每 Run 拿到的 2-3 个遗物影响动词）+ **挑战目标多样性**（同一场战斗追不同挑战）+ **碎裂状态战术**，确保玩家不会感到"我已经玩过这场"。

## 1. 两参考的角色分工（指导我们做取舍）

| 参考 | 它贡献什么 | 它**不**贡献什么 |
|---|---|---|
| **Into the Breach** | 战斗骨架：完美信息、敌方预警、保护建筑、推撞物理、3 单位编制、单图小棋盘、Roguelike | 美术、世界观、Run 元结构（部分） |
| **暗黑地牢** | 美术：哥特/腐败、单位身份感、阴森立绘、压抑感 | 战斗玩法（暗黑地牢是横版回合制）、完美信息 |

> **MVP 阶段不做杀戮尖塔的卡牌形式**——但**借鉴其"协同设计哲学"**。具体而言：
> - ❌ 不做卡组构筑、抽卡、能量等卡牌系统形式（推迟到 1.0+）
> - ✅ 借鉴"协同 + 状态效果"的深度设计（碎裂状态 + 协同遗物，详见 §3.6 / §6.6）
>
> 这让 MVP 定位为：**"ITB 玩法 + 暗黑哥特美术皮 + 杀戮尖塔风的轻量协同层"**——一个有暗黑哥特皮、轻协同深度的小棋盘解谜战旗。

### 我们的差异化定位（诚实版）

> 不是 ITB 的克隆，但 MVP 阶段在玩法上**是 ITB 的精神继承者** + **暗黑哥特美术皮** + **借鉴后继者的若干设计共识**。

我们与 ITB 在 MVP 阶段的真实区别：

| 维度 | Into the Breach | 《长夜余烬》MVP |
|---|---|---|
| **美术风格** | 像素 + 蓝色调机甲 + 城市/沙漠/冰原 | 暗黑哥特立绘 + 中世纪腐败地下据点 |
| **失败结构** | 4 个建筑 = 4 条命，全毁即输 | 守护值 7，单场亏 0-3 不立即结束 Run |
| **棋盘元素** | 山、林、火、水、虫巢 | 石柱、地裂、深渊、被毁建筑（焦黑废墟）|
| **状态效果** | 无（推/拉动作只有位移效果） | **碎裂状态**——撞击产生减速，强化"撞墙/接力"战术回报 |
| **遗物设计** | 装备系统（每个 mech 2-3 个固定槽位）| **4 个协同遗物**（2 改能力 + 2 战术协同），每 Run 拿到 2-3 个组合 |
| **胜负判定** | 二元：建筑存活否 | **挑战目标系统**（4 个可选挑战 + 完成数量奖励梯度） |
| **整体感受** | 紧凑机械的战术解谜 | 暗黑视觉下的协同战术，每 Run 都因遗物 + 挑战目标组合而不同 |

**MVP 阶段我们就是"暗黑哥特版 ITB + 轻量协同层"——这是诚实定位，也是市场空缺**。

调研发现（2018-2025）：ITB 自身没有续作；ITB 后继者（Othercide / Trials of Fire / Inkbound / Banners 等）独立收敛到"状态效果 + 协同"作为深度来源，但**全部抛弃了建筑保护机制**。我们是**唯一保留建筑保护的同时引入轻量协同层**的设计——这是真正的差异化空间。

### 我们的真正卖点

- **冷酷推演下的取舍战术** —— 完美信息棋盘 + 推/拉物理 + 接力推动 + 碎裂减速，让每场战斗成为一道"如何用最少代价守住建筑"的精确谜题。
- **协同遗物 + 挑战目标双层重玩** —— 4 遗物组合产生 6 种主要协同矩阵；同一场战斗 4 个挑战目标可分别追求。一个 Run 体验 vs 另一个 Run 体验明显不同。
- **守护值的弹性失败** —— 不是 ITB 的"4 个建筑等于 4 条命"。**单场可以亏 1-2 栋建筑而不立即结束 Run**，这给玩家"承担风险 + 后续修复"的空间，降低 ITB 著名的硬核挫败感。
- **手绘暗黑立绘** —— ITB 的像素风偏向"清爽精算"；我们的暗黑立绘偏向"压抑视觉"——同样是完美信息棋盘玩法，但视觉锚点截然不同（市场已验证差异化方向，参考 Othercide）。

### 1.0+ 扩展的差异化（远景规划，非 MVP）

如果 MVP 验证成功，1.0+ 阶段会加入下列元素，让游戏与纯 ITB 拉开真正的距离：

- **战中卡牌系统** — 稀疏的法则改写卡（每场 3-8 张，每张限 1 次），是与 ITB 的核心差异化（详见 §9 预留章节）
- **节点图分支 Run 结构** — 杀戮尖塔式的路径选择
- **守卫者升华系统** — 动词扩展路线
- **更多敌人 / 建筑 / 棋盘**

但**这些都不是 MVP 阶段的事**。MVP 只验证战斗循环本身好不好玩。

### 反 AI Slop：我们不会做的事

为了避免成为"看起来什么都做了，但每件事都半成品"的 AI 通病，我们**明确不做**这些事：

- ❌ "深度叙事" — 不做 NPC 对话、剧情演出、世界观文本展开
- ❌ "丰富剧情" — 没有任务系统、没有支线、没有角色弧光
- ❌ "复杂养成系统"（MVP 阶段）— 不做技能树 / 装备系统 / 属性堆叠 / 守卫者升华 / 装备槽
- ❌ "完整的 RPG 流程" — 不做跨 Run 继承（每个 Run 完整且独立）
- ❌ "宏大主题叙事" — 不做"拯救世界 / 末日悲剧 / 命运抗争"等剧情主题
- ❌ "战中卡牌"（MVP 阶段）— 推迟到 1.0+，先把战斗循环本身做好

> **关于 4 个遗物**：MVP 的遗物（链锤改装 / 长杖共鸣 / 碎裂猎人 / 连锁共鸣）**不属于"复杂养成"**——它们是固定的 4 个、每个只改一件事、Run 内一次性生效，本质是"运行时变体"而非"养成系统"。区分点：养成 = 跨 Run 累积；遗物 = Run 内运行时随机出现。

**Less is more. Make one thing exceptional, not ten things mediocre.**

## 2. 核心循环

### Run 级（一局游戏的整体流程）

```
开始一个 Run
  ↓
选择起始守卫者编制（3 个，每种限 1 个 — MVP 阶段不允许重复）
  ↓
进入线性 5 场战斗（4 普通 + 1 Boss）
  ↓
每场战斗胜利后获得：余烬（货币）+ 节点奖励（升级 / 遗物）
  ↓
守护值 ≤ 0 → Run 失败
  或
通关 Boss → Run 胜利
```

### 战斗级（一场战斗的循环）

```
布防阶段（ITB 风格）
  - 棋盘揭示（建筑、地裂、石柱、深渊位置 + 本场总轮数）
  - 不预知敌人种类（每轮出怪时才揭晓）
  - 玩家选 3 个守卫者放在棋盘边缘 2 格内
  ↓
战斗轮次 1 ~ 5，每轮次：
  1. 敌方预警阶段（新出怪揭晓 + 所有敌人显示下回合行动）
  2. 玩家行动阶段（操作守卫者：移动 + 近战/远程攻击）
  3. 敌方执行阶段（按预警严格执行）
  4. 建筑结算阶段（被攻击的建筑扣 HP）
  5. 地裂出怪阶段（本轮预告标记的地裂冒出敌人 / 被占据则延迟 1 轮）
  ↓
战斗结算
  - 建筑全毁 → 单场失败 + 守护值 -3
  - 至少 1 栋建筑存活 → 单场胜利 + 按比例扣守护值
  - 0 栋建筑被毁（完美防守）→ 守护值不扣 + 高级奖励
```

## 3. 战斗机制

### 3.1 完美信息回合制

战斗的核心目标是 **"撑过 5 个战斗轮次，并保护至少 1 栋建筑"**。

- **战斗结构**：每场战斗 = 布防阶段（独立阶段）+ 战斗轮次 1-5 共 5 个作战回合
- **没有命中率**：所有伤害固定，所有连锁可推演，所有已揭晓的敌方意图公开

#### 主目标（必达 = 通关）

- **战斗胜利**：第 5 轮结束时 ≥ 1 栋建筑存活
- **战斗失败**：所有建筑在第 5 轮结束前被毁

#### 挑战目标（可选 = 额外奖励）

每场战斗设有 **4 个挑战目标**——通关同时完成挑战获得额外奖励。这是借鉴 TBW（Tactical Breach Wizards）的设计：让玩家自己控制难度上限，每场战斗有多个值得追求的目标。

| 挑战目标 | 完成条件 | 设计意图 |
|---|---|---|
| **完美防守 (Pristine)** | 0 栋建筑被毁 | 鼓励高水平防御 |
| **物理操控 (Physical)** | 用物理操作（坠渊 / 撞墙 / 撞石柱 / 接力推动）至少击杀 **3 个**敌人 | 鼓励使用核心机制而非纯输出 |
| **速战速决 (Swift)** | 击杀所有敌人且 ≤4 轮结束（提前击杀完毕） | 鼓励主动进攻 |
| **连锁达人 (Chain Master)** | 触发至少 **1 次接力推动连锁杀 2+ 个敌人** | 鼓励高难度物理操作 |

**完成数量奖励**：
- 完成 0 个挑战：基础奖励（6 余烬）
- 完成 1 个挑战：+2 余烬（共 8）
- 完成 2 个挑战：+4 余烬 + **额外 1 选 1 遗物机会**（共 10 + 遗物）
- 完成 3 个挑战：+6 余烬 + 额外遗物 + **守护值 +1**（救命惊喜）
- 完成全部 4 个挑战：+10 余烬 + 额外遗物 + 守护值 +1 + **解锁装饰性"守夜勋章"**（在 Run 结算屏显示）

> **设计意图**：5 场战斗的小 Run 结构本身重玩动力有限。挑战目标让玩家**重玩同一场战斗有意义**——第一次只为通关，第二次追"物理操控 + 速战速决"，第三次追"完美防守 + 连锁达人"。同时不强制——休闲玩家只完成主目标即可通关。
>
> **挑战目标的 UI 显示**（Oracle 审查 B4 修复）：
> - 战斗 HUD 上方显示**小被动核对清单**：4 个挑战目标各一行，含进度计数器（如"物理操控：1/3"、"速战速决：3/4 轮已用"）
> - **不弹窗**——避免分心。玩家自行查阅
> - 完成挑战瞬间 → 该行**勾选 + 短暂高亮**（不打断操作）
> - 结算屏汇总展示 4 个挑战完成情况 + 奖励发放
- **战斗失败 ≠ Run 失败**：Run 失败由 §6 守护值统一裁定

### 3.2 物理规则

**核心简化**：MVP 阶段不使用"质量 / 力 / 动量"等抽象概念。每个攻击/技能直接标注"伤害 X + 推 N 格"或"伤害 X + 拉 N 格"，玩家一眼看懂。

#### 推/拉的逐格结算

被推/拉的单位按指定方向**逐格移动**，每移动 1 格消耗 1 点推力：

| 经过的格子 | 结果 |
|---|---|
| **空格** | 单位滑入，剩余推力 -1，继续 |
| **墙壁（石柱 / 建筑）** | 单位停下 + 受 1 撞墙伤害 + 剩余推力作废 |
| **棋盘外缘** | 单位坠渊（立即出局） |
| **其他单位** | **触发接力**（详见下方） |

#### 接力推动（核心物理乐趣）

当推动中的单位 A 撞到另一个单位 B 时：

- **B 受 1 伤**（撞击伤）
- **剩余推力（N-1）传递给 B**：B 朝原推动方向继续移动 N-1 格，按上述规则结算
- **A 停在 B 原本所在的格子**
- **A 不掉血、不位移**（A 只是"撞到东西就停"）

> **设计意图**：保留"一发推飞链式传导"的策略乐趣（你的招牌爽感来自把炮灰群一发推下深渊），但用玩家能直接看懂的"推 N 格"表达，不再需要在心里算 M/F/P。

#### 坠渊判定

- 被推/拉出棋盘 → 立即坠渊
- 守卫者坠渊 = 本场永久离场
- 敌人坠渊 = 击杀 + 掉落余烬

### 3.3 布防阶段（独立阶段）

战斗开局首先进入**布防阶段**——采用 **ITB 风格的信息时序**：玩家看到棋盘结构和总轮数，但**不预知具体敌人类型**。

1. **棋盘揭示**：玩家看到完整棋盘——**建筑位置（含 HP）**、地裂位置、石柱位置、棋盘地形、深渊外缘
2. **轮次总览**：屏幕侧边显示"**本场战斗共 5 轮**"和"**已出现的敌人威胁等级提示**"（如"本场为标准战" / "本场为精英战"）。**不列举**具体敌人种类与数量
3. **守卫者部署**：玩家从 Run 池中放入 3 个守卫者到棋盘**边缘 2 格内**的空格
4. **点开战 → 进入第 1 轮**：第一批敌人从地裂中冒出 + 它们的预警同步揭晓

> **设计意图（ITB 信息风格）**：玩家在布防阶段看到的是"**地形结构**"——建筑要保护哪几栋、地裂在哪几个位置、石柱可以怎么用、深渊在哪几边。基于这个**通用防御网**做部署，而不是针对具体敌人种类做"反制阵容"。
>
> **每一轮的具体敌人是什么、它的预警行动是什么**——只在它**真正从地裂冒出来的那一刻**揭晓。这强化了"完美信息"的纯粹性：你知道的就 100% 可推演，你不知道的就是未知，没有"既看到种类又看不到细节"的中间态。

### 3.4 战斗轮次 1-5

> 📄 **本节为概要。精确步骤、AI plan 数据结构、锁定原则三条件、UI 威胁可视化规则、胜利条件细化 → 见 [design/round_flow_and_intent.md](design/round_flow_and_intent.md)**

每个轮次按以下严格顺序执行（**移动和攻击是同回合两个独立子阶段**，移动在回合开始时执行可见，攻击在回合末执行）：

1. **地裂出怪阶段**：上回合预告过的地裂冒出新敌人（此时才揭晓是什么）
2. **AI 全员规划**：每个敌人生成 plan（含移动落点 move_to + 攻击目标 attack_pos）
3. **敌方移动子阶段**（可见）：所有敌人逐个移动到 plan.move_to。新出怪也在此移动
4. **预告下回合出怪**：下一轮要出怪的地裂亮起金色 ↑ 标记
5. **玩家行动阶段**：操作 3 个守卫者（移动 + 攻击 + 撤回）。屏幕同时显示敌人当前位置 + 红色攻击意图箭头
6. **敌方攻击子阶段**：按 plan 执行攻击。**被推开的敌人 → 攻击落空**（锁定原则）
7. **建筑结算阶段**：所有命中建筑的攻击统一扣 HP；HP=0 → 被毁
8. **胜负检查**：守卫者灭团 → 败；敌人全清 + 无未来出怪 → 胜

> **锁定原则（形式化版）**：敌人本回合的攻击 plan 是锁定的，但**执行时**会做三项校验，任一失败则整个攻击落空（不造成伤害、不推动、不撞击）：
>   1. 敌人当前位置 == plan.move_to（玩家没把它推开）
>   2. plan.attack_pos 上的目标仍存活
>   3. 敌人与 attack_pos 仍邻接（双保险）

> **信息时序总结**：
> - **你知道**：移动子阶段执行完后，所有敌人的精确位置 + 它们的红色攻击箭头 + 当前回合的地裂预告
> - **你不知道**：下一回合预告的地裂会冒出什么类型的敌人（直到它在下回合步骤 1 真正出现）

> **首回合特例**：rift_schedule 默认从 round=2 开始预告，所以回合 1 没有地裂活动，玩家只面对初始放置的敌人。

### 3.5 原子结算顺序（关键规则）

任何攻击 / 推 / 拉 触发后，按以下顺序结算：

1. 锁定目标 T，结算伤害（T HP -1，但**不立即移除**，T 仍占格）
2. 给 T 朝击退方向赋予 N 点推力（N 来自攻击描述，如"推 1 格"）
3. 进入逐格推进循环：
   - **空格（盘内）** → T 滑入，剩余推力 -1，继续
   - **建筑** → T 撞建筑，建筑 -1 HP，T 受 1 撞墙伤，**T 获得碎裂状态**，剩余推力作废
   - **石柱** → 石柱 -1 HP，T 受 1 撞墙伤，**T 获得碎裂状态**，剩余推力作废
   - **棋盘外缘** → T 坠渊
   - **其他单位 U** → U 受 1 伤，**U 获得碎裂状态**，剩余推力（N-1）传递给 U，T 停在 U 原位置，U 继续按本流程推进（注意 T 不获得碎裂——只有被撞击的一方获得）
4. 推进结束 → 当前主体停在最终位置
5. 链中所有标记死亡的单位**统一移除**

> **核心规则**：
> - **原子链 = 纯物理事件**：一次攻击引发的所有推动/碰撞/坠渊在同一个结算链中完成
> - 0 HP 的单位**仍占格直到当前链结束**（不会因为死了就让出位置）
> - 链结束后立即清除所有 0 HP 单位
> - 地形效应（建筑 HP 扣除显示 / 地裂出怪等）由**回合末统一结算**，不在物理链内
> - 碎裂状态的具体效果详见 §3.6

### 3.6 状态效果：碎裂 (Cracked)

**碎裂**是 MVP 阶段唯一的状态效果——物理操作的副产物，强化"撞击/接力"的战术价值。

#### 触发条件（被动产生，玩家不能"主动施加碎裂"）

| 触发情境 | 是否产生碎裂 |
|---|---|
| 单位被推/拉撞到**建筑** | ✅ 撞击单位获得碎裂 |
| 单位被推/拉撞到**石柱** | ✅ 撞击单位获得碎裂 |
| 单位被推/拉撞到**另一个单位** | ✅ 被撞击的一方（U）获得碎裂；推动来的一方（T）不获得 |
| 单位被推/拉撞到**棋盘外缘**（坠渊） | ❌ 直接死亡，无意义 |
| 单位在**空格**中滑动 | ❌ 无碎裂 |
| 单位被**直接打死**（无撞击） | ❌ 已死亡，无意义 |

#### 效果

- **下一回合移动力 -1**（最低为 0，最低也就被钉在原地一回合）
- **下一回合结束时自动清除**（不需要主动清除机制）

> **重叠规则**：如果一个单位在已经处于碎裂状态时再次受到撞击 → 碎裂**刷新**（重置为"下一回合移动-1"），不会叠加为"移动-2"

#### 视觉表达

- **状态图标**：单位身上叠加红色裂纹符号（半透明）
- **预演 UI**：下回合预警阶段，敌人的移动范围预演会清楚显示"原本可达 X 格，因碎裂只能到 Y 格"（Y = X-1）

#### 战术意义

碎裂主要影响**高 HP 的硬目标**：
- **腐食兽 (HP=1)**：撞墙就死，碎裂无意义
- **瘟疫弓手 (HP=2)**：撞墙后剩 0 HP 直接死，碎裂极少触发；但若被撞**单位**接力（受 1 伤但不死）→ 下回合移动 -1 = **救命窗口**
- **铁角兽 (HP=3)**：被推撞墙 = 2 伤 + 碎裂 → **铁角兽下回合冲撞距离变短**，建筑获得救援空间
- **Boss 锚石 (HP=2)**：被推撞建筑 = 1 伤 + 碎裂（虽然锚石不移动，但碎裂效果保留——见特例）

> **设计意图**：碎裂不是"新动词"——它是物理操作的**奖励层**。让"撞墙 / 撞石柱 / 接力撞击"这些已存在的操作从"1 撞墙伤"升级为"1 撞墙伤 + 减速"，让玩家的精准物理操作有更深的回报。这是与 ITB 后继者（Othercide / Inkbound / Banners 等）的状态效果设计思路一致的轻量化版本。

#### 特例：锚石与建筑
- 锚石、建筑、石柱本身**不会获得碎裂**（它们不移动）
- 但 §11.6 tie-break 规则中：被赋予碎裂的敌人，下回合的"威胁度排序"会下调（因为它的攻击距离/位置变化）

## 4. 建筑机制

### 4.1 建筑是什么

**建筑 = 你必须保护的目标**。它们是棋盘上的固定结构，敌人朝它们攻击，建筑全毁则单场失败。

每场战斗 2-3 栋建筑（每张地图不同位置 / 不同数量），每栋有独立 HP，被任何敌人攻击命中即扣 HP，HP=0 即被毁。

### 4.2 建筑的属性

| 属性 | 值 |
|---|---|
| **HP** | **默认 2**（首击龟裂，二击崩塌）；少量地图变体使用 HP=1（脆弱型，作为特殊关卡设计） |
| **占位** | 1 格，**完全阻挡寻路 + 阻挡推动** |
| **可被推动？** | 否（不可移动） |
| **可被攻击？** | 是（被任何敌人攻击命中即扣 HP；玩家攻击不会扣建筑 HP——友军不可意外摧毁建筑） |
| **可踩上去？** | 否（建筑占据格子，单位不能站立） |

> **HP=2 的设计意图**：玩家在敌人**第一次攻击建筑后**有 1 个回合的救援窗口——可以推走/拉走/击杀威胁。这把"建筑保护"从二元判断（毁或不毁）变成有节奏的救援博弈。

### 4.3 建筑的视觉

每栋建筑是**斜俯视下的一座小型建筑**——可能是：
- **石塔**（圆柱形，顶部有锯齿）
- **观测台**（金属支架 + 风车/天文仪器）
- **修道院钟楼**（塔尖 + 十字架已腐蚀）
- **储物仓**（矮方块 + 木栅栏）
- **古井**（圆形井口 + 石柱顶盖）
- **坟丘**（土堆 + 倾斜的墓碑）

视觉上要**比单位略大**（占据 1 格但视觉占用更多），且**有清晰的"我是个东西"特征**。被打 1 HP 时**视觉龟裂**，被毁时**坍塌成废墟瓦砾留在格上**（不再阻挡寻路，但仍占地标记）。

### 4.4 建筑被毁的视觉与情绪

- **HP=2 → HP=1**：被首次攻击瞬间**屋顶龟裂 + 一阵尘烟扬起**（建筑仍立着，仍阻挡）
- **HP=1 → HP=0**：被再次攻击瞬间**屋顶塌陷 + 黑烟升起 + 建筑变成焦黑废墟（永久标记，不再阻挡）**
- **结算文字反馈**：屏幕角落浮现"**XX 建筑陷落**"（哥特字体，红色衬底）
- **背景音效**：石块崩塌声 + 一声叹息或哀嚎（暗示建筑里曾有人）

> **设计意图**：建筑必须**有名字、有形态**，让玩家觉得失去它**有重量**。你不是在保护一个抽象点位，你在保护**一座叫"碧落塔"的塔楼**——失去它有情绪重量。

### 4.5 敌人 AI 与建筑的关系

敌人核心目标 = **攻击建筑**。但与建筑保护机制配套，必须明确"什么时候敌人会攻击玩家守卫者"——否则玩家可以"跑远 + 远程清场"使建筑保护机制空心化。

#### 核心 AI 规则（3 条铁律）

##### 规则 1：敌人**永远**以建筑为最终目标

敌人**不会**因为玩家守卫者站远了就改变目标。即使所有守卫者都缩在角落，敌人仍然朝建筑前进。**玩家不能用"跑路诱敌"策略**——跑 = 让建筑暴露 = 输。

##### 规则 2：敌人在以下情况攻击守卫者（次要目标）

| 情境 | 敌人行为 |
|---|---|
| 守卫者站在敌人移动路径上 + 敌人**无法绕路**（绕路成本 >2 格）| **近战攻击该守卫者**（造成 1 伤），本回合放弃前进 |
| 守卫者站在弓手射线上 + 守卫者前方有建筑 | 弓手锁定**直线上第一个目标**（详见规则 3）|
| 守卫者站在铁角兽冲刺直线上 | 铁角兽冲刺被守卫者**挡停**：守卫者受 1 伤 + 推 2，铁角兽撞停在守卫者原位置（一击两得：铁角兽优先选这条路径，详见 §8.5 优先级） |

##### 规则 3：守卫者**会**阻挡敌人远程射线

弓手沿直线扫描射程 3 格时，**第一个挡线的目标**（守卫者或建筑）被锁定。这意味着：

- **诱敌挡线战术成立**：玩家可主动用守卫者挡在弓手与建筑之间 → 弓手射中守卫者（守卫者受 1 伤），建筑安全
- **友军挡线（玩家）和敌方挡线（弓手）规则一致**：守卫者既会被自己的远程攻击挡住（§7.2），也会挡敌人的远程攻击。规则对称，玩家可预演

#### 行为流程示例

```
每回合预警阶段（敌人决策树）：
  1. 计算"最近能攻击的建筑"（综合移动距离 + 攻击范围的总成本）
  2. 计算到达"攻击发起位置"的最短路径
  3. IF 路径上有守卫者挡路：
       IF 能绕路（≤2 格成本）→ 绕过去
       ELSE → 近战攻击该守卫者（本回合预警 = 攻击守卫者，不前进）
  4. IF 已经在攻击位置：
       近战敌人 → 攻击建筑（如果守卫者站在相邻位 = 守卫者优先于建筑被攻击）
       弓手 → 沿 4 方向直线扫描，锁定直线上第一个目标（守卫者或建筑，按距离）
       铁角兽 → 沿直线冲刺，撞到第一个单位/建筑/石柱时停止
  5. 玩家行动后改变了上述情况 → 锁定原则：本回合预警动作按原坐标执行，下回合重新计算
```

> **核心节奏特征**：敌人到位即攻击 = **硬空间压力**（瘟疫弓手到达射程内就立刻开打）。这不是慢慢爬条进度的休闲战棋，玩家从第 1 轮就要做关键决策。
>
> **设计意图**：上述 3 条铁律共同保证建筑保护机制不被"跑远 + 远程清场"破解——玩家必须主动介入战场（挡路、推开、击杀），不能消极防守。

## 5. 棋盘与地形

### 5.1 棋盘

- **尺寸**：固定 8x8
- **数量**：MVP 阶段 3-5 张地图骨架（每张地图建筑/地裂位置不同），1.0 后扩展到 8-12 张
- **视角**：45° 斜俯视（玩家从斜上方看下去，能看到深度——深渊真的下沉、建筑真的立着）

### 5.2 棋盘元素总览

| 元素 | 占位 | 阻挡寻路 | 可被攻击 | HP | 视觉 |
|---|---|---|---|---|---|
| **空格** | — | 否 | — | — | 风化石板 |
| **建筑** | 1 格 | 是 | 是（仅敌人可攻击）| **2** | 小型建筑（塔/观测台/钟楼） |
| **石柱** | 1 格 | 是 | 是 | **2** | 风化石柱（首击裂纹，再击碎裂） |
| **地裂** | 0（地面标记）| 否 | — | — | 红光裂缝 + 出怪预告 |
| **深渊** | 棋盘外 | — | — | — | 黑色 + 远处红光 |
| **废墟** | 0（地面标记）| 否 | — | — | 焦黑瓦砾（建筑被毁后留下）|

### 5.3 地裂（敌人出生点）

- **预告机制**：地裂在出怪前 1 轮亮起"出怪预告标记"。**不显示是什么敌人**，下一轮预警阶段才揭晓
- **被占据时的延迟规则**：地裂出怪那一轮，若被任何单位占据 →
  - **占据者受 1 点地底冲击伤害**
  - **出怪延迟 1 回合**（推迟到下一轮，标记保留）
  - **地裂本身保留**，不会消失
- **不可主动攻击**：玩家不能直接消除地裂，只能用"占据 + 吃伤"的方式延后
- **每回合新增**：1-2 个新地裂预告（由地图 + 难度决定）

> **设计意图**：把"压制 = 永久消除"改为"压制 = 延迟"。
> - 旧规则下"自杀堵门"是绝对最优策略（牺牲 1 守卫者 2 HP 换 1 个永久地裂消失）
> - 新规则下占据只是**争取一回合时间**（用于救建筑、清场、调整阵型）
> - 玩家可以反复占据同一地裂做"持续延迟"，但每次都要付 1 HP 代价——是真正的取舍

### 5.4 石柱（可破障碍）

- **HP=2**：首次受击 → 裂纹（仍阻挡）；再次受击 → 碎裂
- **不可被推动**
- **不可踩、阻挡寻路、阻挡推动**
- **战术价值**：
  - 主动用赏金猎人近战攻击 → 拆墙开路；或大魔法师远程魔法弹也可击碎石柱
  - 把敌人推飞撞石柱 → 敌人受 1（撞击伤）+ 石柱 -1 HP，可重复利用同一根石柱做连锁两次
- **敌人不会主动攻击石柱**（不在 AI 攻击优先级里）

> **HP=2 的设计意图**：石柱是推/拉物理的核心教学素材。HP=1 时一击碎，玩家精心计算的"撞石柱反弹"只能玩一次。HP=2 让石柱在整场战斗中持续作为战术资源。

### 5.5 深渊

- **棋盘外缘 1-2 圈**为深渊
- **被推出 = 坠渊死亡**
- **视觉**：黑色无底 + 偶尔有底部红光 + 边缘是破碎石板向下消失

## 6. Run 元结构（线性 5 场 + 守护值）

### 6.1 MVP Run 结构：线性 5 场战斗

> **MVP 阶段不做节点图分支**——线性 Run 先验证战斗本身好不好玩。节点图分支推迟到 1.0+。

```
[Run 开始]
   ↓
[战斗 1：教学场 — 仅腐食兽]
   ↓
[战斗 2：教学场 — 腐食兽 + 瘟疫弓手]
   ↓
[战斗 3：完整教学场 — 全部三种敌人]
   ↓
[营地：修复 +2 守护值 或 2 选 1 遗物]
   ↓
[战斗 4：精英战 — 高难度变体]
   ↓
[商店：未获得遗物购买（每个 10-12 余烬）/ 修复 4 余烬 = +1 守护值]
   ↓
[Boss 战：裂心钟主]
   ↓
[Run 结算]
```

- **战斗总数**：5 场（4 普通 + 1 Boss；其中第 4 场是精英变体，但仍是普通战的难度强化版）
- **非战斗节点**：1 个营地 + 1 个商店（固定位置在 Boss 前，不是分支）
- **路径选择**：无（线性推进）
- **总时长**：1 小时左右一个 Run

> **设计意图**：MVP 阶段牺牲"路径选择"的 Run 级乐趣，换取"先把战斗本身做好"的聚焦。1.0+ 阶段升级为节点图分支结构，玩家可以选择"走精英路 vs 安全路"等。

### 6.2 节点类型（MVP 简化版）

MVP 阶段只有 5 种节点：

| 节点 | 视觉 | 内容 |
|---|---|---|
| **战斗 (Battle)** | 红色剑符号 | 一场标准战斗（5 轮次，2-3 栋建筑），通关获 **8 余烬基础** + 挑战目标奖励（详见 §3.1）+ 杀敌奖励（详见 §6.5，每场上限 +10）。完成 ≥2 个挑战目标 → 额外 1 选 1 遗物机会 |
| **精英 (Elite)** | 红色头骨符号 | 高难度战斗（敌人 +30%、必含铁角兽精英版），通关必获 **1 个遗物** + **12 余烬基础** + 挑战目标奖励 + 杀敌奖励（每场上限 +10）|
| **营地 (Camp)** | 黄色火焰 | 二选一：**修复 +2 守护值** 或 **2 选 1 遗物**（免费，从未获得池子里选）|
| **商店 (Shop)** | 金色钱袋 | 用余烬买：**1-2 个未获得的遗物**（10-12 余烬/个）/ 守护值修复（4 余烬 = +1）|
| **Boss** | 黑色王冠 | 终极 Boss 战（裂心钟主，详见 §8.7 / [boss 文档](design/boss_knell_lord.md)）。**Boss 战杂兵不给余烬**（避免无限刷）。通关给 **15 余烬** |

> **遗物池管理**：MVP 只有 4 个遗物，每场 Run 最多拿到 3 个（不会全部拿到）。所有遗物选项都从"未获得"池子里抽取——避免给玩家重复选项。
>
> **挑战目标的额外遗物机会**：单场战斗中完成 ≥2 个挑战目标解锁的"额外遗物"是从该战斗节点本来不给遗物的情况下额外提供——不会与营地/精英战的遗物机会重复消耗池子。MVP 总遗物池只有 4 个，挑战目标只是加快了拿到遗物的速度。
>
> **MVP 不做的节点类型**（推迟到 1.0+）：
> - ❌ 守卫者升华（节点奖励选项）— MVP 不做升华
> - ❌ 卡牌购买 — MVP 不做卡牌

### 6.3 守护值(Sanctuary Integrity)—— Run 级失败裁定

**弹性失败结构**——这是与 ITB 的"4 个建筑等于 4 条命"不同的设计：单场可以亏损但不立即输掉 Run。

- **初始值**：每个 Run 开始时 = **7**
- **结算时机**：每场战斗结束后扣
  - 完美防守（0 建筑被毁）→ 守护值 **-0**
  - 1 栋建筑被毁 → 守护值 **-1**
  - 2 栋建筑被毁 → 守护值 **-2**
  - 全部建筑被毁（单场失败）→ 守护值 **-3**
- **Run 失败**：守护值 ≤ 0 → 整 Run 结束
- **Run 胜利**：通关 Boss 战 + 守护值 > 0
- **恢复**：营地 +2 守护值 / 商店 4 余烬 = +1 守护值

### 6.4 守卫者 Run 池

- **Run 开始时**：3 个基础守卫者各 1 个（赏金猎人 / 盗墓人 / 大魔法师）
- **每场战斗布防阶段**：3 个守卫者**全员出战**（MVP 阶段无重复选、无替补、无升华）
- **跨场死亡规则**：守卫者本场死亡 → 战斗结束后回 Run 池满血归位

> **MVP 简化**：不做"守卫者池扩充"——3 个基础守卫者贯穿整个 Run。1.0+ 阶段加入升华系统 + 重复选机制 + 更多守卫者类型。

### 6.5 余烬（Ember）—— 货币

> **Oracle 审查 CRITICAL A4 修复**：原版每杀给余烬 + Boss 战无回合上限 + 持续刷怪 = **无限农场漏洞**。以下是闭环版经济。

**主要收入来源（Oracle 推荐：节点固定奖励为主，杀敌奖励为辅）**：

| 来源 | 奖励 |
|---|---|
| **普通战通关** | 基础 **8 余烬** + 挑战目标奖励（详见 §3.1 阶梯） |
| **精英战通关** | 基础 **12 余烬** + 1 个遗物（必给）+ 挑战目标奖励 |
| **Boss 战通关** | **15 余烬** + Run 结算 |

**杀敌奖励（次要来源，仅普通战 + 精英战）**：

- 腐食兽 1 / 瘟疫弓手 1 / 铁角兽 2 / 铁角兽精英 3
- **每场战斗杀敌奖励上限**：**+10 余烬**（超过部分不给，防止刷战术）
- 击杀方式不限（攻击 / 撞墙 / 坠渊 / 地裂压制 / 友军误伤都给）

**Boss 战经济特例**：

- ❌ **Boss 战的杂兵（地裂出怪）不给余烬**（避免无限刷漏洞）
- ❌ Boss 战只给"通关 15 余烬"作为结算
- ✅ 锚石击破 / 心脏钟击中本身**不给余烬**（不是杀敌）
- ✅ Boss HP=0 = 战斗胜利结算 = 15 余烬

**MVP 阶段用途**（仅 2 项）：

| 用途 | 价格 |
|---|---|
| **遗物购买** | 10-12 余烬（商店从未获得池子里选）|
| **守护值修复** | **4 余烬 = +1 守护值**（商店）|

**不用于**：

- ❌ 战中使用（MVP 没有战中卡牌系统）
- ❌ 守卫者升华（MVP 不做）
- ❌ 卡牌（MVP 不做）

#### Run 经济预算（理论范围）

```
基础收入：
  4 场普通战通关 = 4 × 8 = 32
  1 场精英战通关 = 12
  Boss 战通关 = 15
  → 基础收入 = 59 余烬
  
杀敌奖励（保守估计每场 6-8）：
  4 场 × 6 = 24-32
  
挑战目标奖励（每场 2-4）：
  4 场 × 3 = 12

预期 Run 收入：约 95-105 余烬
预期 Run 支出：2-3 个遗物（20-36）+ 修复 2-3 次（8-12）
预期 Run 结余：~50-70 余烬

  → 紧但不窒息。原型期需平衡微调。
```

> **设计意图**：MVP 阶段余烬经济**收入相对固定 + 支出受控**——避免 ITB 经济太松导致"拖时间刷怪"成为最优策略。原型期可调价格或杀敌上限。

### 6.6 遗物（Relic）—— MVP 4 个

**遗物是跨场战斗的永久 buff**，是 MVP 阶段提供"每个 Run 体验不同"的核心机制。每个遗物只改一件事，保持"读完即懂"。

#### 设计原则

1. **每个遗物只改一件事**——不要"+10% 伤害 + 移动+1 + 推力+1"这种多重 buff
2. **2 个改守卫者能力，2 个改通用资源**——多样性 + 经济兼顾
3. **每个遗物影响必须可见**——玩家拿到后能立即感受到变化（不要"30% 几率触发 X"这种隐形效果）
4. **每场 Run 最多拿到 3-4 个**（来自营地 / 商店 / 精英战奖励）

#### MVP 4 个遗物清单

| 遗物 | 类型 | 效果 |
|---|---|---|
| **链锤改装 (Reforged Flail)** | ★ 改能力 | 赏金猎人的近战攻击效果改为 **1 伤 + 推 2 格**（从推 1 升级到推 2） |
| **长杖共鸣 (Resonant Staff)** | ★ 改能力 | 大魔法师的远程魔法弹射程改为 **4 格**（从 3 格升级到 4 格） |
| **碎裂猎人 (Cracksbane)** | ★ 协同 | 任何守卫者攻击**已处于碎裂状态**的敌人时，伤害 +1（1 伤 → 2 伤） |
| **连锁共鸣 (Chain Resonance)** | ★ 协同 | 接力推动链中（A 撞 B，B 继续推动撞 C）的**第二个被撞者及之后**，额外受 1 伤 |

#### 4 个遗物的设计意图（全部影响动词/战术）

##### 链锤改装（改能力）
赏金猎人推 1 → 推 2 → 撞墙时 = 1 伤 + 1 撞墙伤 + 碎裂 → **对铁角兽极其有效**（HP=3 → 一击 2 伤 + 减速）

##### 长杖共鸣（改能力）
大魔法师射程 3 → 4 → 几乎能从棋盘一端打到另一端 → **可以从安全距离把任何敌人推下深渊或撞墙**

##### 碎裂猎人（协同）
所有守卫者攻击碎裂敌人 → 伤害变 2。这创造一个**清晰的两步战术循环**：
- 第一步：用任何方式制造碎裂（撞墙/接力撞击）
- 第二步：任何守卫者跟进一击 = 2 伤
- 这让"先制造碎裂、再补刀"成为重要战术
- 对 HP=2 的弓手 / HP=3 的铁角兽特别有效

##### 连锁共鸣（协同）
接力推动链上的第二个被撞者+ 受额外 1 伤。这鼓励**主动制造长接力链**：
- 把 3 只腐食兽排成一线，一发推飞 = 第 1 个 1 伤 + 第 2 个 2 伤 + 第 3 个 2 伤
- 配合赏金猎人的"链锤改装"（推 2）→ 接力链更容易触发
- 这让"棋盘地形 + 敌人排列"变成主动思考的战术维度

> **设计意图**：原版 4 遗物中有 2 个"通用资源型"（守夜人徽章、应急修缮）被替换为**协同型遗物**。新设计的 4 遗物**全部都是战术变体**——没有"平淡的资源 buff"。这与 ITB 后继者（Othercide / Inkbound / FITS / Banners）独立收敛到的"协同 + 状态效果"设计共识一致。
>
> **遗物协同矩阵**：玩家如果拿到多个遗物，会出现协同放大效果：
> - 链锤改装 + 碎裂猎人 = 赏金猎人推 2 撞墙 → 制造碎裂 → 任意补刀 2 伤
> - 长杖共鸣 + 连锁共鸣 = 大魔法师从远处推动产生长接力链 → 后排敌人受额外伤害
> - **任意两个组合都能产生"我发现了一个组合"的爽快感**

#### 1.0+ 扩展（先不做）

- 更多改能力遗物（盗墓人射程 +1、赏金猎人攻击后追加移动 2、大魔法师推 2 等）
- 更多协同型遗物（"两个守卫者站相邻 1 格时，攻击+1"、"地裂占据者的下回合行动 +1"等）
- 负面遗物（"守护值上限 -2，但敌人数量 -20%"——风险/收益型）
- 12+ 个遗物池（从 4 扩展）

> **MVP 为何只有 4 个**：足够让玩家在 1 个 Run 内拿到 2-3 个产生变化，但少到玩家不会面临"选哪个"的认知负担。1.0+ 再扩池子。

## 7. 3 个守卫者（MVP）

### 7.1 设计原则

1. **形象 → 功能**：每个守卫者的外貌一眼看出它是干嘛的
2. **机制差异化**：3 个守卫者覆盖"近战推 / 远程拉 / 远程推"三类动词，构成物理三角
3. **数值精炼**：HP/移动力/攻击效果 用单一数字表达，让玩家精确推演连锁结果

### 7.2 守卫者总览（MVP）

| 守卫者 | HP | 移动 | 攻击 | 类型 |
|---|---|---|---|---|
| **赏金猎人 (Bountyhunter)** | 2 | 2 | 近战 4 方向相邻 1 格 → 1 伤 + 推 1 | 近战推 |
| **盗墓人 (Graverobber)** | 2 | 2 | 远程 4 方向直线 3 格 → 1 伤 + 拉 1 | 远程拉 |
| **大魔法师 (Mage)** | 2 | 2 | 远程 4 方向直线 3 格 → 1 伤 + 推 1 | 远程推 |

> **远程攻击的友军规则**（盗墓人 / 大魔法师）：远程直线 3 格扫描时**会被友军挡线**——玩家自己的单位站在直线上 → 锁定友军前方第一个目标。这要求玩家自己管理阵型，避免互相挡线。

### 7.3 赏金猎人 (Bountyhunter)

**追猎者**——专门追捕被通缉的灵魂、亡灵、变异者。被诅咒之地的赏金猎人不是为了正义，是为了**赏金 / 赎罪 / 一份未尽的契约**而战斗。

| 项 | 内容 |
|---|---|
| **形象** | 身披深色长大衣、戴宽檐帽 + 半脸面罩的人形；腰间挂多个皮带和小袋（弹药 / 通缉令卷轴 / 短刀 / 手雷）；**单手持短斧 / 链锤 / 弯刀**之一（视觉锚点是"实用的近战武器"）；姿态是**警觉的半蹲**——随时准备扑上去；胸前别着一个带血迹的铜质徽章（赏金猎人公会的标记）|
| **形象 → 功能** | 大衣 + 兜帽 = 暗黑哥特"追猎者"；短武器 = 一眼近战；半蹲姿态 = 暗示"机动追击 + 多次出手"；铜徽章 = 暗示"职业身份 / 是有契约的人，不是疯子" |
| **核心动作** | 近战攻击 4 方向相邻 1 格 → 1 伤 + 推 1 格 |
| **特例规则** | **近战攻击后可额外移动 1 格**（必须是 4 方向相邻空格）——攻击后留出"切完即走"的机动空间 |
| **战术定位** | 切入型近战 / 配合远程守卫者完成击杀 / 推炮灰送渊。攻击后额外移动让她可以"打了就跑"，避免被多个敌人围攻 |
| **1.0+ 升华路线**（MVP 不做）| • **追加猎杀**——若近战击杀（HP 归零）一只敌人，恢复一次完整行动权（同回合可击杀多个 HP=1 敌人）<br/>• **撞墙不受 1 伤**——专注于追击不被自身物理代价拖累<br/>• **近战攻击后追加 2 格移动**——更高的机动性<br/>• **重型契约**——攻击效果变为"1 伤 + 推 2"，可用普通推力对付硬目标 |

### 7.4 盗墓人 (Graverobber)

**钩链流浪者**——以盗墓为生的边缘人，被诅咒之地里干这行的人很多，因为这片土地的尸体上常常带着不该被埋葬的东西。盗墓人的工具——**带铁钩的长链** + **铲子 + 撬棍**——成了她在末更守夜战中的兵器。

| 项 | 内容 |
|---|---|
| **形象** | 穿磨损粗布外套 + 长靴的人形；**头戴破旧宽檐帽 + 黑布蒙面**（只露一双眼睛）；**单手紧握盘起的铁链，链头是粗大的铁钩**（视觉锚点）；腰带上挂铲子 / 短撬棍 / 几个磨损布袋；姿态略蹲，像是"在墓地里偷偷摸摸打开棺材的人"；身上有泥土污渍 |
| **形象 → 功能** | 铁钩+长链 = 一眼远程拉（这就是盗墓人的工具）；蒙面 + 宽檐帽 = 神秘 / 阴郁 / 暗黑哥特；蹲姿 = 暗示"潜行追猎"而非正面冲突 |
| **核心动作** | 远程拉攻击 4 方向直线 3 格（被友军/敌人/建筑/石柱阻挡）→ 1 伤 + 拉 1 格朝盗墓人方向 |
| **战术定位** | 把敌人拉到自己面前集中处理 / 拉脱弓手脱离射程 / 拉到石柱前撞死。**3 格射程**让她能从相对安全的距离开战。注意要管理与友军的站位，避免互相挡线 |
| **1.0+ 升华路线**（MVP 不做）| • **斜钩**——拉力可对角线（8 方向）<br/>• **双钩**——同方向同时拉锁定目标 + 相邻 1 个友军（援护）<br/>• **反钩**——拉力可反转为推（"用钩子顶飞它"）<br/>• **抽身**——拉后追加移动 1 格<br/>• **强力拉**——攻击效果变为"1 伤 + 拉 2" |

> **设计意图（两个角色的对比）**：
> - **赏金猎人**是**进攻型 / 速度型 / 多次出手** —— 她冲到敌人面前一刀切，再换下一个目标
> - **盗墓人**是**控场型 / 距离型 / 单次出手** —— 她从远处把敌人钩过来，配合赏金猎人的近战或大魔法师的魔法弹完成击杀
>
> 两者完美互补：盗墓人**拉**敌人 → 赏金猎人**冲**过去打。这是 MVP 的核心战术循环。

### 7.5 大魔法师 (Mage)

**远程魔法推手**。手持法杖发射魔法弹推走敌人，与盗墓人的"远程拉"对偶。

| 项 | 内容 |
|---|---|
| **形象** | 一名披着深色长袍、戴兜帽的人形；袖口露出符文绑带；**手持长法杖，杖头悬浮一团青色魔法能量**；姿态站立、法杖稍前伸；袍上有古老符文 |
| **形象 → 功能** | **法杖+魔法能量** = 一眼远程魔法攻击；兜帽+长袍 = 法术使者；魔法能量的青色与玩家阵营色一致 |
| **核心动作** | 远程魔法弹：沿 4 方向直线扫描射程 3 格（被友军/敌人/建筑/石柱阻挡）→ 锁定第一个目标 → **1 伤 + 推 1 格远离大魔法师方向** |
| **战术定位** | 远程推手——可送敌人下深渊 / 撞石柱 / 撞建筑 / 推到盗墓人想要的位置触发连锁。与盗墓人对偶：盗墓人"拉过来"、大魔法师"推出去"，两个远程动词覆盖所有空间操作场景 |
| **1.0+ 升华路线**（MVP 不做）| • **强化魔法弹**——攻击效果变为"1 伤 + 推 2"<br/>• **召唤石柱**——在指定空格生成临时石柱（持续 2 回合，HP=1，会自动消失）<br/>• **路径改写**——施法变体，选 1 个敌人改写其下回合移动路径绕远 +2 格（曾考虑作为 MVP 核心动作，因复杂度过高推迟到升华）<br/>• **二段施法**——攻击后恢复 1 次移动 |

> **设计意图（MVP 简化）**：MVP 阶段大魔法师**只有一个动作**——远程推。这让 3 个守卫者的动词清晰对称：
> - 赏金猎人 = 近战推（短距离精确）
> - 盗墓人 = 远程拉（拉到自己面前处理）
> - 大魔法师 = 远程推（推到地形上处理）
>
> 路径改写曾考虑作为 MVP 第二动作（"让敌人下回合多绕 2 格"），但有 3 个问题导致推迟到 1.0+：
> 1. 延迟生效，往往不如直接推一下立竿见影
> 2. 实现 UI 复杂（要预演敌人改写后的新路径）
> 3. 它承载了"全游戏唯一非 ITB 动词"的差异化重量，单一技能扛不动
>
> MVP 先把"3 个推/拉动词的物理乐趣"做扎实，1.0+ 再加路径改写等节奏控制类技能。

> **玩家心智模型一句话**：
> **"远程推一格——可以一个人当半个盗墓人，反方向干活。"**

## 8. 敌人

### 8.1 敌人设计原则

1. **形象 → 功能**：暗黑地牢式"曾经是 X，现在腐败了"，每个敌人形态强烈差异化
2. **行为可预测**：敌人 AI 极度可预测——智能感来自组合，而非个体复杂度
3. **MVP 阶段 3 种 + 1 精英变体**：覆盖"近战 / 远程 / 冲撞"三种威胁类型
4. **1.0+ 扩展到 10-15 种**（含蓄力远程、传送干扰、自爆等新行为类型）

### 8.2 敌人总览（MVP 3 种 + 1 精英变体）

| 敌人 | HP | 移动 | 攻击 | 行为类型 |
|---|---|---|---|---|
| **腐食兽 (Carrion Spawn)** | 1 | 2 | 近战相邻 1 格 → 1 伤 | 被动近战 |
| **瘟疫弓手 (Plague Archer)** | 2 | 2 | 远程直线 3 格 → 1 伤 | 被动远程 |
| **铁角兽 (Ironhorn Beast)** | 3 | 2 | 直线冲刺最多 3 格（停于首障）→ 1 伤 + 推 2 | 主动冲撞 |
| **铁角兽精英 (Elite)** | 4 | 2 | 同铁角兽，但推力 = 3 | 主动冲撞（精英战使用）|

**敌人配比**：
- 腐食兽：35-40%（基础威胁）
- 瘟疫弓手：30-35%（远程压力）
- 铁角兽：20-25%（节奏关键，至少 1 个出现在轮次 3）

> **关于"铁角兽精英"**：仅在精英战（§6.1）出现，HP 和推力提升但移动力不变，避免变成"绕图飞奔"的混乱单位。

> **1.0+ 推迟的敌人**（设计稿见附录或后续版本）：
> - 诅咒巫师 (Cursed Caster) — 蓄力远程，引入"时间窗口管理"
> - 腐土钻地虫 (Burrower) — 通过地裂传送，引入"全图威胁"

### 8.3 腐食兽 (Carrion Spawn) — HP 1

- **形象**：小型四足扭曲生物，骨瘦如柴、像被剥皮的犬科 + 多余关节；皮肤泛灰绿、背部外露脊椎；无眼、张嘴
- **行为**：朝最近能攻击建筑的位置行进。挡路时绕路（≤2 格）或近战攻击挡路守卫者
- **战术意义**：基础威胁 / 连锁素材；紧贴排列时是接力推动的最佳教学（一发推飞链式传导）

### 8.4 瘟疫弓手 (Plague Archer) — HP 2

- **形象**：直立人形，戴鸟嘴医生面罩、披褴褛长袍；持骨弓 / 投掷标枪；姿态是"已搭好箭蓄力"
- **行为**：朝建筑射程内的位置行进。每回合预警阶段检查**4 方向直线 3 格内是否有可被击中的单位**（守卫者 / 建筑 / 其他敌人）→ 若有则锁定**直线上第一个单位**实施远程攻击；若无则正常行进
- **关键 1**：弓手锁定的是**直线上第一个单位，无论类型**——**没有"建筑优先权"**。这意味着身体挡线战术成立（玩家把守卫者放在弓手和建筑之间，弓手会射中守卫者）
- **关键 2**：瘟疫弓手**不会主动避开会误伤友军的射线方向**（玩家可主动布置"诱敌挡线"战术，让弓手射死自己人）
- **战术意义**：远程压制；引入"距离 ≠ 安全"的战术张力。**HP=2** 意味着玩家必须用物理操作（拉脱射程、推到位、挡线）而不是直接秒杀

### 8.5 铁角兽 (Ironhorn Beast) — HP 3

- **形象**：大型双足/四足混合怪物，肌肉发达；头顶弯曲铁角；姿态低头冲刺；蹄下扬尘
- **行为**：每回合预警阶段，朝最近能撞到建筑或玩家守卫者的方向选定一条**直线冲刺路径**（最多 3 格）：
  - 冲刺路径上遇到**第一个单位/建筑/石柱时立即停止**
  - 撞击效果：**1 伤 + 推 2 格**（被撞者按 §3.5 原子结算流程承受推动）
  - 若冲刺方向上没有任何东西可撞 → 沿该方向移动到最近的建筑或守卫者邻位
- **优先级**：优先选择"撞到玩家守卫者 + 后方有建筑"的方向（一击两得，详见 §11.6 tie-break）
- **战术意义**：高 HP 硬钉子，**必须用物理操作把它的冲刺路径打偏**——用石柱挡、用守卫者引开、用大魔法师推走（推 1 格能让它的冲刺路径改向）。直接打死需要 3 次命中

### 8.6 与建筑的关系

所有敌人的**核心目标都是攻击建筑**（详见 §4.5 的 AI 铁律）：

- **腐食兽** → 移动到建筑相邻格 → 攻击建筑 1 伤
- **瘟疫弓手** → 移动到攻击范围内 → 远程攻击建筑 1 伤（射线被守卫者挡住时锁定守卫者）
- **铁角兽** → 直线冲到建筑前 → 撞击建筑 1 伤（冲刺路径上有守卫者时撞守卫者，详见 §8.5 优先级）

**玩家干预手段**（每个敌人都有多种解法）：
- **推开/拉走**：让它本回合的预警攻击落空 + 移到不能攻击建筑的位置
- **击杀**：腐食兽 HP=1 一击就死；弓手 HP=2 需要 2 次伤害；铁角兽 HP=3 需要 3 次伤害（或撞墙/撞石柱/坠渊补刀）
- **挡路**：把守卫者放在敌人和建筑之间——敌人无法绕路时会近战攻击你（守卫者扛伤换时间）
- **挡线**：把守卫者放在弓手射线上 → 弓手射中守卫者，建筑安全（人肉盾牌战术）
- **撞地形**：把敌人推/拉到石柱前撞死、推下深渊瞬间击杀

> **关键**：以上所有干预手段都**需要玩家主动介入战场**——不能消极防守。详见 §4.5 的 AI 铁律 1（敌人不追玩家，只攻建筑）。

### 8.7 Boss 设计：裂心钟主 (Knell Lord)

> 📄 **完整设计已拆分到独立文档**：[design/boss_knell_lord.md](design/boss_knell_lord.md)

**概要**：MVP 唯一 Boss，盘外悬浮的巨大钟体。

**关键机制**：
- **盘外本体**（视觉装饰）+ **盘内心脏钟（中央 1 格弱点）** + **2 块锚石**（HP=2）
- 锚石活着 → Boss 锁链相（心脏钟金属覆盖，不可被攻击）
- 锚石全毁 → Boss 暴露相 3 回合（心脏钟可被任意动词命中）
- 心脏钟 HP=3，3 回合内累计 3 伤 → Boss 死亡
- Boss 未死亡时暴露相结束 → 锚石重生 2 块 + 回到锁链相（Boss HP 保留）

**Boss 回合脚本**（每回合执行 1 个动作，循环 1→2→3→4→1）：
1. 召唤潮（所有地裂倒计时归零）
2. 横扫钟波（1 行/列推 2 格 + 1 伤）
3. 锚链脉冲（锚石周围敌人 +1 移动，叠加上限 +1）
4. 静默（喘息回合）

**胜利条件**：3 个暴露相回合内累计对**心脏钟**造成 3 伤。
**失败条件**：所有保护建筑被毁 → 单场失败 → 守护值 -3。
**经济特例**：Boss 战的**杂兵不给余烬**（避免无限刷农场），仅 Boss 击杀给 15 余烬。

**详细机制 / 设计意图 / 待敲定项 → 见独立文档**。

## 11. UI 与符号

### 11.1 默认精确预演 UI（精简版）

完美信息游戏的精髓 — **所有当前已揭晓的信息默认即可见**。但**避免信息过载**：只显示玩家做决策必需的信息，不逐格渲染中间过程。

- 棋盘上**已出现的敌人**下回合行动意图（移动落点 + 攻击范围 + 攻击伤害 + 锁定目标）
- 玩家操作后：**只显示连锁最终结果**（所有单位的最终位置 + 总伤害），不逐格显示中间推动过程
- 坠渊判定、撞墙伤害、石柱破碎预演（仅最终结果）
- **碎裂状态**：被撞单位上方显示裂纹图标 + "下回合 -1 移动"文字
- **碎裂单位下回合的减速**：移动范围自动按 -1 后格数显示（合并到敌人意图显示中，不单独做一层）
- **建筑 HP 变化预测**：**只标注本回合会被攻击的建筑**（在建筑旁显示"⚠ -1"），不标注所有建筑
- **地裂的出怪预告标记**：标记位置 = 下一轮会出怪，但**不显示是什么敌人**（ITB 风格）
- **总轮数与当前轮数**（如"第 2 / 5 轮"）

> **精简原则**：ITB 实际只显示"最终会发生什么"，不显示"中间每一步怎么发生"。连锁预演同理——玩家关心"推完之后谁在哪、谁死了"，不关心"第 1 格推到第 2 格再推到第 3 格"的逐格动画。

### 11.2 移动范围可视化（ITB 风格）

- 点选守卫者 → **高亮所有可达落点格**（不显示路径）
- 可达集按 4 方向 A* 计算
- 障碍切断身后区域 → 形状不规则
- 视觉：**苍白冷青地面叠加层**（4 色编码中的"玩家方"色；柔和半透，暗黑哥特式"冰冷月光"色）

### 11.3 颜色编码（精简至 4 色）

| 颜色 | 含义 | 用途 |
|---|---|---|
| **苍白冷青** | 玩家方 | 守卫者、可达集、玩家攻击预演（柔和半透，暗黑哥特式"冰冷月光"色） |
| **金色** | 保护目标 | 建筑、锚石 |
| **暗红** | 威胁 | 敌人攻击命中格、建筑将被毁、友军挡线警告、碎裂状态裂纹图标 |
| **洋红** | 敌方 | 敌人单位、敌人移动预警轨迹 |

> **精简原则**：7 色需要玩家记忆映射 → 4 色按"谁的东西"分（我方/保护/威胁/敌方），直觉可读。石柱和不可达格用**默认暗色**（不加特殊颜色）。友军挡线警告合并到暗红色（都是"别这么做"的信号）。碎裂裂纹图标也用暗红（都是伤害信号）。

### 11.4 守护值 UI

屏幕顶部：**羊皮纸卷上的红色印章** — 7 个印章，每损失一个就被划掉。

### 11.5 战斗 HUD

**顶部 HUD**：
```
[守护值: 7/7] [轮次 3/5] [余烬: 23] [建筑: 3/3 存活]
```

**侧边挑战目标核对清单**（Oracle 审查 B4 修复）：
```
本场挑战目标：
  ☐ 完美防守：0/0 建筑被毁  ✅ 进行中
  ☐ 物理操控：1/3 物理击杀
  ☐ 速战速决：3/4 轮已用  ⚠️ 剩 1 轮
  ☐ 连锁达人：0/1 接力杀 2+
```

设计原则：**被动显示，无弹窗**。玩家自行决定追哪个挑战。

### 11.6 决定论规则与战斗节奏

> 📄 **完整设计已拆分到独立文档**：[design/ui_decision_rules.md](design/ui_decision_rules.md)

该独立文档定义：
- **敌人 AI tie-break 规则**（同距离选路、远程射击优先级、铁角兽冲刺方向）—— 实现 AI 决策树时必读
- **战斗轮次出怪预算**（5 轮每轮敌人数量、敌人配比、精英战配比、威胁预算硬上限）
- **ITB 风格信息时序提示**（战斗开始 / 每轮末 / 下轮预警的具体 UI 显示）

主策划案 §4.5 的"敌人 AI 三铁律"定义"敌人攻击谁"，独立文档定义"多个可能性中如何精确抉择"——二者配套使用。

### 11.7 教学入门阶段（前 3 场战斗）

新玩家的前 3 场战斗按以下顺序教学（不是教学关卡 = 是普通战斗但敌人配比受控）：

| 战斗 | 敌人配比 | 棋盘元素 | 教学目标 |
|---|---|---|---|
| **第 1 场** | 仅腐食兽（**4 个**，按 2/1/1/0/0 节奏出怪）| 1 张地图 + 2 栋建筑 + **1 块石柱（强制放在关键位置）** | 学会移动、近战攻击、推 1 / 拉 1、建筑保护、**强制学会接力推动连锁**（地图设计成把 2 只腐食兽推飞撞 1 栋建筑是最优解）|
| **第 2 场** | 腐食兽 + 瘟疫弓手 | 1 张地图 + 3 栋建筑 + 2 块石柱 + 深渊四边 | 学会远程对抗、射线净空、撞石柱连锁、友军挡线规则、**碎裂状态**（撞墙/撞石柱产生） |
| **第 3 场** | 全部三种敌人 | 1 张地图 + 3 栋建筑 + 多个石柱 + 深渊 | 学会铁角兽冲撞的应对（用石柱挡 / 推偏方向 / 撞墙施加碎裂减速）、地裂占据延迟规则 |

**教学方式**：
- **首次出现某机制时**，屏幕弹出**羊皮纸式提示卡**（哥特字体，单句话讲解）
- 提示卡可手动关闭，关闭后**整个 Run 不再弹出**（再玩新 Run 自动跳过教学战斗）
- 不做单独的"教学关卡"——直接在第 1-3 场战斗内嵌教学

| **守卫者重复选** | **❌ 不允许重复**（3 种全员出战，无选择空间）| 推迟到 1.0+ |
| **守卫者升华** | **❌ MVP 不做** | 推迟到 1.0+ |
| **敌人** | **3 种**（腐食兽 HP=1 / 瘟疫弓手 HP=2 / 铁角兽 HP=3）+ **1 个精英变体**（铁角兽精英版：HP=4，推力 3） | 砍掉诅咒巫师、腐土钻地虫 |
| **建筑** | 2 种视觉变体（石塔 / 钟楼），**HP 默认 2** | 留 HP=1 脆弱型变体作为特殊地图设计 |
| **棋盘** | **2 张地图骨架** | 砍掉到 2 张，给 UI 调试留时间 |
| **Run 结构** | **线性 5 场战斗**（4 普通 + 1 Boss）+ 守护值 | 不做节点图分支 |
| **卡牌系统** | **❌ MVP 不做卡牌** | 推迟到 1.0+ 第 1 版迭代 |
| **遗物** | **4 个基础遗物**（已有初步设计，详见 §6.6）：2 个改守卫者能力 + 2 个协同遗物 | 来自营地 / 商店 / 战斗奖励 / 挑战目标 |
| **状态效果** | **碎裂状态**（撞墙/撞石柱/接力撞击产生，下回合 -1 移动力，详见 §3.6）| 唯一状态，与协同遗物深度联动 |
| **挑战目标** | 每场 4 个挑战目标（完美防守 / 物理操控 / 速战速决 / 连锁达人），完成数量奖励梯度 | TBW 风格，详见 §3.1 |
| **节点类型** | 战斗 / 精英 / 营地 / 商店 / Boss（5 种）| 简化的线性流 |
| **Boss** | 1 个 Boss（裂心钟主，详见 §8.7） | 完整脚本 |
| **美术** | 3 守卫者 + 4 敌人（含精英）+ 1 Boss + 2 建筑 + 棋盘背景 + UI 全套 + 碎裂图标，**每单位仅 1 张静态立绘，零帧动画** | 总资产数 ~10-11 |

**预计 MVP 开发时长**：**7-9 个月**（独立开发，Oracle 审查 + UI 精简后修订）

> **诚实说明**（Oracle 审查 + UI 精简修订）：完美信息棋盘的 UI 是开发量最大的部分，但**精简后大幅降低**——连锁只显示最终结果（不逐格）、建筑 HP 只标被攻击的（不标全部）、颜色编码 4 色（非 7 色）。完整 MVP 工期分解：

| 模块 | 单人估计 |
|---|---|
| 核心战斗模拟器 + 撤销友好状态模型 | 3-5 周 |
| 预演/UI 决定论层（精简版） | **4-6 周**（原 6-10 周，精简省 ~40%） |
| 敌人 AI + tie-break + 测试场景 | 3-5 周 |
| Run/元/商店/营地/挑战/遗物流程 | 3-5 周 |
| Boss + Boss UI + Boss 特定 bug | 3-4 周 |
| 教学/平衡/抛光/集成 | 6-8 周 |

**现实估算：7-9 个月**（UI 精简后从 8-10 月下调）。

如果坚持 **5-7 个月**目标，**第一里程碑必须砍到**：1 张地图 / 无 Boss / 无商店/营地 / 无守护值 / 无挑战目标——只验证战斗循环本身。

#### MVP 留存目标（量化预期）

| 指标 | 目标 |
|---|---|
| **新玩家首次通关时长** | 8-12 小时（包含学习曲线 + 3-5 次失败 Run） |
| **可重玩深度** | 3-5 个 Run 让玩家发现核心遗物组合 + 完成 50% 以上挑战目标 |
| **核心循环爽快度验证** | 玩家在前 3 个 Run 内至少触发 1 次"我发现了一个组合"的爽快时刻（如链锤改装 + 碎裂猎人协同） |

> **超出 MVP 范围**：如果玩家想玩 30+ 小时，必须 1.0+ 加入元进度系统。MVP 不追求长程留存。

#### 已知 MVP 风险（坦诚记录）

| 风险点 | 缓解方案 |
|---|---|
| **2 张地图骨架可能让 5 场战斗感觉重复** | 通过挑战目标系统让"同一张地图"有不同战术目标；通过遗物组合让"同一场战斗"有不同打法。1.0+ 必扩展到 4-5 张地图骨架 |
| **3 守卫者固定阵容缺乏多样性** | 通过改能力遗物（链锤改装 / 长杖共鸣）让守卫者每 Run 不同。1.0+ 必加守卫者升华 |
| **4 个遗物池过小** | 玩家每 Run 拿到 3 个 → 几乎覆盖整个池子 → 第 2 个 Run 后无新鲜感。1.0+ 必扩展到 12+ 遗物 |
| **建筑保护 + 守护值 + 单位 HP 三重压力可能散乱** | 原型测试时观察玩家"想这一步要 30 秒以上"现象——如有则简化系统（可能合并守护值与建筑机制） |

### 12.2 第 1 版迭代后（如果 MVP 验证成功）→ 加什么

**按价值排序**：

1. **战中卡牌系统** — 加入 6-8 张稀疏法则卡（详见 §9）— **这才是真正的与 ITB 差异化**
2. **节点图分支** — 把线性 Run 升级为精简节点图（8-10 节点）
3. **守卫者升华系统** — 给 3 个守卫者各 2-3 条动词扩展路线
4. **新守卫者**：1-2 个新角色（如重装坦克 / 治疗辅助 / 远程蓄力等差异化角色——具体类型在 1.0+ 阶段根据 MVP 玩家反馈再定）
5. **第 4-5 个敌人**：诅咒巫师 + 腐土钻地虫
6. **更多遗物**：从 4 个扩展到 12 个
7. **第 3-4 张地图**
8. **守卫者重复选** — 通过特定遗物解锁

### 12.3 1.0+ 扩展（更远的未来）

| 模块 | 扩展方向 |
|---|---|
| **守卫者** | 8 种（增加重型 / 召唤 / 治疗 / 远程蓄力等） |

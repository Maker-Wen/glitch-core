## A. CRITICAL ISSUES（开发前必须修复，5 项）

### A1. Boss 当前用现有动词无法被打中 🔴🔴🔴

- **问题**：§8.7 Boss 在盘外，但所有 3 个守卫者动作都瞄准棋盘上的格子/单位。"暴露相时任何攻击命中 Boss 都扣 1 HP" **没有合法的瞄准规则**。
- **影响**：Boss 无法实现，需要后期临时发明新规则——会拖垮工期，破坏"同一套动词"的承诺。
- **修复**：暴露相期间在棋盘边给 Boss 一个**盘内弱点格**（如 1 格"心脏钟"目标），或让所有锚石位置变成可攻击命中盒。只用现有近战/推/拉瞄准规则。

### A2. 弓手瞄准规则自我矛盾 🔴🔴

- **问题**：§4.5 / §8.4 说守卫者会身体挡住弓手射线；§11.6 说弓手选定方向后**优先锁定建筑**（即使守卫者挡在前面）。
- **影响**：破坏完美信息承诺。玩家第一次身体挡线失败时会感觉作弊。
- **修复**：**直线上第一个目标被打中，到此为止**。建筑无优先级，挡住的就是挡住。

### A3. 普通战的威胁预算约束不够紧 🔴🔴

- **问题**：3 行动/回合 vs 任何回合的"3 个硬威胁 + 余量" → 经常无法挽救。文档自己的最坏情况（3 铁角兽在不同车道 + 其他敌人）已经超出可靠响应带宽。
- **影响**：原型期玩家反馈会变成"不公平的随机"，但真实问题是生成器数学。
- **修复**：硬性出怪规则：
  - 普通战每回合**最多 2 个硬威胁建筑**
  - **第 4 轮前最多 1 个活动铁角兽**
  - **普通战总共最多 2 铁角兽**
  - 3 铁角兽场景留给精英战/Boss

### A4. 经济不一致，Boss 战可被无限刷 🔴🔴

- **问题**：§6.5 每杀必给余烬，Boss 战又**无回合上限**且持续刷怪。这造成**无限或近无限的余烬农场**。即使非 Boss 战，文档的 Run 收入远超声明的 30-50 范围。
- **影响**：商店/修复价格失去意义，最优玩法变成"拖时间刷怪"。
- **修复**：
  - 原型期用**节点固定奖励为主要经济**
  - **Boss 战的杂兵不给余烬**
  - 如保留每杀奖励，整场战斗的余烬奖励要设置上限

### A5. 物理结算的语义还未完全冻结 🔴🔴

- **问题**：§3.5/§3.6 仍留有这些未解决问题：
  - 同动作 Cracksbane 触发时机
  - 0 HP 单位在链中继续推动
  - 敌人移动冲突
  - 守卫者是否会被碎裂
  - 锚石碎裂行为有矛盾
- **影响**：在这些规则冻结前，可靠的预演/撤销系统无法建造。
- **修复**：开发前写 1 页"战斗结算真值表"。特别明确：
  - 伤害快照**在碎裂施加之前**
  - 0 HP 单位**在链结束前保持实体**
  - 碎裂**只影响下一次意图生成**
  - 锚石**永远不会获得碎裂**

## B. IMPORTANT ISSUES（原型期内应解决，9 项）

1. **Battle 1 可能太容易而非太难**——4-5 个 HP=1 腐食兽 + 建筑 HP=2 → 太宽松。修复：保持 4 个，强制设置一个明显的连锁/石柱教学场景。

2. **Battle 3 在数学上可能过载**——3 铁角兽 = 9 HP 自身 + 5 其他敌人 = 14-17 总 HP，而玩家总输出仅 15 行动 × 1 伤。修复：普通 Battle 3 用 **1 铁角兽保底，最多 2 个**，绝不 3 个。

3. **"3 同时威胁"只有每个 1 行动可解时才公平**——一旦涉及挡线、移动+攻击要求、隐藏出怪身份，并不总是。修复：威胁分类为**硬**（需要直接行动）vs **软**（一回合外），按此规划预算。

4. **挑战目标与"战斗中隐藏追踪"冲突**——"Swift""Physical""Chain Master"是有意目标，但 §3.1 把它们隐藏到结算屏。修复：在战斗中显示**小被动核对清单/计数器**，无需弹窗。

5. **友军挡线仍有认知风险**——8×8 棋盘 + 2 远程单位 → 会产生"为什么我的射击没生效"时刻。修复：明确预览：**橙色被挡线 + 友军剪影 + 最终实际目标**。

6. **碎裂不够直觉，不能纯靠玩家自己发现**——推/拉可以通过玩耍学到；碎裂不能。修复：1 个强制教学卡 + 幽灵下回合移动预览。

7. **三条压力轨道可能模糊决策**——建筑 HP、守卫者 HP、守护值在不同时间尺度运作。修复：**第一个战斗原型不评估守护值**，先验证战斗本身。

8. **Boss 可读性对首个可玩版本是多一个系统**——脚本队列 + 锚石逻辑 + 盘外目标 + 全棋盘扫击 + 脉冲光环 + 常规敌人 + 建筑——太多了。修复：Boss 只在基础战斗切片稳定后再原型。

9. **文档过度宣称"完美信息"**——你实际有的是：**揭示后的完美战术信息 + 揭示前隐藏的出怪身份**。修复：营销和教程要这样表述。

## C. 边缘情况裁定（写到"结算真值表"里）

| 情境 | 推荐裁定 |
|---|---|
| 0 HP 单位在链中 | 保持实体直到链结束。仍可被推、碰撞、给别人施加碎裂、坠渊 |
| 碎裂重复施加 | 布尔值，下回合结束时清除。同链/回合多次施加只是刷新，不叠加 |
| Cracksbane 时机 | 在**攻击声明时**检查目标状态，不是在同动作碰撞后。所以单独的链锤改装**不能**一击秒杀新鲜的铁角兽 |
| 链锤改装 + Cracksbane 数学 | 新鲜铁角兽：BH 攻击 1 + 撞墙 1 = 总 2，留碎裂活着；已碎裂铁角兽：BH 攻击 2 + 撞墙 1 = 总 3，一击秒杀 |
| 地裂压制 | 占据延迟**同一个排队的出怪** 1 回合；地裂在排队时不滚新出怪。队列大小 = 1 |
| Boss 横扫推方向 | 朝该行/列**最近的棋盘边缘**推；并列时按 N/E/S/W |
| Boss 横扫 + 碎裂 | 是的，Boss 引发的撞墙/撞石/撞单位**可以**施加碎裂，保持一致性 |
| 锚石 | 自己永远不获得碎裂。但敌人被推撞锚石**可以**获得碎裂——这是好的反制，不是漏洞 |
| 无路 + 无绕路 + 无挡路攻击者 | 敌人**保持原位**。不消失，不自杀 |
| 两个敌人想去同一格 | 按**敌人生成 ID 升序**解析；后者保持原位。预演必须用相同规则 |
| 双锚石脉冲叠加 | 上限 **+1 移动**，不是 +2 |
| 守卫者 + 深渊边缘 | 敌人和 Boss 效果可以把守卫者推入深渊。玩家远程攻击**不**会击中友军（除非明确选择友军误伤）；否则友军只阻挡射线 |

## D. 工期预警 🟠

**5-7 个月对完整 MVP 太乐观**。这能完成一个**战斗垂直切片**，但不能完成"完整 5 场 Run + 营地/商店/遗物/挑战/Boss + 抛光的决定论 UI"。

| 模块 | 单人估计 |
|---|---|
| 核心战斗模拟器 + 撤销友好状态模型 | 3-5 周 |
| 预演/UI 决定论层 | 6-10 周 |
| 敌人 AI + tie-break + 测试场景 | 3-5 周 |
| Run/元/商店/营地/挑战/遗物流程 | 3-5 周 |
| Boss + Boss UI + Boss 特定 bug | 3-4 周 |
| 教学/平衡/抛光/集成 | 6-8 周 |

**现实是 8-10 个月**。

如果坚持 5-7 个月，**首个目标砍到**：1 张地图 / 无 Boss / 无商店/营地 / 无守护值 / 无挑战目标——只验证战斗循环。

## E. 商业可行性

**作为原型/demo 钩子：可以。作为可发售的商业产品：弱。**

当前可卖的差异化不是"哥特 ITB"，是 **"确定性连锁碰撞战术 + 弹性建筑损失"**。如果连锁物理幻想在 trailer 里不能瞬间被看懂，游戏就只会被读成"ITB 加暗皮"。

**一句话推介**：
> "A gothic horror tactics roguelite where every enemy move is knowable, every shove can trigger a lethal chain reaction, and you're fighting to keep the last sanctuary standing."

## G. 原型期 Top 3 优先级

1. **先建确定性战斗模拟器**——1 张地图、3 守卫者、腐食/弓手/铁角兽、建筑、石柱、深渊、完整推/拉链解析、撤销
2. **再建预演层**——敌人意图、最终位置、碰撞伤害、碎裂预测、挡线、建筑 HP 损失。**预演撒一次谎，设计就崩了**
3. **在元/Boss 工作前跑脚本化平衡场景**——明确测试：Battle 1 教学、3 威胁回合、铁角兽车道过载、碎裂连击数学、地裂延迟、同格敌人冲突

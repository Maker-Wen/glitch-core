# 美术圣经与 AI 提示词

> **本文档拆分自主策划案 §10**。主策划案：[../game_design.md](../game_design.md)
>
> 本文档定义《长夜余烬》的美术风格规范、色板、AI 提示词模板。开发期间生成立绘资产时查阅。

---

## 1. 整体风格

| 维度 | 规则 |
|---|---|
| **媒介** | 纯 2D 手绘立绘 + 引擎合成棋盘（无 3D 建模、**零帧动画**） |
| **棋盘视角** | **正交 8x8 方格棋盘**：逻辑格、点击命中、移动范围、攻击预览全部以 72x72 方格为准；不使用菱形 / 等角地板 |
| **单位呈现** | **棋子式立绘**：单位是 2D 棋子，绘制角度为"半侧面 + 轻微俯视"——能看见头顶、肩膀、武器、部分脸；脚底锚点必须落在正交格心。**风格对标实体桌游棋子**——玩家看到的第一反应是"这是个棋子"而非"这是个没做完动画的角色" |
| **地形呈现** | 地板必须是 **square tile-safe**：单格完整填满 72x72 正交方格，边界清楚，不能生成菱形底板、透视地砖或跨格大图；建筑 / 柱子可以有轻微俯视体积，但底部占位仍是 1 个正交格 |
| **朝向表达** | 立绘默认"面向棋盘下方"，引擎用旋转/翻转实现 4 朝向 |
| **描边** | **厚黑描边**（3-5px），所有立绘、地形、UI——强化棋子/桌游感 |
| **色调** | 黑底 + 暗红 + 血污金 + 病态绿 + 苍白蓝；**禁霓虹色**、**禁高饱和** |
| **材质** | **手绘油画 + 水墨晕染**感（不是平涂，但也不是写实贴图） |
| **资产数量** | 每个单位 **仅 1 张静态立绘**，无攻击帧/受伤帧/动画帧 |
| **动态反馈** | **零帧动画，全靠代码特效 + 音效**（详见下方 §8） |

## 3. AI 提示词通用前缀

```
3/4侧俯视，轻微俯角，
脚底锚点清楚，可有轻微接触阴影，不要圆形底座或地面圆盘，
暗黑哥特奇幻风格，粗黑描边3-5像素，油画质感，
低饱和色板，无霓虹色，无高饱和色，
暗黑地牢角色美术风格，迈克·米格诺拉地狱男爵美学，
实体桌游棋子风格，粗犷手绘感，
单帧静态立绘，无动画，无动态姿势
```

> ⚠️ 永远用 `3/4侧俯视`，不要用 `侧视图` 或 `正视图`
>
> ⚠️ 每个提示词末尾都加 `单帧静态立绘，无动画`——防止 AI 生成出"正在挥刀"的动态帧，我们只要一个**静止待机姿态**

## 7. 美术验证流程（开发期必做）

在大规模生成前，**先跑 1 张守卫者立绘验证风格**：

1. **第一步**：用 §4.1 的赏金猎人提示词跑 1 张
2. **第二步**：把它放在原型棋盘的 1 个格子上
3. **第三步**：截图给真人玩家看（5-10 个），问："这看起来是个独立游戏还是 AI 生成的素材库？"
4. **通过率 < 60% 就需要换风格或找真人插画师**

> 这一步是降低**美术风险**的工程动作。AI 美术帮你做 token，但容易让游戏被打上"AI Slop"标签。

## 8. 零帧动画下的动态反馈系统

> **核心原则**：零帧动画 ≠ 零反馈。桌游棋子没有动画，但玩家不会觉得"干"——因为**状态变化本身就是反馈**。我们的目标是让纯静态看起来像**设计选择**（桌游棋子美学），而非技术限制。

### 8.1 代码特效（引擎层实现，无需美术帧）

| 事件 | 视觉反馈 | 实现方式 |
|---|---|---|
| **移动** | 瞬移到目标格 + 原格短暂残影（0.2s 淡出） | 代码：复制 sprite → 原位淡出 |
| **攻击命中** | 目标格**全屏微震**（2px，0.1s）+ 命中格红色闪框 | 代码：screen shake + tile flash |
| **伤害数字** | 格子上方弹出伤害数字（"−1"），0.5s 后淡出 | 代码：label popup |
| **推/拉** | 被推单位瞬移到新格 + 原格→新格之间画一条**淡轨迹线**（0.3s 淡出） | 代码：line2d 渲染 |
| **接力推动** | 连锁路径依次画轨迹线（每段间隔 0.1s），最后全屏微震 | 代码：序列化 line2d |
| **碎裂状态** | 单位上方叠加**裂纹图标**（红色，静态）+ 格子边缘红色裂纹纹理 | 代码：overlay sprite |
| **死亡** | 单位**缩小到 0 + 淡出**（0.3s）+ 格子短暂暗红闪光 | 代码：scale tween + fade |
| **建筑被击** | 建筑格子**红色脉冲**（0.2s）+ HP 数字变化 | 代码：tile pulse |
| **建筑被毁** | 建筑立绘**碎裂消失**（切为 2-3 块偏移淡出，无需美术帧，代码裁切）+ 格子变废墟纹理 | 代码：random split + offset + fade |
| **坠渊** | 单位**向下淡出 + 红色粒子溅射** | 代码：translate down + fade + particles |
| **回合切换** | 敌方回合 → 屏幕边缘**暗红晕染**（0.3s），玩家回合 → 暗红消退 | 代码：vignette overlay |
| **挑战完成** | 对应行**金色闪亮**（0.5s）+ 勾选标记出现 | 代码：row highlight |

### 8.2 音效（动态反馈的第二通道）

> 零帧动画下，**音效承担 50% 的反馈职责**。美术只管"长什么样"，音效管"发生了什么"。

| 事件 | 音效方向 |
|---|---|
| 近战命中 | 沉闷撞击 + 骨裂声 |
| 远程命中 | 嗖射 + 命中脆响 |
| 推/拉 | 滑动摩擦声 + 被推方闷哼 |
| 接力连锁 | 每次接力叠加一层**金属碰撞声**（音高递增，营造连锁感） |
| 碎裂产生 | 石裂/骨裂声 |
| 坠渊 | 长下坠声 + 远处闷响 |
| 建筑被毁 | 坍塌轰鸣 + 碎石散落 |
| 回合切换 | 敌方回合：低沉钟鸣；玩家回合：短促铁链声 |
| Boss 暴露相 | **巨钟长鸣**（这是 Boss 的身份音） |

### 8.3 节奏控制

纯静态 + 代码特效的关键是**节奏感**——事件不能同时发生，必须有序列：

1. 玩家确认操作 → 0.1s 延迟
2. 推/拉轨迹线画出 → 0.3s
3. 接力链逐段画出（每段 0.1s）→ 全屏微震 0.1s
4. 伤害数字弹出 → 0.5s 淡出
5. 死亡单位缩小淡出 → 0.3s
6. 碎裂图标出现 → 停留
7. 0.2s 间隔 → 下一事件

**总延迟**：单次操作约 1-1.5s，玩家可按 **空格键跳过**（直接跳到最终状态）。

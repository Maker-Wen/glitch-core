# 断墙远征地图面板视觉刷新设计

## 背景

当前 `断墙外远征地图` 面板仍然像调试阶段界面：主区域是大块半透明底板，三个目的地是纯色矩形按钮，右侧存在较长的说明文字。它能表达功能，但不像正式游戏 UI，也和据点背景、战斗 HUD 的暗色美术调性不够统一。

本次只刷新远征地图选择面板的视觉表现，不改变 Run 创建、远征路线权重、委托榜、据点入口和测试期望的核心交互。

## 目标

1. 把面板从 demo 色块升级为正式的战术沙盘风格。
2. 删除或替换明显像开发说明的长文本。
3. 保留三条远征选择：`断墙外环`、`裂隙回廊`、`废弃军需线`。
4. 继续让选中远征后创建对应 Run 并打开任务委托榜。
5. 使用 GPT 生成的项目内美术资源增强氛围，并通过截图自评迭代。

## 非目标

1. 不调整 RunState 的路线生成逻辑和数值权重。
2. 不重做据点主界面、任务委托榜或战斗 HUD。
3. 不引入新输入流程、确认弹窗或复杂动画系统。
4. 不依赖运行时联网或外部资源路径。

## 视觉方向

采用已确认的 **A. 战术沙盘** 方向。

主视觉是暗金属作战桌或远征沙盘：低饱和黑褐底、暗金属边、琥珀高光、裂隙冷光点缀。画面需要比当前更有空间感，但仍保持文字可读和按钮可点。

三条目的地不再像普通 UI 色块，而是战区铭牌或地图钉：

| 目的地 | 视觉倾向 | 信息重点 |
| --- | --- | --- |
| 断墙外环 | 橄榄绿 / 防线印记 | 标准、均衡、稳定 |
| 裂隙回廊 | 暗红 / 裂隙灼光 | 高压、成长、战斗密度 |
| 废弃军需线 | 钢蓝 / 补给符号 | 资源、补给、规划 |

## 信息结构

面板分为三层：

1. 顶部标题区：只保留 `断墙外远征地图` 铭牌，不放常驻副标题或操作提示。
2. 全宽沙盘区：显示暗色沙盘底图、低调路径线、三块目的地铭牌和少量地名点缀。
3. 右侧情报区取消，地图台横向扩展到主面板宽度，让选择行为成为唯一视觉中心。

不再放置额外提示语、角落说明或路线情报段落。路线差异只通过三块目的地铭牌的名称、短副标题和颜色表达。

底部保留 `返回据点`。

## 实现方案

在 `scripts/core/game_manager.gd` 内集中改造 `_show_expedition_table()` 及相关辅助函数：

1. 新增远征沙盘背景资源常量，加载 `art/ui/expedition/expedition_tactical_map_gpt.png`。
2. 新增 `_add_expedition_map_backdrop()` 用 TextureRect 展示 GPT 生成底图；资源缺失时回退到程序化暗色面板。
3. 新增 `_add_expedition_route_line()` 或等价轻量绘制，用细线连接三个目的地，增强地图关系。
4. 调整 `_add_expedition_map_region()` 的按钮样式，使按钮成为有边框、有内发光、有悬停状态的战区铭牌。
5. 移除右侧说明面板，避免界面再次出现 demo 感解释文字。

保持按钮文字仍为：

- `断墙外环\n标准 / 均衡`
- `裂隙回廊\n高压 / 成长`
- `废弃军需线\n资源 / 补给`

这样现有测试可继续按文本查找按钮。

## 美术资源

首选通过可用的 GPT 图像生成能力创建一张 1280x720 或 1024x576 的暗色沙盘底图，再复制进 `art/ui/expedition/`。

如果当前环境没有可调用的内置图像生成工具，则使用已有 GPT 风格资源和程序化绘制先完成可运行版本，并明确记录未生成新图的限制。

资源要求：

1. 无文字、无 logo、无水印。
2. 中央留出三块按钮位置，不让高亮纹理压住文字。
3. 暗色基调，琥珀高光，少量冷蓝裂隙光。
4. 不使用纯紫蓝渐变或单一色相背景。

## 验证

1. 运行相关 Godot 测试，至少覆盖 `test_main_menu_hub_flow.gd`。
2. 启动或运行项目截图，确认面板在 1280x720 内无文字重叠。
3. 检查三条远征按钮仍可点击并创建对应 `expedition_id`。
4. 自评截图：正式感、层级、可读性、与据点背景融合度。

## 风险

1. GPT 底图如果细节过多，可能影响文字可读性；需要叠加暗色遮罩或降低对比。
2. 当前 UI 多为代码构建，过多新 helper 会让 `game_manager.gd` 继续变大；本次只加少量局部辅助函数。
3. 工作区已有大量未提交改动，提交或回滚时必须只处理本次新增与修改文件。

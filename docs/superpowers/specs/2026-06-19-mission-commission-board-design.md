# 据点任务委托面板改造设计

> 日期：2026-06-19  
> 状态：已按当前实现更新  
> 范围：据点中的断墙远征门面板、固定委托槽、任务卡、任务详情确认。  
> 结论：断墙远征门展示不同类型的任务委托卡，玩家先看任务目标、风险和奖励，再进入详情确认；完成一个委托后立即补入新委托，不要求清空同层所有任务。

## 1. 目标

当前主场景已经从主菜单拆成据点页，`断墙远征门` 是玩家进入下一次行动选择的主入口。本次方向是把当前可选行动包装成任务委托。

这样做的目的有三个：

1. 让玩家先理解“这次任务是什么”，而不是先看路线结构。
2. 避免把底层路径结构、连线和可达状态直接搬到前台。
3. 让委托榜像一个持续刷新的任务板：玩家完成一个任务，就能看到一个新的可接任务。

## 1.1 与关卡地图选择的边界

关卡地图选择和任务委托榜必须分开，但都挂在据点主场景的 `断墙远征门` 下：

| 模块 | 出现时机 | 回答的问题 | 表现形式 |
|---|---|---|---|
| 关卡地图选择 | 未创建 Run 时，进入据点后点击断墙远征门 | 这一局去哪个区域 | 区域地图 / 地图桌 |
| 任务委托榜 | 已有 Run 时，点击断墙远征门 | 下一次行动接哪个委托 | 任务卡 / 布告板 |

任务委托榜不承担“选择不同 Run 地图”的职责，也不展示区域地图、节点连线或路线图。它只展示本局当前可接任务。

## 2. 展示原则

任务委托面板应回答三个问题：

1. 当前有哪些可接任务。
2. 每个任务大概是什么类型、风险多高、奖励是什么。
3. 点进详情后，玩家能否做出是否开始任务的判断。

据点首页不承担这些判断。`守护值`、`腐化`、守卫者 HP、敌人压力、回合数和奖励详情，都应放到任务详情、事件选择、营地或商店等决策页中按需展示。

## 3. 任务类型

第一版使用当前节点类型和压力标签推导任务类型名称：

| 节点数据 | 前台任务类型 | 目的 |
|---|---|---|
| 普通战 + 裂隙标签 | 裂隙压制 | 占住或延迟地裂，换取余烬和成长机会 |
| 普通战 + 堵路 / 推撞标签 | 清剿委托 | 利用推撞和地形解决高密度敌群 |
| 普通战默认 | 防守委托 | 撑到回合结束并保护建筑 |
| 精英战 | 精英讨伐 | 高风险战斗，主要奖励遗物 |
| Boss | Boss 压制 | 处理锚石、心脏钟和毁灭计数，获得终局奖励 |
| 事件 | 事件委托 | 公开资源交换、腐化和下一战修正 |
| 营地 | 整备委托 | 在守卫者 HP 和守护值之间取舍 |
| 商店 | 补给委托 | 花余烬购买治疗、修复或遗物 |

## 4. 任务卡字段

任务卡展示短信息，避免变成长说明：

| 字段 | 示例 | 说明 |
|---|---|---|
| 任务名 | `铁角闸门` | 来自节点标题 |
| 任务类型 | `防守委托` | 从节点类型和压力标签推导 |
| 风险 | `■■□□□ 2/5` | 进入详情前的粗判断 |
| 压力标签 | `裂隙压力 · 堵路拥挤` | 最多展示 1 到 2 个关键词 |
| 奖励预览 | `余烬 +7 · 成长机会` | 区分普通战、精英战、Boss、事件、营地、商店 |
| 操作 | `查看详情` | 不直接开战，先进入确认页 |

任务卡不展示路径层级、连线或暂不可选内容。当前可接任务由底层委托槽筛出，面板只展示可选委托。

## 4.1 委托槽刷新规则

第一版委托榜使用固定槽位，而不是“清完一层再刷新”：

1. 初始显示 3 个可接委托。
2. 玩家完成任意一个委托后，该委托从榜单移除。
3. 榜单立即从可达候选池中补入 1 个新委托，保持最多 3 个可选项。
4. 已完成的委托不会重新进入榜单。
5. 累计完成 5 个非 Boss 委托后，Boss 委托单独出现。
6. Boss 出现时不再强迫玩家清空剩余普通委托。

这样做能避免玩家完成一个任务后看到榜单变空，也避免“必须把同层所有节点做完”的误解。

## 5. 任务详情字段

任务详情确认页展示足以影响决策的信息：

- 任务类型和任务名。
- 当前任务目标，例如“防守到第 5 回合”“处理事件选项并返回据点”。
- 压力提示和地图 / 机制提示。
- 奖励预览，明确区分普通战、精英战、Boss、事件、营地和商店。
- 出战风险摘要：存活守卫者、必要资源和会影响本次任务判断的压力字段。
- 高风险警告：风险 3 以上且残编、资源过低或压力过高时提示。
- 主按钮：开始任务。
- 次按钮：返回据点。
- 辅助返回：返回任务布告。

## 6. 奖励表达

不同任务的奖励表达必须不同：

| 任务 | 奖励预览 |
|---|---|
| 普通战 | 余烬 +基础值，奖励任务可追加余烬和成长 / 修复机会 |
| 精英战 | 余烬 +基础值，遗物选择，完成更多奖励任务提高选项或稀有权重 |
| Boss | 余烬 +基础值，章节 / 终局奖励，心脏钟命中可追加余烬 |
| 事件 | 选项会改变余烬、守护值、腐化或下一战状态 |
| 营地 | 治疗小队或修复防线，只能选 1 项 |
| 商店 | 消耗余烬购买治疗、修复或遗物 |

## 7. 非目标

本次不做以下内容：

- 不做路径图。
- 不展示暂不可选内容。
- 不重写路线生成器。
- 不新增任务池配置表。
- 不让任务委托榜承担 Run 地图选择。
- 不要求玩家清空同一层所有任务。
- 不改变战斗胜负条件和奖励结算。
- 不实现新的商店、工坊、神龛系统。
- 不新增完整视觉资产。

## 8. 验收标准

1. 断墙远征门打开 `任务委托` 面板，不出现 `断墙远征图`。
2. 初始任务委托榜显示 3 个委托槽。
3. 每张任务卡显示任务名、任务类型、风险、压力标签和奖励预览。
4. 任务详情页显示任务目标、奖励预览和队伍风险。
5. 普通战、精英战、Boss、事件、营地、商店在文案上能被玩家区分。
6. 完成一个委托后，榜单立即补入新的可接委托。
7. 完成足够数量的非 Boss 委托后，Boss 委托单独出现。
8. 现有主菜单、据点、任务详情、事件、营地、商店返回流程测试继续通过。

> 日期：2026-06-10  
> 状态：当前可跑 Demo Run 的权威内容规格 + 完整 Run 扩展蓝图  
> 依赖：`scripts/run/run_state.gd`、`scripts/data/battle_config_catalog.gd`、[map_pool_design.md](map_pool_design.md)、[run_structure_design.md](run_structure_design.md)

## 1. 设计口径

本文只定义两件事：

1. **Run 外层地图节点** ：玩家在一局 Run 中看到、选择和推进的节点图。
2. **战斗内地图关卡** ：进入战斗后使用的 8x8 棋盘、保护目标、地形、敌群、出怪表和奖励任务。

本文不使用生成大图做节点预览。真实战斗由 `BattleConfigCatalog` 的 8x8 数据驱动；后续美术应直接服务 runtime 地块、建筑、地裂、石柱和 Boss 物件。

## 2. 当前可跑 Demo Run 节点图

当前代码中的 Demo Run 是一个 **6 层完整分支路线图** ：

- 图上共有 12 个节点。
- 单次通关路径会访问 6 个节点。
- 第 2 层提供事件 / 商店 / 普通战三选一。
- 第 3 层提供普通战 / 营地 / 风险事件三选一。
- 第 4 层收束到精英战。

### 2.2 单次路径

| 路径 | 节点序列 | 设计意图 | 适合玩家 |

| 稳定恢复线 | 断墙前哨 -> 熄灭的灯塔 -> 巡火营地 -> 铁角闸门 -> 残火营地 -> 钟楼外环 | 战斗少、恢复多，容错最高 | 新手或残血队伍 |

| 早商店资源线 | 断墙前哨 -> 前线军需点 -> 斥候仪式坑 -> 铁角闸门 -> 军需仓库 -> 钟楼外环 | 早期商店 + 后期商店，构筑选择最多 | 首战表现好、余烬足够的玩家 |

## 5. 战斗地图细案

### 5.1 断墙前哨

**目标** ：第一战只教三件事：建筑 HP、远程线压、推离威胁。不能同时引入地裂和精英。

| 内容 | 配置 |
|---|---|
| 守卫者出生 | `(2,5)`、`(3,5)`、`(4,5)` |
| 保护目标 | `b_well (3,3) HP2`、`b_store (4,3) HP2`、`b_shrine (3,4) HP2` |
| 石柱 | `(2,2)`、`(5,2)`、`(2,6)`、`(5,6)` |
| 初始敌人 | `rot_beast (1,1)`、`rot_beast (6,1)`、`rot_beast (1,6)`、`plague_archer (4,0)` |
| 脚本出怪 | R2 `rot_beast (7,3)`；R3 `plague_archer (0,4)`；R4 `rot_beast (6,6)` |
| 地裂 | 无 |

**设计评估** ：

- 敌人 7 个，符合普通战 7-10 的预算。
- 没有地裂，首战信息量可控。
- 第 3 回合左侧弓手制造一次明确挡线题。
- 四根石柱给推撞和挡线提供素材，但不会堵死路径。

### 5.2 裂缝庭院

**目标** ：让玩家第一次理解“占地裂可以延迟出怪”，同时保留远程线压。

| 内容 | 配置 |
|---|---|
| 守卫者出生 | `(2,6)`、`(3,6)`、`(4,6)` |
| 保护目标 | `b_nw (3,3)`、`b_ne (4,3)`、`b_sw (3,4)`、`b_se (4,4)`，均 HP2 |
| 石柱 | `(1,3)`、`(6,4)` |
| 地裂 | `r_nw (2,2)`、`r_se (5,5)` |
| 初始敌人 | `rot_beast (1,1)`、`plague_archer (6,1)`、`bone_grub (6,6)` |
| 脚本出怪 | R3 `plague_archer (7,2)`；R4 `rot_beast (0,5)` |
| 地裂出怪 | R2 `r_nw -> rot_beast`；R3 `r_se -> bone_grub`；R4 `r_nw -> rot_beast` |

**设计评估** ：

- 敌人 8 个，符合普通战预算。
- 2 个地裂、3 次地裂出怪，符合裂隙强度 1。
- 中央 2x2 建筑让玩家必须守住核心区域。
- 蚀骨蛆群从下侧压建筑，和弓手线压形成行动取舍。

### 5.3 铁角闸门

**目标** ：第一个精英战，明确展示铁角兽冲撞车道、关键建筑和堵路压力。

| 内容 | 配置 |
|---|---|
| 守卫者出生 | `(2,6)`、`(3,6)`、`(4,6)` |
| 保护目标 | `b_left (3,3) HP2`、`b_right (4,3) HP2`、`k_gate (3,4) HP3` |
| 石柱 | `(3,1)`、`(4,1)`、`(2,2)`、`(5,2)`、`(2,4)`、`(5,4)` |
| 地裂 | `r_left (1,5)`、`r_right (6,5)` |
| 初始敌人 | `ironhorn (3,0)`、`rot_beast (1,1)`、`rot_beast (6,1)`、`plague_archer (6,3)` |
| 脚本出怪 | R2 `plague_archer (0,2)`；R3 `shell_beetle (7,4)`；R4 `ironhorn (4,0)`；R5 `rot_beast (0,6)` |
| 地裂出怪 | R2 `r_left -> rot_beast`；R3 `r_right -> rot_beast`；R4 `r_left -> bone_grub` |

**设计评估** ：

- 敌人 11 个，符合精英战 10-13 的预算。
- 首只铁角兽在 `(3,0)`，能直观压中线。
- 第二只铁角兽 R4 才出现，避免早期双冲撞过压。
- 护壳虫只承担堵路，不和双铁角同回合制造不可解硬威胁。
- 关键建筑无伤任务和冲撞车道强相关，任务目标正确。

### 5.4 钟楼外环

**目标** ：Boss 战不是击杀战，而是 6 回合防守 + 锚石/心脏钟奖励窗口。

| 内容 | 配置 |
|---|---|
| 守卫者出生 | `(2,6)`、`(3,6)`、`(4,6)` |
| 保护目标 | `b_left (2,3) HP2`、`b_right (5,3) HP2`、`b_back (3,5) HP2`、`k_bell_gate (4,4) HP3` |
| Boss 对象 | `a_left (1,2) HP2`、`a_right (6,2) HP2`、`h_heart_bell (4,2)` |
| 石柱 | `(2,1)`、`(5,1)`、`(1,5)`、`(6,5)` |
| 地裂 | `r_left (0,3)`、`r_right (7,3)`、`r_top (3,0)` |
| 初始敌人 | `rot_beast (2,0)`、`rot_beast (5,0)`、`plague_archer (7,5)`、`rot_beast (0,5)` |
| Boss 召唤 | R3 `rot_beast (3,1)`、`rot_beast (4,1)`；R5 `bell_thrall (0,4)`、`bell_thrall (7,4)`；R6 `rot_beast (3,0)` |
| 地裂出怪 | R2 `r_left -> bone_grub`；R3 `r_top -> rot_beast`；R4 `r_right -> plague_archer`；R5 `r_left -> rot_beast` |

**设计评估** ：

- 敌人 13 个，符合 Boss 12-16 的预算。
- 3 个地裂符合 Boss 裂隙强度 2。
- 锚石位置左右分散，逼玩家在守建筑和打锚石之间分配行动。
- 心脏钟只影响奖励和 Doom 压力，不能提前胜利，符合防守战核心裁定。
- 钟奴 R5 出现，给终局压迫但不提前淹没玩家。

### 5.5 石柱墓园

**目标** ：第 1 章正式路线普通战，强调推撞、阻挡和连锁。它比裂缝庭院更挤，作为精英前的高收益战斗选择。

| 内容 | 配置 |
|---|---|
| 守卫者出生 | `(1,6)`、`(3,6)`、`(5,6)` |
| 保护目标 | `b_center_l (3,3) HP2`、`b_center_r (4,3) HP2`、`b_lower (2,4) HP2` |
| 石柱 | `(1,2)`、`(2,2)`、`(5,2)`、`(6,2)`、`(1,5)`、`(6,5)`、`(4,5)` |
| 地裂 | `r_left (0,4)`、`r_right (7,4)` |
| 初始敌人 | `rot_beast (2,0)`、`rot_beast (5,0)`、`plague_archer (7,2)` |
| 脚本出怪 | R2 `shell_beetle (0,2)`；R3 `rot_beast (6,6)`；R4 `shell_beetle (1,4)` |
| 地裂出怪 | R2 `r_left -> rot_beast`；R3 `r_right -> bone_grub`；R4 `r_left -> rot_beast` |

**设计评估** ：

- 敌人 9 个，符合普通战预算。
- 当前运行时没有腐爆囊，所以用护壳虫替代“占位堵路”压力。
- 石柱较多，适合奖励任务“物理击杀”和“推离威胁”。
- 已接入固定路线第 3 层，只能从灯塔、前线军需点或裂缝庭院分支进入。

### 5.6 断桥边缘

**目标** ：候补高风险地图，未来用于深渊边缘和坠落解法。

| 内容 | 配置 |
|---|---|
| 守卫者出生 | `(2,6)`、`(3,6)`、`(4,6)` |
| 保护目标 | `b_left (2,3) HP2`、`b_right (5,3) HP2`、`b_lower (2,4) HP2` |
| 石柱 | `(1,2)`、`(6,2)`、`(1,5)`、`(6,5)` |
| 地裂 | `r_top_l (3,1)`、`r_bottom_r (4,6)` |
| 深渊元数据 | `void_cells: (3,3), (4,3), (3,4), (4,4)`；`x=0` 向西坠落，`x=7` 向东坠落 |
| 初始敌人 | `rot_beast (1,1)`、`plague_archer (6,1)`、`rot_beast (6,6)` |
| 脚本出怪 | R2 `rot_beast (3,0)`；R4 `shell_beetle (7,5)` |

- 深渊规则当前没有接入 `Grid`，所以 `void_cells` 只是元数据，不改变 runtime 格子。
- 当前版本可作为候补配置加载，但不应进入正式路线池。
- 未来实现深渊后，可以把奖励任务改为“无坠落事故 / 坠落处决”。

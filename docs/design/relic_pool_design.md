# 遗物池、权重与协同设计

> 日期：2026-06-04  
> 状态：第一版内容池规格  
> 依赖：[run_relic_economy_design.md](run_relic_economy_design.md)、[reward_selection_design.md](reward_selection_design.md)、[run_structure_design.md](run_structure_design.md)、[warden_roster_and_upgrades.md](warden_roster_and_upgrades.md)

## 1. 目的

本文档补齐 Run 肉鸽深度中最关键的遗物系统，作为奖励池配置、商店库存、事件奖励、神龛奖励和 UI 展示的交接依据。

本文档回答：

1. Demo 和完整第一版需要多少遗物。
2. 遗物分哪些类型、稀有度和章节解锁。
3. 遗物如何进入奖励池、商店、事件和神龛。
4. 哪些遗物互斥，哪些可以形成流派。
5. 哪些遗物效果禁止出现，避免破坏防守战术核心。

## 2. 核心裁定

- 遗物改变解法，不堆大数值。
- 遗物不能改变标准战斗胜利条件。
- 遗物不能隐藏敌人 AI、随机命中、随机伤害或随机死亡判定。
- 遗物不能永久免疫某类核心压力。
- 遗物不能无代价复活守卫者。
- 遗物可以改变奖励、预防损失、增强推拉、延迟裂隙、强化任务收益和制造风险收益。
- 所有遗物触发都必须能在 HUD、预演、结算或奖励页解释。
- 唯一遗物不可重复获得。

## 3. 稀有度

| 稀有度 | 定位 | 基础权重 | 强度边界 |
|---|---|---:|---|
| 普通 | 小幅改写、稳定收益、流派拼图 | 65% | 单场或单回合小收益 |
| 稀有 | 改变解法、形成流派核心 | 30% | 可明显改变优先级，但要有触发条件 |
| 诅咒 | 强收益 + 腐化、HP 或守护值代价 | 5% | 高收益必须公开代价 |
| 章节 | Boss 后奖励或章节专属 | 特殊 | 只在章节奖励池出现 |

第一轮 Demo 只使用普通和稀有。诅咒遗物从完整第一版第 2 章后开放。

## 4. 类型

| 类型 | 作用 | UI 标签 |
|---|---|---|
| 位移 | 改推、拉、换位、撞击、连锁 | 位移 |
| 防守 | 改建筑、屏障、废墟、守护值损失 | 防守 |
| 裂隙 | 改地裂占位、出怪延迟、裂隙收益 | 裂隙 |
| 任务 | 奖励任务收益、完成方式、额外余烬 | 任务 |
| 风险 | 用 HP、守护值或腐化换强收益 | 风险 |
| 经济 | 商店、工坊、营地、重抽、奖励选项 | 经济 |
| 角色 | 指定守卫者强化 | 角色 |

同一遗物可以有 2 个标签，但 UI 主标签只能有 1 个，避免卡片难读。

## 5. 池规模

| 阶段 | 目标数量 | 使用范围 |
|---|---:|---|
| Demo | 12 | 第 1 章固定路线、精英战、少量事件 |
| 第一章可玩版 | 20 | 支撑多次第 1 章 Run |
| 完整第一版 | 40 | 支撑 3 章 Run、商店、事件、神龛 |
| 后续扩展 | 60+ | 支撑长期构筑变化 |

## 6. 获得来源

| 来源 | 规则 | 备注 |
|---|---|---|
| 精英战 | 遗物 3 选 1，完成 2 任务后 4 选 1 | Demo 必做 |
| Boss 章节奖励 | 稀有或章节遗物 3 选 1 | 第 1-2 章使用 |
| 商店 | 2 个普通，1 个稀有，第 2 章后稀有概率提高 | 完整第一版 |
| 事件 | 按事件配置，常见 2 选 1 或固定获得 | 完整第一版 |
| 神龛 | 稀有 / 诅咒 2 选 1，腐化代价公开 | 第 2 章后 |
| 起始选择 | 普通遗物 3 选 1 | Demo 不启用 |

## 7. 权重规则

### 7.1 基础权重

| 奖励池 | 普通 | 稀有 | 诅咒 | 章节 |
|---|---:|---:|---:|---:|
| 起始遗物 | 100 | 0 | 0 | 0 |
| 第 1 章精英战 | 75 | 25 | 0 | 0 |
| 第 2 章精英战 | 65 | 35 | 0 | 0 |
| 第 3 章精英战 | 55 | 45 | 0 | 0 |
| Boss 章节奖励 | 25 | 60 | 0 | 15 |
| 商店 | 70 | 30 | 0 | 0 |
| 神龛 | 0 | 70 | 30 | 0 |
| 风险事件 | 40 | 45 | 15 | 0 |

完成 3 个奖励任务时，当前遗物奖励池稀有权重 +15，普通权重对应降低。诅咒权重不因此提高。

### 7.2 类型权重

| 当前构筑缺口 | 权重修正 |
|---|---:|
| 没有任何防守遗物 | 防守 +10 |
| 没有任何位移遗物 | 位移 +8 |
| 已有 2 个裂隙遗物 | 裂隙 -10 |
| 当前腐化 5 以上 | 风险 -8，经济 +5 |
| 守护值 3 以下 | 防守 +12，风险 -12 |
| 存活守卫者少于 3 | 角色 -8，防守 +8，经济 +5 |

权重修正只影响候选生成，不保证必出。所有修正必须在配置中可调。

### 7.3 过滤规则

- 已拥有唯一遗物不再出现。
- 角色遗物只在对应守卫者存活且出战时出现。
- 守卫者死亡后，对应角色遗物从后续池中移除。
- 与已拥有遗物互斥的遗物不出现。
- 若合法候选不足，按 [reward_selection_design.md](reward_selection_design.md) 的补偿规则转化为余烬。

## 10. 流派覆盖

### 10.1 物理连锁流

| 核心 | 辅助 | 目标体验 |
|---|---|---|
| 断钟回响、裂纹透镜、锈蚀尖桩 | 链锤改装、处决银币、碎裂冠 | 用推撞、碎裂和处决解决多条威胁 |

### 10.2 建筑防守流

| 核心 | 辅助 | 目标体验 |
|---|---|---|
| 余烬护符、黑铁楔、堡垒印、末灯 | 焦土旗帜、灰泥桶、镜面壁垒 | 允许建筑受少量压力，用防守遗物转化损失 |

### 10.3 裂隙压制流

| 核心 | 辅助 | 目标体验 |
|---|---|---|
| 裂隙钉、残墙图纸、裂隙盖板、回廊钥匙 | 裂隙标记石、坟土钩爪 | 主动占裂隙和延迟出怪，换取奖励任务收益 |

### 10.4 任务经济流

| 核心 | 辅助 | 目标体验 |
|---|---|---|
| 守夜誓约、守夜绳结、处决银币、丧钟计数器 | 冷静账本、余烬钱袋 | 追求高难奖励任务，滚动更多选项和资源 |

### 10.5 风险收益流

| 核心 | 辅助 | 目标体验 |
|---|---|---|
| 血税契约、腐化冠冕、墓契、饥饿灰烬 | 余息誓约、黑钟 | 承担 HP、腐化和 Boss 压力，换更强奖励和爆发 |

## 11. 互斥和限制

### 11.1 硬互斥

| 遗物 A | 遗物 B | 原因 |
|---|---|---|
| 裂圣坛 | 末灯 | 守护值低线保护过强 |
| 黑钟 | 丧钟计数器 | Boss 压力和 Boss 奖励会自循环 |
| 饥饿灰烬 | 圣灰灯 | 经济收益和恢复折扣叠加过强 |
| 堡垒印 | 外墙旗帜 | 指定建筑和随机建筑屏障叠加会让建筑压力过低 |

### 11.2 软限制

软限制不禁止出现，但降低权重。

| 条件 | 权重调整 |
|---|---:|
| 已有 3 个以上防守遗物 | 防守遗物 -15 |
| 已有 2 个以上经济遗物 | 经济遗物 -12 |
| 当前腐化 7 以上 | 诅咒遗物 -20 |
| 存活守卫者少于 3 | 角色遗物 -15 |
| 没有大魔法师 | 碎裂相关遗物 -20 |
| 没有盗墓人 | 拉动相关角色遗物移除 |
| 没有赏金猎人 | 链锤相关角色遗物移除 |

## 12. 禁止设计

以下遗物效果禁止进入第一版：

- 所有建筑永久免疫伤害。
- 所有远程敌人永久失效。
- 每回合自动清空所有地裂。
- 守卫者死亡后无代价复活。
- 随机概率免伤、随机暴击、随机额外行动。
- 隐藏敌人意图或让敌人 AI 临时重算。
- 永久攻击力大量堆叠。
- 每回合无条件恢复所有建筑。
- 让清空敌人成为提前胜利条件。

| 协同提示 | 与已有遗物、守卫者或奖励任务的关系 |

文案必须使用确定表达：

- 使用“每场第一次”“每章 1 次”“最多 2 次”。
- 不使用“有概率”“少量”“大量”“显著”等模糊词。

## 15. Demo 配置建议

Demo 固定路线中只有 1 次精英战稳定给遗物，因此遗物池要保证每次 3-4 个选项都有效。

推荐 Demo 精英战池：

| 类型 | 数量 |
|---|---:|
| 位移 / 角色 | 4 |
| 防守 | 4 |
| 裂隙 | 2 |
| 任务 | 2 |

Demo 奖励池禁用：

- 诅咒遗物。
- 商店专用遗物。
- 第 2-3 章遗物。
- 依赖未实装守卫者的遗物。
- 依赖未实装工坊 / 商店 / 神龛的遗物。

## 16. 验收标准

| 场景 | 标准 |
|---|---|
| Demo 精英战奖励 | 能展示 3 个合法遗物选项 |
| 完成 2 个奖励任务 | 遗物选项 +1 后展示 4 个，不重复 |
| 已拥有唯一遗物 | 后续不再出现 |
| 无对应守卫者 | 角色遗物不出现 |
| 腐化 7 以上 | 诅咒遗物权重降低并显示高腐化警告 |
| 守护值 3 以下 | 防守遗物权重提高，风险遗物权重降低 |
| 互斥遗物已拥有 | 冲突遗物不进入候选 |
| 遗物触发 | HUD、预演或结算能解释来源 |
| 奖励池为空 | 按奖励文档转化为余烬 |
| 第 3 章 Boss 胜利 | 不发可继续 Run 的章节遗物 |

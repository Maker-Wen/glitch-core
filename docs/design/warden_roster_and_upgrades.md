# 守卫者与升级设计

> 日期：2026-06-03
> 状态：第一版角色与升级池
> 依赖：[defense_roguelite_core_design.md](defense_roguelite_core_design.md)

## 1. 设计原则

守卫者不是 RPG 角色堆属性，而是 8x8 棋盘上的解题动词。

设计原则：

1. 每名守卫者有一个清楚的核心动词。
2. 每名守卫者能处理至少一种公开意图。
3. 每名守卫者有保护建筑的手段。
4. 升级优先改变位移、范围、时序、地形和奖励任务能力。
5. 少做攻击力 +1，除非它明显打开新解法。

## 2. 队伍结构

Run 开始选择 3 名守卫者：

- 第一版允许 5 选 3。
- 同名守卫者不可重复。
- 每名守卫者战斗内每回合默认 1 移动 + 1 行动。
- 守卫者 HP 标准为 2，防线型可以为 3。

队伍构筑应形成明显取舍：

| 队伍倾向 | 优点 | 缺点 |
|---|---|---|
| 高位移控制 | 推拉多，清威胁强 | 修建筑弱 |
| 防线保护 | 建筑稳定，容错高 | 奖励任务难追 |
| 物理处决 | 坠渊和连锁强 | 对空旷地图依赖高 |
| 裂隙压制 | 出怪控制强 | 对远程威胁处理慢 |

## 3. 基础守卫者

### 3.1 赏金猎人

定位：近战推位、边缘处决、连锁启动。

基础数值：

| 项 | 值 |
|---|---:|
| HP | 2 |
| Move | 2 |
| Range | 1 |
| Damage | 1 |
| Force | 推 1 |

基础技能：链锤击。攻击相邻敌人，造成 1 伤并推 1。

升级方向：

| 升级 | 效果 | 目的 |
|---|---|---|
| 重链 | 推力 +1 | 增强空间解法 |
| 处决钩 | 将敌人推下深渊时获得 +1 余烬，本场最多 2 次 | 奖励任务协同 |
| 盾肩 | 攻击后可与目标原格相邻建筑交换 1 次位置 | 保护建筑 |
| 碎骨冲击 | 撞墙时额外施加碎裂 | 控制下回合 |

### 3.2 盗墓人

定位：远程拉位、挡线修正、裂隙控制。

基础数值：

| 项 | 值 |
|---|---:|
| HP | 2 |
| Move | 2 |
| Range | 3 |
| Damage | 1 |
| Force | 拉 1 |

基础技能：倒钩索。直线 3 格命中第一个敌人，造成 1 伤并向自己拉 1。

升级方向：

| 升级 | 效果 | 目的 |
|---|---|---|
| 长索 | 射程 +1 | 处理远端威胁 |
| 坟土钩爪 | 拉到相邻后，盗墓人可移动 1 格 | 调整挡线 |
| 裂隙楔 | 拉动站在地裂上的敌人时，延迟该地裂下一次出怪 | 裂隙奖励 |
| 反手抛 | 如果目标被拉到相邻，改为侧推 1 | 高阶控位 |

### 3.3 大魔法师

定位：远程推位、群控、碎裂协同。

基础数值：

| 项 | 值 |
|---|---:|
| HP | 2 |
| Move | 2 |
| Range | 3 |
| Damage | 1 |
| Force | 推 1 |

基础技能：斥力弹。直线 3 格命中第一个敌人，造成 1 伤并向远离自己的方向推 1。

升级方向：

| 升级 | 效果 | 目的 |
|---|---|---|
| 长杖共鸣 | 推动目标撞击后，对目标施加碎裂 | 下回合控制 |
| 余波 | 如果目标被推入另一个单位，第二个单位也被推 1 | 连锁强化 |
| 护火 | 对相邻建筑施加 1 次屏障，替代攻击 | 保护能力 |
| 法阵 | 攻击穿过的第 1 个空格留下法阵，敌人经过时移动 -1 | 路径控制 |

## 4. 新增守卫者候选

### 4.1 铁誓卫

定位：防线、换位、承伤。

基础数值：

| 项 | 值 |
|---|---:|
| HP | 3 |
| Move | 2 |
| Range | 1 |
| Damage | 1 |
| Force | 0 |

基础技能：铁誓换位。与相邻守卫者、敌人或建筑旁空格交换位置；若目标是敌人，造成 1 伤。

关键升级：

- 守门：回合结束时若相邻建筑，本回合该建筑受到的第一次伤害 -1。
- 拦截：相邻远程线穿过自己时，铁誓卫优先成为目标。
- 压阵：换位后获得 1 点临时护甲。

### 4.2 祷告者

定位：建筑修复、屏障、风险转移。

基础数值：

| 项 | 值 |
|---|---:|
| HP | 2 |
| Move | 2 |
| Range | 2 |
| Damage | 0 |
| Force | 0 |

基础技能：余烬祷告。选择 2 格内建筑，恢复 1 HP，不能超过初始 HP。

关键升级：

- 代祷：改为给建筑 1 次屏障。
- 殉灯：建筑受致命伤时，祷告者可承受 1 伤阻止毁灭，每场 1 次。
- 净化：修复建筑时清除相邻地裂的本轮强化。

### 4.3 工兵

定位：地形制造、路径阻断、连锁素材。

基础数值：

| 项 | 值 |
|---|---:|
| HP | 2 |
| Move | 2 |
| Range | 2 |
| Damage | 0 |
| Force | 0 |

基础技能：临时路障。在 2 格内空地放置 1 个 HP=1 的路障，阻挡移动和射线，可被撞毁。

关键升级：

- 黑铁桩：路障被撞毁时对撞击单位造成 1 伤。
- 快速搭建：每场第一次放路障不消耗行动。
- 裂隙盖板：路障可放在地裂上，延迟下一次出怪。

### 4.4 决斗士

定位：机动、侧推、精英点杀。

基础数值：

| 项 | 值 |
|---|---:|
| HP | 2 |
| Move | 3 |
| Range | 1 |
| Damage | 1 |
| Force | 侧推 1 |

基础技能：穿身刺。攻击相邻敌人，移动到敌人另一侧空格，并将敌人向左或右侧推 1。

关键升级：

- 影步：若穿身后站在建筑相邻格，返还 1 移动。
- 断筋：被侧推目标移动 -1。
- 标记猎物：攻击精英敌人后，本场对其撞击伤害 +1。

## 5. 升级结构

每名守卫者有 6 个升级，分 3 类：

| 类别 | 数量 | 说明 |
|---|---:|---|
| 动词增强 | 2 | 推拉距离、范围、连锁、换位 |
| 防守增强 | 2 | 修复、屏障、挡线、建筑保护 |
| 任务增强 | 2 | 裂隙、物理击杀、清场、低损任务收益 |

每名守卫者每章最多获得 1 次升级。完整 3 章 Run 中，核心队伍每人约 2-3 个升级。

## 6. 伤势规则

守卫者 HP 不建议每场自动满回。

第一版规则：

- 战斗结束后，守卫者保留当前 HP。
- 若守卫者倒地但战斗胜利，战后以 1 HP 归队并获得 1 个伤势。
- 每个伤势使该守卫者进入下一场时最大 HP -1。
- 营地可移除 1 个伤势或全队恢复 1 HP。
- 最大 HP 降到 0 时，该守卫者本 Run 离队。

伤势让路线和营地有意义，但不能过度惩罚。第一章可降低伤势出现频率，避免新手连续失败。

## 7. 平衡边界

守卫者单次行动默认只应解决 1 条硬威胁。高阶连锁可以解决 2 条，但应依赖位置和预演。

不建议出现：

- 大范围无条件清场。
- 长距离任意传送。
- 永久提高伤害到 3 以上。
- 无代价复活。
- 可以稳定每回合修复所有建筑的循环。

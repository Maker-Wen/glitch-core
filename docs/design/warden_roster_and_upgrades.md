# 守卫者与升级设计

> 日期：2026-06-03
> 状态：3 技能制角色与升级池
> 依赖：[defense_roguelite_core_design.md](defense_roguelite_core_design.md)

## 1. 设计原则

守卫者不是 RPG 角色堆属性，而是 8x8 棋盘上的解题动词。

设计原则：

1. 每名守卫者有一个清楚的核心动词。
2. 每名守卫者能处理至少一种公开意图。
3. 每名守卫者有保护建筑的手段。
4. 升级优先改变位移、范围、时序、地形和奖励任务能力。
5. 少做攻击力 +1，除非它明显打开新解法。

## 2. 技能系统定案

每名守卫者固定携带 3 个主动技能。移动和待命是系统动作，不占主动技能槽；遗物不作为常驻第 4 技能，优先作为全局规则或战后构筑奖励。

3 个主动技能必须形成清晰分工：

| 技能位 | 定位 | 设计要求 |
|---|---|---|
| 技能 1 | 主解题技 | 高频、稳定、容易理解，是角色最核心的棋盘动词 |
| 技能 2 | 防守 / 修正技 | 用来救建筑、挡线、换位、修复、延迟地裂或修正站位 |
| 技能 3 | 条件 / 签名技 | 更强但需要局面条件、次数、冷却或风险，不应成为无脑常用攻击 |

战斗规则：

- 每名守卫者每回合最多使用 1 个主动技能。
- 使用主动技能后，该守卫者本回合行动结束。
- 守卫者可以先移动再使用主动技能；移动后不能再次移动。
- 移动通过棋盘可达格直接执行，不做成技能栏按钮。
- 待命 / 结束回合是全局或小型系统按钮，不进入 3 技能槽。
- 技能必须支持合法目标高亮和行动预演。
- 技能效果必须服务棋盘状态变化，例如伤害、推拉、换位、修复、护盾、地裂延迟、地形生成或 Boss 部件压制。

### 2.1 技能显示和升级显示

技能按钮必须显示当前实际效果，而不是只显示基础效果和强化标记。

示例：

| 状态 | 按钮短描述 |
|---|---|
| 基础链锤击 | `1 伤 推 1` |
| 获得重链后 | `1 伤 推 2` |
| 获得碎骨冲击后 | `1 伤 推 2 碎裂` |

强化标记可以作为辅助提醒，但不能替代描述更新。技能 hover 详情需要显示：

- 当前实际效果。
- 冷却 / 次数 / 条件。
- 已生效的升级来源。

技能升级应被并入技能本身，不作为战斗内遗物图标单独展示。遗物只在其效果是全局规则、跨角色触发或经济收益时显示在遗物区。

## 3. 队伍结构

Run 开始选择 3 名守卫者：

- 第一版允许 5 选 3。
- 同名守卫者不可重复。
- 每名守卫者战斗内每回合默认 1 移动 + 1 行动。
- 守卫者 HP 标准为 2，防线型可以为 3。

队伍构筑应形成明显取舍：

| 队伍倾向 | 优点 | 缺点 |
|---|---|---|
| 高位移控制 | 推拉多，清威胁强 | 修建筑弱 |
| 防线保护 | 建筑稳定，容错高 | 奖励任务难追 |
| 物理处决 | 坠渊和连锁强 | 对空旷地图依赖高 |
| 裂隙压制 | 出怪控制强 | 对远程威胁处理慢 |

## 4. 基础守卫者

### 4.1 赏金猎人

定位：近战推位、边缘处决、连锁启动。

基础数值：

| 项 | 值 |
|---|---:|
| HP | 2 |
| Move | 2 |
| Range | 1 |
| Damage | 1 |
| Force | 推 1 |

主动技能：

| 技能 | 定位 | 目标 | 当前效果 |
|---|---|---|---|
| 链锤击 | 主解题技 | 相邻敌人 / Boss 锚石 | 造成 1 伤，推 1 |
| 护卫肩撞 | 防守 / 修正技 | 相邻单位 | 与目标换位；若目标是敌人，造成 1 伤，不推 |
| 悬赏处决 | 条件 / 签名技 | 相邻敌人 | 造成 1 伤；若本次行动导致目标死亡、坠落或撞毁，本场悬赏进度 +1；每场 2 次 |

升级方向：

| 升级 | 效果 | 目的 |
|---|---|---|
| 重链 | 推力 +1 | 增强空间解法 |
| 处决钩 | 将敌人推下深渊时获得 +1 余烬，本场最多 2 次 | 奖励任务协同 |
| 盾肩 | 护卫肩撞可选择相邻建筑旁空格作为换位落点 | 保护建筑 |
| 碎骨冲击 | 撞墙时额外施加碎裂 | 控制下回合 |

主动技能：

| 反手抛 | 条件 / 签名技 | 直线 2 格敌人 | 将目标拉向自己；若目标到达相邻格且侧向有空格，可侧推 1 |

| 裂隙楔 | 延迟回合 +1，或对地裂上敌人额外造成 1 伤 | 裂隙奖励 |

## 5. 新增守卫者候选

### 5.1 铁誓卫

定位：防线、换位、承伤。

基础数值：

| 项 | 值 |
|---|---:|
| HP | 3 |
| Move | 2 |
| Range | 1 |
| Damage | 1 |
| Force | 0 |

候选技能方向：

| 技能 | 定位 | 当前效果 |
|---|---|---|
| 铁誓换位 | 主解题技 | 与相邻守卫者、敌人或建筑旁空格交换位置；若目标是敌人，造成 1 伤 |
| 守门 | 防守 / 修正技 | 给相邻建筑 1 次伤害 -1 |
| 拦截 | 条件 / 签名技 | 本回合相邻远程线穿过自己时，铁誓卫优先成为目标 |

关键升级：

- 守门：回合结束时若相邻建筑，本回合该建筑受到的第一次伤害 -1。
- 拦截：相邻远程线穿过自己时，铁誓卫优先成为目标。
- 压阵：换位后获得 1 点临时护甲。

### 5.2 祷告者

|---|---:|

| Move | 2 |
| Range | 2 |
| Damage | 0 |
| Force | 0 |

候选技能方向：

| 技能 | 定位 | 当前效果 |
|---|---|---|
| 余烬祷告 | 主解题技 | 选择 2 格内建筑，恢复 1 HP，不能超过初始 HP |

## 6. 升级结构

每名守卫者有 6 个升级，分 3 类：

| 类别 | 数量 | 说明 |
|---|---:|---|
| 动词增强 | 2 | 推拉距离、范围、连锁、换位 |
| 防守增强 | 2 | 修复、屏障、挡线、建筑保护 |
| 任务增强 | 2 | 裂隙、物理击杀、清场、低损任务收益 |

每名守卫者每章最多获得 1 次升级。完整 3 章 Run 中，核心队伍每人约 2-3 个升级。

升级与技能的关系：

- 升级直接改造 3 个主动技能，不新增第 4 个常驻技能。
- 技能按钮短描述显示当前实际效果。
- 升级来源只在 hover 详情、角色页和奖励页中展开。
- 与单一技能绑定的强化属于技能升级，不作为战斗内遗物图标展示。

## 7. HP、濒死和死亡规则

守卫者 HP 是 Run 级资源，不是单场临时血条。玩家必须清楚理解：棋子还在场就能行动，HP 归 0 就死亡。

第一版规则：

- 战斗结束后，存活守卫者保留当前 HP，不自动回满。
- HP 为 1 时进入濒死；濒死守卫者仍可移动、行动、阻挡和被敌人锁定。
- 濒死时再受到 1 点伤害会死亡。
- HP 降到 0 时死亡，从棋盘移除，并从本 Run 名单中移除。
- 坠渊 / 出界直接死亡，只在明确深渊地图中作为强预告危险使用。
- 所有出战守卫者死亡时，Run 立即失败。
- 只要仍有至少 1 名守卫者存活，战斗可以继续；后续节点可以残编进入，但关卡不会自动降难。
- 营地可让所有存活守卫者恢复 1 HP。
- 商店可让 1 名存活守卫者恢复 1 HP。

第一版不做随机死亡判定、濒死检定、倒地救援或复活。死亡必须是公开意图和确定性伤害的结果。

### 7.1 UI 表达

守卫者 HP 必须常驻展示：

- HP 为 2 或 3 时显示普通血点。
- HP 为 1 时显示“濒死”状态色和高风险提示。
- 敌人意图命中濒死守卫者时，预演必须显示“将死亡”。
- 死亡后棋子从棋盘移除，结算页写入“已死亡 / 本 Run 离队”，不使用“撤离”“归队”等词。

这样避免玩家误解“棋子消失后又回来”，也避免额外设计伤员状态区。

## 8. 平衡边界

守卫者单次行动默认只应解决 1 条硬威胁。高阶连锁可以解决 2 条，但应依赖位置和预演。

不建议出现：

- 大范围无条件清场。
- 长距离任意传送。
- 永久提高伤害到 3 以上。
- 无代价复活。
- 可以稳定每回合修复所有建筑的循环。

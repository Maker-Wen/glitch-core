# 防守战术肉鸽核心设计

> 日期：2026-06-03
> 状态：新版主纲
> 适用范围：战斗目标、守卫者、敌人、地图、奖励任务、Run 结构、遗物与经济

## 1. 定位结论

《长夜余烬》的核心定位固定为：

> 暗黑小队战术肉鸽。玩家指挥 3 名守卫者，在 8x8 小棋盘上通过公开意图、推拉位移、阻挡、撞击和路线构筑，撑过一连串以保护建筑和关键目标为核心的防守战。

本作不是清怪战旗，也不是目标多变的任务制战棋。所有标准战斗都围绕同一件事： **守到终局** 。

## 2. 不可违反规则

1. **胜利条件稳定** ：坚持到最大回合、至少 1 名守卫者存活、保护目标未全部被毁。
2. **不提前胜利** ：清空敌人、全建筑存活、封印裂隙、击破 Boss 部件都不能提前结束战斗。
3. **奖励任务可变** ：清场、完美防守、封裂隙、物理击杀、Boss 压制只作为额外奖励目标。
4. **公开意图** ：所有已揭示敌人下回合行为必须清楚展示，并能被玩家行动打断或利用。
5. **战斗内无随机** ：无随机命中、随机伤害、隐藏 AI、随机行动重算。
6. **深度来自空间和构筑** ：主要深度来自空间解法、敌人意图、守卫者技能、遗物、奖励任务、路线选择。
7. **数值服务解题** ：HP、移动力、伤害、推拉力都要服务棋盘题型，不做大数值膨胀。

## 3. 核心循环

### 3.1 战斗内 30 秒循环

```text
观察敌人意图和地裂预告
  -> 选择 1 名守卫者行动
  -> 预演推拉、撞击、挡线、建筑损失
  -> 执行动作改变棋盘
  -> 威胁减少、奖励进度推进或代价暴露
  -> 继续处理下一条威胁
```

这套循环必须成立于每个回合。玩家的乐趣不是“打死多少怪”，而是“用 3 次行动把 4-6 条压力压到可承受范围”。

### 3.2 Run 级循环

```text
选择 3 名守卫者
  -> 在章节地图选择路线
  -> 进入防守战
  -> 根据建筑损失、奖励任务、守卫者伤势结算
  -> 获得余烬、遗物、升级或事件收益
  -> 路线压力升级
  -> 击退章节 Boss 后进入下一章
```

Run 的随机性只出现在路线、节点、奖励、事件、遗物和敌群组合。战斗内仍保持确定性。

## 4. 战斗胜负框架

每场战斗进入时定义：

- `max_rounds`
- `protected_targets`
- `warden_roster`
- `rift_schedule`
- `reward_tasks`
- `encounter_budget`

### 4.1 标准胜利

战斗在 `max_rounds` 结束后检查胜利：

1. 至少 1 名守卫者存活。
2. 如果有保护目标，至少 1 个保护目标存活。
3. Boss 战如果存在章节核心目标，章节核心没有完成毁灭计数。

满足以上条件则胜利。

### 4.2 标准失败

任一条件发生时立即失败：

1. 所有守卫者阵亡或离场。
2. 所有保护目标被毁。
3. 特定 Boss 机制达成毁灭条件，例如钟鸣计数满。

### 4.3 不提前胜利裁定

以下情况不触发胜利：

- 当前敌人全灭。
- 没有 pending 地裂出怪。
- 没有未来地裂 schedule。
- 所有奖励任务完成。
- 所有建筑满血。
- Boss 锚石全部摧毁。
- Boss 暴露核心被击破。

这些情况只会降低后续压力或提高结算奖励。战斗必须继续到 `max_rounds`。

## 5. 战斗类型重新定义

旧文档中的“歼灭战”和“封印战”不再作为独立胜利类型。它们改为同一防守框架下的 **压力主题** 和 **奖励任务组合** 。

| 战斗主题 | 主目标 | 主题压力 | 常见奖励任务 |
|---|---|---|---|
| 守卫战 | 撑到终局，保住建筑 | 多方向近战和远程威胁 | 完美防守、低损防线 |
| 清剿压力战 | 撑到终局 | 敌人总量少但高价值目标多 | 终局清场、精英击杀 |
| 裂隙压制战 | 撑到终局 | 地裂靠近建筑，持续出怪 | 占裂隙、延迟出怪、封锁裂隙 |
| 护送防线战 | 撑到终局 | 关键目标位置脆弱，需要轮流挡线 | 指定目标无伤、守卫者全活 |
| 精英战 | 撑到终局 | 硬威胁上限提高，奖励更强 | 多任务组合 |
| Boss 战 | 撑到终局，防止毁灭机制 | Boss 公开脚本 + 常规敌群 | 压制部件、完美防守、限制 Boss 阶段 |

## 6. 深度来源

### 6.1 空间解法

空间解法是战斗底层。每张地图必须至少提供 2 种可读解法：

- 把敌人推离攻击位。
- 用守卫者挡住远程线。
- 把敌人推入深渊或撞上石柱。
- 用建筑、废墟、路障塑造路径。
- 占住地裂延迟出怪。
- 牺牲次要建筑保护关键建筑。

### 6.2 敌人意图组合

敌人单体行为要简单，但组合后制造张力：

- 近战敌人逼近建筑，制造行动税。
- 远程敌人让挡线和拉推成立。
- 冲撞敌人制造车道谜题。
- 引导敌人制造“现在不处理，下回合变坏”的延迟压力。
- 堵路敌人让移动空间变贵。

### 6.3 守卫者动词

守卫者设计遵循“动词优先”：

- 基础动词少而清楚。
- 升级改变作用范围、附加位移、保护、任务收益。
- 尽量不做单纯攻击 +1。
- 每个守卫者至少有 1 个保护建筑的办法和 1 个处理敌人意图的办法。

### 6.4 遗物改写

遗物不堆属性，而是改写解法：

- 改变推拉距离。
- 给撞击、碎裂、挡线、地裂占位附加收益。
- 让特定奖励任务更容易完成。
- 改变战斗开局布防或地形。

### 6.5 奖励任务

奖励任务承担三件事：

1. 给高手追求。
2. 让同一地图在不同 Run 中有不同优先级。
3. 把“清场、封裂隙、Boss 部件击破”从胜利条件转化为收益目标。

## 7. 数值基准

| 项 | 普通战 | 精英战 | Boss 战 |
|---|---:|---:|---:|
| 棋盘 | 8x8 | 8x8 | 8x8 |
| 守卫者数量 | 3 | 3 | 3 |
| 回合数 | 5 | 5-6 | 6 |
| 保护目标数 | 3-4 | 3-5 | 2-4 |
| 保护目标 HP | 2 | 2-3 | 2-3 |
| 每回合硬威胁上限 | 2 | 3 | 3 |
| 总敌人预算 | 7-10 | 10-13 | 12-16 |
| 初始守护值 | 7 | - | - |

硬威胁指本回合会造成不可忽视损失的敌人，包括攻击建筑、击杀守卫者、摧毁关键目标或触发 Boss 毁灭计数的行为。

## 9. 需要修正的旧方向

以下旧方向应废弃或降级：

| 旧方向 | 新裁定 |
|---|---|
| 歼灭战清空敌人即胜利 | 改为“终局清场”奖励任务 |
| 封印战完成封印即胜利 | 改为“裂隙压制”奖励任务和减压机制 |
| Boss 击杀即胜利 | 改为 Boss 战中的压制目标，胜利仍看终局防守 |
| 无建筑战斗作为常规节点 | 不作为主线常规节点，仅可用于教程、事件或特殊挑战 |
| 大量数值成长 | 改为动词增强、地形互动和奖励任务协同 |

## 10. 首轮落地顺序

1. 修正战斗胜负：取消清空敌人提前胜利。
2. 实装保护目标 HP 和建筑毁灭失败。
3. 建立奖励任务记录与结算。
4. 增加 2-3 个敌人职责，而不是先扩大量级。
5. 增加 6-8 个遗物，验证 Run 差异。
6. 做 1 章 6 节点短 Run，验证路线损耗和奖励循环。

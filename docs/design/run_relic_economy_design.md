# Run、遗物与经济设计

> 日期：2026-06-03
> 状态：第一版肉鸽框架
> 依赖：[defense_roguelite_core_design.md](defense_roguelite_core_design.md)

## 1. 设计目标

肉鸽深度要服务防守战斗，而不是覆盖战斗：

- 路线选择制造风险和资源取舍。
- 遗物改变解法，不堆大数值。
- 经济约束升级、修复、事件和商店。
- 损耗让玩家关心整支小队，而不是只关心单场完美解。

## 2. Run 结构

第一版完整 Run 建议为 3 章。Run 长度、路线生成、节点预览、存档点和 Demo 固定路线以 [run_structure_design.md](run_structure_design.md) 为准；本文档只保留经济、遗物和事件框架。

| 章 | 节点数 | 主题 | 新内容 |
|---|---:|---|---|
| 第 1 章：外墙余烬 | 5-6 | 基础建筑防守 | 腐食兽、弓手、石柱、地裂 |
| 第 2 章：裂隙回廊 | 6-7 | 裂隙和精英压力 | 铁角兽、裂隙司祭、腐爆囊 |
| 第 3 章：长夜钟楼 | 6-7 | Boss 脚本和高级组合 | 钟奴、护壳虫、Boss 机制 |

每章结尾固定 Boss 或章节核心战。章节内路径半随机生成，但节点类型和难度遵守预算。

## 3. 节点类型

| 节点 | 占比 | 作用 |
|---|---:|---|
| 普通战 | 45% | 稳定获得余烬和升级 |
| 精英战 | 15% | 高风险遗物来源 |
| 事件 | 15% | 换资源、换 HP、获得特殊收益 |
| 工坊 | 10% | 购买或强化守卫者升级 |
| 营地 | 10% | 恢复守卫者 HP、修复守护值 |
| 神龛 | 5% | 高收益高腐化 |
| Boss | 每章 1 个 | 章节终局 |

第一版 Demo 可以压缩为 1 章 6 节点：普通战、事件、普通战、精英战、营地、Boss。

## 4. Run 资源

### 4.1 守护值

守护值代表据点整体防线，默认上限和起始值为 12。

- 保护目标每受到 1 点实际伤害，结算时扣 1 点守护值。
- 守护值损失没有单场封顶，战斗内 HUD 和行动预演必须实时显示预计损失。
- 防线溃败不额外追加固定扣减；保护目标全毁时，建筑 HP 已经自然转化为守护值损失。
- 守护值归 0 则 Run 失败。
- 每章最多通过奖励任务恢复 1。
- 营地可恢复 2。
- 商店可花余烬恢复 1。

### 4.2 余烬

余烬是主要货币。

来源：

- 普通战基础 7。
- 精英战基础 11。
- Boss 战基础 14。
- 奖励任务额外 2-8。
- 事件收益。

消耗：

- 工坊购买升级。
- 商店购买遗物。
- 营地治疗、商店急救和修复守护值。
- 事件支付。

### 4.3 腐化

腐化是高收益代价资源。

获得：

- 神龛选择。
- 某些强遗物。
- 事件交易。

效果：

| 腐化值 | 效果 |
|---:|---|
| 0-2 | 无 |
| 3-4 | 每章额外 1 个裂隙强化 |
| 5-6 | 精英战硬威胁上限 +1，但仍不能超过 3 |
| 7+ | Boss 战毁灭计数初始 +1 |

腐化不能随机改变战斗内行为，只能改变公开的战前配置。

### 4.4 守卫者 HP 和死亡

守卫者 HP 是 Run 级角色资源。战斗结束不自动回满，死亡不自动复活。

规则：

- 普通守卫者最大 HP 为 2，防线型守卫者最大 HP 可以为 3。
- HP 为 1 时进入濒死，但仍可正常移动、行动和被敌人锁定。
- HP 降到 0 时死亡，从本 Run 名单中移除。
- 3 名出战守卫者全部死亡时，Run 失败。
- 若仍有 1-2 名守卫者存活，可以残编继续；关卡不自动降难，玩家需要通过营地、事件或后续补员系统修正风险。
- 第一版不提供复活服务。

守卫者死亡是比建筑损失更硬的失败压力。建筑可以用守护值承接，人员死亡会永久减少行动数。

## 5. 经济基准

### 5.1 收入

| 节点 | 基础余烬 | 任务上限 | 总上限 |
|---|---:|---:|---:|
| 普通战 | 7 | 6 | 13 |
| 精英战 | 11 | 8 | 19 |
| Boss 战 | 14 | 8 | 22 |
| 事件 | -4 到 +8 | - | 8 |

Boss 杂兵击杀不给余烬。普通战如保留击杀余烬，整场上限为 3，避免鼓励刷怪。

### 5.2 消耗

| 消耗项 | 价格 |
|---|---:|
| 普通升级 | 10 |
| 稀有升级 | 14 |
| 普通遗物 | 12 |
| 稀有遗物 | 18 |
| 营地：全队恢复 1 HP | 免费节点选择 |
| 营地：恢复 2 守护值 | 免费节点选择 |
| 商店：单人恢复 1 HP | 4 |
| 商店：恢复 1 守护值 | 6 |
| 刷新奖励选项 | 3 |

价格目标：玩家每章通常能买 1-2 个关键成长，不能什么都买。

营地默认在“治疗小队”和“修复防线”中二选一。商店提供小额修复，目的是让玩家补洞，不是把损耗完全抹掉。

## 6. 遗物设计原则

遗物分 5 类：

| 类别 | 作用 |
|---|---|
| 位移遗物 | 改推拉、换位、撞击 |
| 防守遗物 | 改建筑、屏障、修复、守护值 |
| 裂隙遗物 | 改地裂占位、出怪延迟、裂隙奖励 |
| 风险遗物 | 用 HP、守护值、腐化换强收益 |
| 任务遗物 | 强化奖励任务收益或完成方式 |

遗物不能让某个核心压力永久失效。例如“所有建筑第一次受伤无效”可以；“所有建筑永久免疫远程”不可以。

## 7. 第一版遗物池

| 遗物 | 稀有度 | 效果 |
|---|---|---|
| 链锤改装 | 普通 | 赏金猎人的推力 +1 |
| 长杖共鸣 | 普通 | 大魔法师推动目标撞击后施加碎裂 |
| 坟土钩爪 | 普通 | 盗墓人拉到相邻后可移动 1 格 |
| 余烬护符 | 普通 | 每场第一次普通建筑受伤 -1 |
| 裂隙钉 | 普通 | 守卫者站在地裂上时，地裂延迟出怪且守卫者不受地裂伤害 |
| 残墙图纸 | 普通 | 战斗开局可放置 1 个 HP=1 临时路障 |
| 断钟回响 | 稀有 | 每回合第一次撞击会把被撞单位继续推 1 格 |
| 黑铁楔 | 稀有 | 敌人被推向建筑时，先受到 1 伤；若死亡则不伤建筑 |
| 血税契约 | 稀有 | 守卫者本回合受伤后，下一次攻击推拉力 +1；濒死时不会触发第二次 |
| 守夜誓约 | 稀有 | 每章第一次完成 3 个奖励任务时，守护值 +1 |
| 焦土旗帜 | 普通 | 废墟相邻的敌人移动 -1 |
| 工匠遗骨 | 普通 | 修复建筑时，如果该建筑相邻有敌人，对该敌人造成 1 伤 |
| 裂纹透镜 | 稀有 | 对碎裂敌人的第一次攻击额外 +1 伤害，每回合 1 次 |
| 圣灰灯 | 普通 | 营地恢复守护值价格 -3 |
| 腐化冠冕 | 稀有 | 获得遗物选项 +1，但腐化 +2 |

## 8. 遗物组合方向

### 8.1 物理连锁流

核心遗物：

- 链锤改装
- 断钟回响
- 裂纹透镜

体验：用推撞和碎裂处理多条威胁，追求物理处决和连锁大师。

### 8.2 建筑防守流

核心遗物：

- 余烬护符
- 黑铁楔
- 工匠遗骨
- 圣灰灯

体验：允许建筑承受少量压力，通过修复、减伤和反击稳定通关。

### 8.3 裂隙压制流

核心遗物：

- 裂隙钉
- 残墙图纸
- 坟土钩爪

体验：主动占裂隙，延迟出怪，用路线控制换奖励任务。

### 8.4 风险爆发流

核心遗物：

- 血税契约
- 腐化冠冕
- 守夜誓约

体验：承担伤害和腐化，换更强奖励选项和高收益战斗。

## 9. 事件设计

事件必须产生明确取舍，不做长叙事。

| 事件 | 选择 A | 选择 B |
|---|---|---|
| 熄灭的灯塔 | 花 6 余烬恢复 1 守护值 | 获得 10 余烬，腐化 +1 |
| 破损军械库 | 获得普通升级，随机存活守卫者受 1 伤 | 跳过，获得 4 余烬 |
| 裂隙边的祈祷 | 腐化 +2，获得稀有遗物 | 移除 1 腐化 |
| 难民车队 | 失去 5 余烬，下一战建筑 HP +1 | 不帮助，无效果 |
| 钟声梦魇 | 下一战硬威胁 +1，奖励任务额外 +1 | 守护值 -1 |

事件选择必须在进入下一战前完全公开影响，不允许进入战斗后才揭示负面。

## 10. 路线生成约束

每章路线生成遵守：

- 第 1 节点必须是普通战。
- Boss 前 1 个节点不能是神龛。
- 每章至少 1 个营地或工坊。
- 精英战后至少给 1 个非战斗节点选择。
- 高腐化路线必须显示风险图标。
- 同一路径不连续出现 3 个战斗节点，除非奖励明显更高。

## 11. Demo 落地范围

第一轮可玩 Demo 不需要完整 3 章。

推荐范围：

1. 1 章 6 节点路线。
2. 3 名现有守卫者 + 1 名新增守卫者。
3. 4 类敌人：腐食兽、瘟疫弓手、铁角兽、裂隙司祭。
4. 8 个遗物。
5. 8 个奖励任务。
6. 守护值、守卫者 HP、余烬、营地恢复。

这足够验证肉鸽深度是否来自路线和构筑，而不是单场战斗目标变化。

# UI 决定论规则与战斗轮次预算

>
> 本文档定义完美信息棋盘的"敌人 AI tie-break 精确优先级"和"战斗轮次出怪节奏"。实现 AI 决策树时必读。

## 1. 决定论规则（敌人 AI tie-break — 关键）

完美信息游戏的成败由"敌人下回合行为是否 100% 可推演"决定。下表是 AI 选择的精确优先级，**必须严格执行**。

> ⚠️ 本规则与主策划案 §4.5（敌人 AI 三铁律）配套使用。三铁律定义"敌人攻击谁"，本节定义"多个可能性中如何抉择"。

### 1.1 敌人移动选路 tie-break（同距离时）

按以下顺序应用：

1. **最近的能攻击到的建筑**（综合"移动距离 + 攻击范围"的总成本）
2. 多个建筑距离相同 → 选 **HP 较低的建筑**
3. HP 也相同 → 按建筑棋盘 ID 升序（左上角 ID=0，从左到右、从上到下递增）
4. 路径多条等长 → 按 **北 → 东 → 南 → 西** 选择第一格（与玩家 A* 一致）

### 1.2 远程敌人（瘟疫弓手）的射击优先级 🔴 已更新

> **Oracle 审查发现**：旧规则"方向选定后优先锁定建筑"与 §4.5"守卫者会挡线"矛盾。**以下是统一版本**。

进入射程后，沿 4 方向直线扫描：

1. **优先选有任何可被击中目标的方向**（守卫者 / 建筑 / 其他敌人都算可被击中）
2. 多方向都有可击中目标 → 按 **北 → 东 → 南 → 西** 选第一个方向
3. 方向选定后，沿线扫描，**锁定第一个单位（含建筑），无论是什么类型**：
   - 第一个是建筑 → 击中建筑
   - 第一个是守卫者 → 击中守卫者（**身体挡线战术成立**）
   - 第一个是其他敌人 → 击中其他敌人（友军误伤）
4. 完全无目标 → 不射击 / 改为正常移动

**核心原则**：**直线上第一个目标被命中，没有建筑优先权**。这与玩家远程攻击的"友军挡线"规则**对称**——保证完美信息承诺。

详见 [combat_resolution_truth_table.md §5](combat_resolution_truth_table.md)。

### 1.3 冲撞型（铁角兽）的冲刺方向

主动攻击型，每回合预警阶段重新计算：

1. **优先选能撞到玩家守卫者 + 后方有建筑的方向**（一击两得）
2. 仅能撞到玩家守卫者 → 选第一个能撞的方向（北→东→南→西）
3. 仅能撞到建筑 → 选第一个能撞的建筑方向
4. 都不能 → 朝最近建筑的最短路径（普通寻路）

## 2. 战斗轮次预算（每场战斗的敌人节奏）

战斗节奏由"轮次预算"控制——每轮新出怪数量由地裂数量决定，但**总量经过预算**避免堆怪。

### 2.1 MVP 阶段标准战斗（5 轮）— Oracle 调整后

> **Oracle 审查发现**：旧版本 3 铁角兽同场 + 3 行动/回合 → 经常无法挽救。**以下是调整后的安全预算**。

| 轮次 | 新出怪数量 | 备注 |
|---|---|---|
| **第 1 轮** | 2 个 | 开局压力小，给玩家"打开局面"的回合 |
| **第 2 轮** | 2-3 个 | 节奏稳定上升 |
| **第 3 轮** | 3 个 | 中盘高潮，**最多 1 个铁角兽** |
| **第 4 轮** | 2 个 | 收尾压力 |
| **第 5 轮** | 0-1 个 | 清场轮 |

**总出怪数量**：每场战斗 **8-10 个敌人**（精英战 +30%，可超过此预算）。

### 2.2 威胁预算硬性规则（Oracle CRITICAL A3）

防止"3 行动/回合 vs 太多硬威胁"导致的不公平失败感：

| 规则 | 数值 |
|---|---|
| **每回合最多硬威胁数**（能在 1 行动外击杀的目标）| **2 个** |
| **任意时刻棋盘上铁角兽上限**（活着的）| **2 个** |
| **第 4 轮前最多 1 个铁角兽活动** | 保底 |
| **普通战总共铁角兽数** | **最多 2 个**（含整场战斗） |
| **3 铁角兽场景** | **仅精英战 / Boss 战**可触发 |

**威胁分类**（系统判断时使用）：
- **硬威胁**：当前回合可攻击建筑或锚石的敌人（弓手已在射程 / 铁角兽朝建筑冲 / 腐食兽相邻建筑）
- **软威胁**：本回合还在移动、下回合才到位的敌人

威胁预算只算**硬威胁**。新出怪敌人按其下回合行动判定。

### 2.3 敌人配比规则（MVP）

每场战斗的敌人种类配比（按 Oracle 修订）：

- **腐食兽（基础威胁）**：40-45%（提升基础威胁比例）
- **瘟疫弓手（远程压力）**：30-35%
- **铁角兽（节奏关键）**：15-20%（最多 2 个/场，至少 1 个保底出现在第 3 轮）

### 2.4 精英战配比

精英战每场比普通战**多 30% 敌人** + 必含 1 个铁角兽精英版（HP=4，推力=3）。精英战可触发 **3 铁角兽同场**。

### 2.4 ITB 风格的信息时序提示

- **战斗开始**：UI 显示"本场共 5 轮，威胁等级 = 标准 / 精英"。**不列举**具体敌人种类与数量
- **每轮末尾**：在地裂上显示"出怪预告"图标（金边闪烁），告诉玩家下一轮这里会冒出怪，但**不显示是什么类型**
- **下一轮预警阶段开始**：地裂中冒出敌人，**此时才揭晓敌人类型 + 预警下回合行动**

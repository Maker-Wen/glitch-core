## 1. Demo 概览

### 一句话

> 8×8 棋盘上的 ITB 风格回合制战斗：3 个守卫者 vs 多波敌人（含地裂出怪），通过推/拉/接力撞击物理操作完成 5 个回合的攻防。完美信息、完美可推演。

### 跑起来

```
# 用 Godot 4.6 Mono 打开项目
godot --path .

# 或者直接执行运行
/Applications/Godot_mono.app/Contents/MacOS/Godot --path .

# 跑测试（127 个单元测试）
godot --headless --path . -s scripts/tests/test_runner.gd
```

## 2. 已实现的玩法功能

### 2.1 战斗循环

| 阶段 | 状态 | 详情 |
|---|---|---|
| **布防阶段（Garrison）** | ✅ | 玩家依次点击下方 2 行的格子部署 3 个守卫者 |
| **回合 1-5 战斗** | ✅ | 完整 5 回合循环，每回合：地裂出怪 → 敌人移动 → 玩家行动 → 敌人攻击 |
| **回合超时** | ✅ | 5 回合后存活守卫者 → 胜利；全灭 → 失败 |
| **完美信息** | ✅ | 所有敌人意图（攻击源/攻击目标格）公开显示 |
| **锁定原则** | ✅ | 敌人攻击方向锁定；被推开后红线从当前位置沿原方向平移 |

### 2.2 玩家操作

#### 守卫者选择 & 行动

| 操作 | 状态 | 详情 |
|---|---|---|
| **点击守卫者** | ✅ | 弹出技能页面 + 高亮可行动范围 |
| **快速点击棋盘格** | ✅ | 直接执行（绿格移动 / 红格攻击）|
| **技能驱动操作** | ✅ | 点底部技能按钮 → 高亮目标范围 → 点目标格 |
| **每回合 1 移动 + 1 攻击** | ✅ | 攻击或结束回合后该守卫者完毕，颜色变暗 |
| **撤回上一步** | ✅ | Cmd/Ctrl+Z 或顶部琥珀色按钮，回到上次状态 |
| **结束回合** | ✅ | 空格键 或 顶部按钮 |
| **取消选中** | ✅ | 右键 / 点空白格 |

#### 技能页面（底部弹出）

| 技能 | 状态 | 备注 |
|---|---|---|
| **默认攻击** | ✅ | 绿色按钮（推荐），上膛后变金色 |
| **移动** | ✅ | 显示移动力（点击棋盘绿格即可） |
| **遗物技能** | ⏳ | 占位按钮，灰色禁用（1.0+ 实装）|

**上膛状态**：点击技能按钮后进入「等待选择目标」状态，棋盘上只显示该技能的合法范围。再次点击同一技能或右键取消。

### 2.3 守卫者（3 种，全部可用）

| 守卫者 | HP | 移动 | 攻击 | 类型 |
|---|---|---|---|---|
| **赏金猎人** | 2 | 2 | 近战 4 方向相邻 1 格 → 1 伤 + 推 1 | 近战推 |
| **盗墓人** | 2 | 2 | 远程 4 方向直线 3 格 → 1 伤 + 拉 1 | 远程拉 |
| **大魔法师** | 2 | 2 | 远程 4 方向直线 3 格 → 1 伤 + 推 1 | 远程推 |

### 2.4 敌人（2 种，全部可用）

| 敌人 | HP | 移动 | 攻击 | 行为 |
|---|---|---|---|---|
| **腐食兽 (Carrion Spawn)** | 2 | 3 | 近战相邻 1 格 → 1 伤 | 朝最近守卫者移动；邻接即攻击 |
| **瘟疫弓手 (Plague Archer)** | 2 | 2 | 远程直线 3 格 → 1 伤 | 4 方向扫描；锁定第一个守卫者；同阵营单位挡线但不被攻击 |

> 切片演示阶段腐食兽 HP=2、移动=3（主策划案 §8.3 规定 HP=1、移动=2，正式实现教学关时调回）。详见 [round_flow_and_intent.md §9](design/round_flow_and_intent.md)。

### 2.5 物理引擎

| 机制 | 状态 | 详情 |
|---|---|---|
| **推 N 格** | ✅ | 每攻击附带固定推力，按 §3.5 原子结算 |
| **拉 N 格** | ✅ | 反方向推（与推共用结算流程）|
| **接力撞击 (Relay)** | ✅ | A 推 B，B 撞 C → C 受 1 伤 + 剩余推力传递 |
| **撞墙** | ✅ | 撞石柱 → 1 撞墙伤 + 推力作废 |
| **坠渊** | ✅ | 推/拉出棋盘 → 立即出局 |
| **0 HP 占格** | ✅ | 链中死亡单位 Tend 前仍占格（避免链断）|
| **死亡延迟清算** | ✅ | 整条链结算完才统一移除死亡单位 |
| **友军误伤禁用** | ✅ | 同阵营 chain 撞击 0 伤（玩家不会误伤自己的守卫者）|

## 3. 引擎架构特性（开发者视角）

### 3.1 完美信息保证

| 承诺 | 实现 |
|---|---|
| **预演 = 执行** | `BattleEngine.preview_action()` 在 `state.clone()` 上跑同一份 `_dispatch_action` |
| **零随机** | 整数坐标 + 整数推力 + 固定 N→E→S→W tie-break |
| **零浮点** | 所有逻辑用 `int` 和 `Vector2i` |
| **可推演** | 同样状态 + 同样操作 = 同样结果 |

### 3.2 状态机分层

```
┌────────────────────────────────────────────────────────┐
│                       BattleScene (view)               │
│  · Drawing / animation / input dispatch                │
│  · Listens to engine.events_produced / state_changed   │
└──────────────────────┬─────────────────────────────────┘
                       │ apply_action(BattleAction)
                       ▼
┌────────────────────────────────────────────────────────┐
│                  BattleEngine (orchestrator)           │
│  · _dispatch_action -> per-kind handlers               │
│  · Auto-advance round, check victory                   │
│  · History stack for undo                              │
└──────┬───────────────────────────┬─────────────────────┘
       │ uses                       │ uses
       ▼                            ▼
┌──────────────────┐    ┌─────────────────────────┐
│   AIDecider      │    │   PhysicsResolver       │
│ · plan_enemy_turn│    │ · resolve_attack        │
│ · replan_attack  │    │ · resolve_move          │
│ · scan_line      │    │   (push/pull/relay)     │
└──────┬───────────┘    └───────────┬─────────────┘
       │                            │
       ▼                            ▼
       ┌─── BattleState (data) ─────┐
       │ · grid, units, plans       │
       │ · round, phase, outcome    │
       │ · rift state, deploy zone  │
       └────────────────────────────┘
```

## 7. 演示玩法循环（5 分钟体验）

1. **启动 → 布防阶段**
   - 棋盘下方 2 行变绿（可部署区）
   - 顶部显示「请部署：赏金猎人（还剩 3 个）」
   - 点击 3 个绿格部署 3 个守卫者
   - 按空格 → 进入回合 1

2. **回合 1**
   - 北边一线 3 只敌人（2 腐食兽 + 1 弓手）

## 8. 演示亮点（推荐试一下的操作）

### 8.1 经典 ITB 推下深渊

把腐食兽推到棋盘边缘 → 直接坠渊击杀。最高效的清场手段，对 HP 高的敌人（如未来的铁角兽）尤其关键。

### 8.2 接力推动（Chain Push）

3 只腐食兽一字排开 → 用大魔法师远程推 → 最后一只可能被推下深渊。一次操作多杀。

### 8.3 撞石柱减速

地图中央有石柱。把敌人推到石柱旁 → 撞墙 1 伤 + 推力作废。

### 8.4 弓手挡线

让腐食兽站在弓手与守卫者之间 → 弓手本回合**无法射击**（同阵营挡线但 0 伤）。等于让弓手白费一回合。

### 8.5 推开敌人 = 平移攻击线

弓手或腐食兽显示红色攻击意图 → 移动守卫者到旁边，用近战推开敌人 → 敌人本回合仍会按原方向出手，但红线从敌人新位置重新投射。若新攻击格为空，则不造成伤害；若新攻击格上有守卫者或建筑，则命中新的目标。

### 8.6 拉过来送葬

用盗墓人从 3 格外把敌人拉到自己面前 → 下回合用赏金猎人补刀。

### 8.7 撤回检查

任何阶段按 Cmd+Z 撤回，最多 50 步。可以反复试错。
